# Версии

Версии `nginx` делятся на две ветки:

- `Mainline` (Основная)
- `Stable` (Стабильная)

## Основная

Основная версия содержит все самые новые функции, исправления ошибок, включения исправления безопасности.
Рекомендуется для разработчиков.

Особенности:

- Обозначается нечетным числом во второй части версии.
- Новые версии выходят примерно раз в месяц.
- Изменения в версии могут влиять на работу сторонних модулей.

## Стабильная

Стабильная версия уже не обновляется новыми функциями, получает только патч исправления

Особенности:

- Обозначается четным числом во второй части версии.
- Изменения в стабильной ветви не должны затронуть сторонние модули.

::: tip
На рабочих серверах рекомендуется использовать стабильную версию.
:::
