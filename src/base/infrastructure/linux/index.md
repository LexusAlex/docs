# Linux

Раздел объединяет последовательный учебный маршрут и справочные материалы для повседневной работы с Linux.

| Раздел | Для чего |
|--------|----------|
| [Изучение Linux](learning-roadmap.md) | Последовательный путь от первой виртуальной машины до администрирования сервера |
| [Команды Linux](commands/) | Подробный справочник команд, сгруппированный по задачам |
