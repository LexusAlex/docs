# Файрвол

Управление сетевым экраном: фильтрация трафика, разрешение и блокировка соединений.

## Команды

| Команда | Описание |
|---------|----------|
| [iptables](iptables.md) | Классический файрвол Linux |
| [nftables](nftables.md) | Современная замена iptables |
| [ufw](ufw.md) | Uncomplicated Firewall (простой интерфейс) |
| [firewalld](firewalld.md) | Файрвол с зонами (RHEL/Fedora) |

## Цепочки iptables

| Цепочка | Описание |
|---------|----------|
| `INPUT` | Входящий трафик |
| `OUTPUT` | Исходящий трафик |
| `FORWARD` | Транзитный трафик |

## Действия

| Действие | Описание |
|----------|----------|
| `ACCEPT` | Разрешить |
| `DROP` | Отклонить (без ответа) |
| `REJECT` | Отклонить (с ответом) |
| `LOG` | Записать в лог |
