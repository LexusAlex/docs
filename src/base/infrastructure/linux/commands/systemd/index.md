# systemd и службы

Управление службами, анализ загрузки, настройка системных параметров.

## Команды

| Команда | Описание |
|---------|----------|
| [systemctl](systemctl.md) | Управление службами |
| [journalctl](journalctl.md) | Чтение системных логов |
| [systemd-analyze](systemd-analyze.md) | Анализ времени загрузки |
| [hostnamectl](hostnamectl.md) | Управление именем хоста |
| [timedatectl](timedatectl.md) | Настройка времени и часового пояса |
| [localectl](localectl.md) | Настройка локали |

## Состояния служб

| Состояние | Описание |
|-----------|----------|
| `active (running)` | Работает |
| `active (exited)` | Завершила работу (oneshot) |
| `active (waiting)` | Ожидает события |
| `inactive` | Остановлена |
| `failed` | Ошибка |
| `enabled` | Автозапуск включён |
| `disabled` | Автозапуск отключён |

## Типы юнитов

| Тип | Расширение | Описание |
|-----|------------|----------|
| Service | `.service` | Служба (демон) |
| Socket | `.socket` | Сокет для активации по запросу |
| Timer | `.timer` | Планировщик (аналог cron) |
| Mount | `.mount` | Точка монтирования |
| Target | `.target` | Группа юнитов (аналог runlevel) |
