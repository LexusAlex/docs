# vmstat

**Уровень:** Средний

Отображение статистики виртуальной памяти, процессов, CPU и ввода-вывода.

## Синтаксис

```bash
vmstat [опции] [интервал [количество]]
```

## Опции

| Опция | Описание |
|-------|----------|
| `-a` | Показать активную/неактивную память |
| `-d` | Статистика по дискам |
| `-s` | Сводка статистики |
| `-S единица` | Единицы измерения (k, K, m, M) |
| `-t` | Добавить timestamp |
| `-f` | Количество созданных процессов |
| `-m` | Статистика slab |
| `-w` | Широкий формат вывода |
| `-D` | Статистика дисковой активности |

## Поля вывода

### procs (процессы)

| Поле | Описание |
|------|----------|
| `r` | Процессы, ожидающие выполнения |
| `b` | Процессы в непрерывном сне |

### memory (память)

| Поле | Описание |
|------|----------|
| `swpd` | Использованная виртуальная память |
| `free` | Свободная память |
| `buff` | Буферы |
| `cache` | Кеш |

### swap (подкачка)

| Поле | Описание |
|------|----------|
| `si` | Память, загружаемая из swap |
| `so` | Память, выгружаемая в swap |

### io (ввод-вывод)

| Поле | Описание |
|------|----------|
| `bi` | Блоки, полученные от устройств |
| `bo` | Блоки, отправленные на устройства |

### system (система)

| Поле | Описание |
|------|----------|
| `in` | Прерывания в секунду |
| `cs` | Переключения контекста в секунду |

### cpu (процессор)

| Поле | Описание |
|------|----------|
| `us` | Время пользователя |
| `sy` | Время системы |
| `id` | Время простоя |
| `wa` | Ожидание ввода-вывода |
| `st` | Время, украденное виртуальной машиной |

## Примеры

### Обновление каждые 2 секунды

```bash
vmstat 2
```

### 10 обновлений с интервалом 1 секунда

```bash
vmstat 1 10
```

### Активная/неактивная память

```bash
vmstat -a
```

### Статистика по дискам

```bash
vmstat -d
```

### Сводка

```bash
vmstat -s
```

### С timestamp

```bash
vmstat -t 2
```

### В мегабайтах

```bash
vmstat -S M
```

### Широкий формат

```bash
vmstat -w 2
```

### Статистика процессов

```bash
vmstat -f
```

### Логирование

```bash
vmstat 5 100 > vmstat.log
```

### Статистика slab

```bash
vmstat -m
```

### С использованием SI-единиц

```bash
vmstat -S m
```

## Практические сценарии

### Анализ загрузки CPU

```bash
vmstat 1 5
# procs -----------memory---------- ---swap-- -----io---- -system-- ------cpu-----
#  r  b   swpd   free   buff  cache   si   so    bi    bo   in   cs us sy id wa st
#  1  0      0 512000  64000 2048000    0    0     5    10  100  200 10  5 83  2  0
```

Если `us` + `sy` > 80% — система загружена.

### Обнаружение проблем с памятью

```bash
vmstat 2
# Если si/so постоянно > 0 — интенсивное использование swap
# Если free очень мало — возможна нехватка памяти
```

### Мониторинг ввода-вывода

```bash
vmstat -d
# Высокие bi/bo указывают на интенсивную работу с дисками
```

:::tip
Запустите `vmstat` без аргументов для получения средних значений с момента загрузки системы.
:::

:::warning
Высокие значения `wa` (>20%) указывают на проблемы с вводом-выводом, которые могут замедлять систему.
:::

### Проверка нагрузки на систему

```bash
# Значение r > количество ядер CPU означает очередь процессов
vmstat 1 | awk '$1 > 4 {print "High CPU queue:", $1}'
```
