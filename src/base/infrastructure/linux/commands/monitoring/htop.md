# htop

**Уровень:** Средний

Интерактивный мониторинг процессов с улучшенным интерфейсом по сравнению с top.

## Синтаксис

```bash
htop [опции]
```

## Опции

| Опция | Описание |
|-------|----------|
| `-d задержка` | Задержка обновления в десятых долях секунды |
| `-u пользователь` | Показать процессы пользователя |
| `-p PID` | Показать только указанные процессы |
| `-t` | Древовидный режим |
| `-s поле` | Сортировка по полю |
| `-C` | Без цвета |
| `-h` | Помощь |

## Клавиши F1-F10

| Клавиша | Действие |
|---------|----------|
| `F1` | Помощь |
| `F2` | Настройка интерфейса |
| `F3` | Поиск процесса |
| `F4` | Фильтр процессов |
| `F5` | Дерево процессов |
| `F6` | Выбор сортировки |
| `F7` | Уменьшить приоритет (nice) |
| `F8` | Увеличить приоритет (nice) |
| `F9` | Завершить процесс |
| `F10` | Выход |

## Интерактивные команды

| Клавиша | Действие |
|---------|----------|
| `t` | Древовидный вид |
| `>` | Следующее поле сортировки |
| `<` | Предыдущее поле сортировки |
| `F` | Следовать за процессом |
| `H` | Скрыть/показать потоки |
| `K` | Скрыть/показать ядра |
| `M` | Сортировка по памяти |
| `P` | Сортировка по CPU |
| `T` | Сортировка по времени |
| `l` | Показать командную строку |
| `s` | Показать системные вызовы |
| `a` | Привязaть к процессору |

## Примеры

### Запуск в древовидном режиме

```bash
htop -t
```

### Мониторинг конкретного пользователя

```bash
htop -u root
```

### Сортировка по памяти

```bash
htop -s PERCENT_MEM
```

### Мониторинг конкретных процессов

```bash
htop -p 1234,5678
```

### Запуск с задержкой обновления

```bash
htop -d 20
```

### Без цвета (для логирования)

```bash
htop -C
```

### Сортировка по CPU

```bash
htop -s PERCENT_CPU
```

### Мониторинг с фильтром

```bash
htop -u postgres
```

### Показать только определенные процессы

```bash
htop -p $(pgrep nginx)
```

## Практические сценарии

### Настройка интерфейса

1. Нажмите `F2` для входа в настройки
2. Выберите раздел "Columns"
3. Добавьте нужные столбцы
4. Сохраните настройки

### Поиск утечки памяти

1. Запустите `htop`
2. Нажмите `M` для сортировки по памяти
3. Следите за процессами с растущим потреблением
4. Используйте `F5` для просмотра дерева процессов

### Завершение процесса

1. Найдите процесс с помощью `F3` или `F4`
2. Выделите его стрелками
3. Нажмите `F9`
4. Выберите сигнал (SIGTERM — безопасно)

:::tip
htop автоматически запоминает настройки между сессиями в файле `~/.config/htop/htoprc`.
:::

:::warning
При завершении процессов через F9 по умолчанию отправляется SIGTERM. Для принудительного завершения выберите SIGKILL (9).
:::

## Преимущества перед top

- Цветной интерфейс
- Горячие клавиши для всех операций
- Древовидный вид по умолчанию
- Настройка отображения столбцов
- Визуальные индикаторы использования ресурсов
- Поддержка мыши
