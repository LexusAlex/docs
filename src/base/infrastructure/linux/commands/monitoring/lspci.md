# lspci

**Уровень:** Средний

Отображение информации о PCI-устройствах в системе.

## Синтаксис

```bash
lspci [опции]
```

## Опции

| Опция | Описание |
|-------|----------|
| `-v` | Подробный вывод |
| `-vv` | Очень подробный вывод |
| `-vvv` | Максимально подробный вывод |
| `-n` | Показать числовые коды |
| `-nn` | Показать числовые коды и имена |
| `-k` | Показать используемые модули ядра |
| `-d [vendor]:[device]` | Фильтр по ID устройства |
| `-s [[домен]:]шина:устройство[.функция]` | Фильтр по адресу |
| `-t` | Дерево устройств |
| `-m` | Машиночитаемый формат |
| `-x` | Показать hex-дамп конфигурации |
| `-xxx` | Показать полный hex-дамп |
| `-i файл` | Использовать другой файл ID |
| `-D` | Всегда показывать домен |

## Классы устройств

| Класс | Описание |
|-------|----------|
| `0200` | Сетевой контроллер |
| `0300` | Видеоконтроллер |
| `0106` | SATA-контроллер |
| `0c03` | USB-контроллер |
| `0401` | Звуковой контроллер |

## Примеры

### Список всех устройств

```bash
lspci
```

### Подробная информация

```bash
lspci -v
```

### С модулями ядра

```bash
lspci -k
```

### Числовые ID

```bash
lspci -nn
```

### Конкретное устройство

```bash
lspci -s 00:02.0 -v
```

### Фильтр по классу (видеокарты)

```bash
lspci -d ::0300
```

### Сетевые контроллеры

```bash
lspci -d ::0200
```

### Дерево устройств

```bash
lspci -t
```

### Поиск драйвера

```bash
lspci -k | grep -A3 "VGA"
```

### Hex-дамп

```bash
lspci -x -s 00:02.0
```

### Машиночитаемый формат

```bash
lspci -m
```

### Фильтр по производителю

```bash
lspci -d 8086:
# Все устройства Intel
```

### Поиск видеокарты

```bash
lspci -nn | grep -i vga
```

### USB-контроллеры

```bash
lspci -d ::0c03
```

## Практические сценарии

### Определение видеокарты

```bash
lspci -k | grep -A3 -i "vga\|3d"
```

### Проверка сетевых карт

```bash
lspci -k | grep -A3 -i "network\|ethernet"
```

### Поиск драйвера для устройства

```bash
lspci -k -s 03:00.0
```

:::tip
Используйте `lspci -nn` для получения числовых ID устройств. Это полезно при поиске драйверов на сайте производителя.
:::

:::warning
Для получения полной информации о USB-устройствах используйте `lsusb`, а не `lspci`.
:::

### Проверка поддержки VT-d/IOMMU

```bash
lspci | grep -i "iommu\|dmar"
```

### Информация о NVMe

```bash
lspci -v | grep -A10 -i "nvme\|non-volatile"
```
