# dmesg

**Уровень:** Средний

Отображение сообщений ядра (kernel ring buffer).

## Синтаксис

```bash
dmesg [опции]
```

## Опции

| Опция | Описание |
|-------|----------|
| `-T` | Читаемый формат времени |
| `-w` | Следить за новыми сообщениями |
| `-W` | Следить и ждать новых сообщений |
| `-l уровень` | Фильтр по уровню |
| `-t` | Без меток времени |
| `-C` | Очистить буфер |
| `-c` | Очистить после чтения |
| `-s размер` | Размер буфера |
| `-D` | Отключить вывод в консоль |
| `-E` | Включить вывод в консоль |
| `--facility` | Фильтр по facility |
| `-n уровень` | Установить уровень консоли |
| `--color` | Цветной вывод |

## Уровни сообщений (level)

| Уровень | Описание |
|---------|----------|
| `emerg` | Аварийные ситуации |
| `alert` | Требуется немедленное действие |
| `crit` | Критические условия |
| `err` | Ошибки |
| `warn` | Предупреждения |
| `notice` | Уведомления |
| `info` | Информационные |
| `debug` | Отладочные |

## Facility

| Facility | Описание |
|----------|----------|
| `kern` | Ядро |
| `user` | Пользовательские процессы |
| `mail` | Почта |
| `daemon` | Демоны |
| `auth` | Аутентификация |
| `syslog` | Системный лог |
| `lpr` | Печать |
| `news` | Новости |

## Примеры

### Все сообщения

```bash
dmesg
```

### С читаемым временем

```bash
dmesg -T
```

### Только ошибки

```bash
dmesg -l err
```

### Предупреждения и ошибки

```bash
dmesg -l warn,err
```

### Следить в реальном времени

```bash
dmesg -w
```

### Только ядро

```bash
dmesg --facility=kern
```

### Без меток времени

```bash
dmesg -t
```

### Последние 20 строк

```bash
dmesg | tail -20
```

### Поиск USB-устройств

```bash
dmesg | grep -i usb
```

### Ошибки дисков

```bash
dmesg | grep -i "error\|fail" | grep -i "sd\|nvme\|ata"
```

### Подключение дисков

```bash
dmesg | grep -i "sd[a-z]"
```

### Очистка буфера

```bash
dmesg -C
```

### Чтение и очистка

```bash
dmesg -c
```

### Цветной вывод

```bash
dmesg --color=always | less -R
```

### Фильтр по PID

```bash
dmesg -T | grep "\[ *1234\]"
```

## Практические сценарии

### Обнаружение аппаратных проблем

```bash
# Ошибки дисков
dmesg | grep -i "i/o error\|bad sector\|hardware error"

# Ошибки памяти
dmesg | grep -i "mce\|memory\|edac"

# Проблемы с USB
dmesg | grep -i "usb.*error\|usb.*fail"
```

### Мониторинг подключения устройств

```bash
# Следить за подключением
dmesg -w | grep -i "connect\|disconnect"
```

### Проверка драйверов

```bash
dmesg | grep -i "module\|driver\|firmware"
```

:::tip
Используйте `dmesg -T` для получения времени в читаемом формате. Без этой опции время указывается в секундах с момента загрузки.
:::

:::warning
Для очистки буфера dmesg требуются права root. Будьте осторожны — это удалит все сообщения ядра.
:::

### Анализ загрузки системы

```bash
# Время загрузки
dmesg | grep -i "linux version"

# Загрузка драйверов
dmesg | grep -i "loaded\|registered"

# Ошибки при загрузке
dmesg | grep -i "fail\|error" | head -20
```

### Мониторинг температуры

```bash
dmesg | grep -i "thermal\|temperature"
```
