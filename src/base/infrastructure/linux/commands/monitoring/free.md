# free

**Уровень:** Начинающий

Отображение информации об использовании оперативной памяти.

## Синтаксис

```bash
free [опции]
```

## Опции

| Опция | Описание |
|-------|----------|
| `-b` | В байтах |
| `-k` | В килобайтах (по умолчанию) |
| `-m` | В мегабайтах |
| `-g` | В гигабайтах |
| `--tera` | В терабайтах |
| `-h` | Человекочитаемый формат |
| `-s интервал` | Интервал обновления в секундах |
| `-c количество` | Количество обновлений |
| `-t` | Показать строку итогов |
| `-w` | Широкий формат (разделение buffers и cache) |
| `--si` | Использовать степени 1000 вместо 1024 |

## Поля вывода

| Поле | Описание |
|------|----------|
| `total` | Общий объем памяти |
| `used` | Используемая память |
| `free` | Свободная память |
| `shared` | Разделяемая память |
| `buff/cache` | Буферы и кеш |
| `available` | Доступная память |

## Примеры

### Человекочитаемый формат

```bash
free -h
```

### В мегабайтах

```bash
free -m
```

### С итоговой строкой

```bash
free -ht
```

### Обновление каждые 2 секунды

```bash
free -h -s 2
```

### 5 обновлений с интервалом 1 секунда

```bash
free -h -s 1 -c 5
```

### В гигабайтах

```bash
free -g
```

### Широкий формат

```bash
free -hw
```

### С использованием SI-единиц

```bash
free -h --si
```

### Логирование в файл

```bash
free -h -s 60 > memory.log
```

### Показать только память (без swap)

```bash
free -h | grep -v Swap
```

### Экспорт в CSV

```bash
free -m | awk 'NR==2{print $2","$3","$4","$5","$6","$7}'
```

### Мониторинг с timestamp

```bash
while true; do echo "$(date): $(free -h | grep Mem)"; sleep 5; done
```

## Практические сценарии

### Понимание buffers/cache

- **buffers** — метаданные файловой системы
- **cache** — страницы файлов в памяти
- Они освобождаются автоматически при необходимости

### Свободная vs доступная память

- **free** — память, которая вообще не используется
- **available** — память, доступная для новых приложений (включая reclaimable cache)

```bash
free -h
#               total        used        free      shared  buff/cache   available
# Mem:           15Gi       5.2Gi       3.1Gi       512Mi       7.1Gi       9.1Gi
# Swap:         2.0Gi          0B       2.0Gi
```

Здесь `available` (9.1Gi) больше `free` (3.1Gi), потому что часть cache может быть освобождена.

:::tip
Используйте `available` вместо `free` для оценки доступной памяти. Это более точный показатель.
:::

:::warning
Если `free` памяти мало, но `available` много — это нормально. Система использует свободную память для кеширования для ускорения работы.
:::

### Мониторинг утечек памяти

```bash
# Логирование каждые 5 минут
free -m -s 300 -c 288 > /var/log/memory_$(date +%Y%m%d).log
```

### Проверка использования swap

```bash
free -h | awk '/Swap/{printf "Swap usage: %.1f%%\n", $3/$2*100}'
```

## Связки с другими командами

```bash
# Процент использования памяти
free -m | awk '/Mem:/ {printf "Usage: %.1f%%\n", $3/$2*100}'

# Предупреждение при использовании памяти более 80%
free -m | awk '/Mem:/ {if ($3/$2 > 0.8) print "WARNING: High memory usage"}'

# Мониторинг памяти каждые 5 секунд
watch -n 5 'free -h'

# Проверка использования swap
free -m | awk '/Swap:/ {if ($3>0) print "Swap in use:", $3"M"}'

# Детальная информация о памяти (buffers, cached, active, inactive)
cat /proc/meminfo | grep -E "^(MemTotal|MemFree|Buffers|Cached|Active|Inactive)"

# Отправить алерт при нехватке памяти
free -m | awk '/Mem:/ {if ($3/$2 > 0.9) system("echo \"Memory critical: " int($3/$2*100) "%\" | mail -s ALERT admin@example.com")}'

# Логирование использования памяти с временной меткой
echo "$(date '+%Y-%m-%d %H:%M'): $(free -m | awk '/Mem:/ {printf "%.0f%%", $3/$2*100}')" >> /var/log/mem_history.log

# Показать топ-5 процессов по использованию памяти
ps aux --sort=-%mem | head -6 | awk '{printf "%-10s %-6s %-6s %s\n", $1, $4"%", $6/1024"MB", $11}'

# Сравнить использование памяти сейчас и 5 минут назад
free -m | awk '/Mem:/ {print $3}' > /tmp/mem_now.txt; sleep 300; echo "5 min ago: $(cat /tmp/mem_now.txt)MB, now: $(free -m | awk '/Mem:/ {print $3}')MB"

# Проверить, есть ли утечки памяти (рост RSS у процессов)
ps -eo pid,rss,cmd --sort=-rss | head -10 | awk '{printf "%-8s %-10s %s\n", $1, $2/1024"MB", $3}'
```
