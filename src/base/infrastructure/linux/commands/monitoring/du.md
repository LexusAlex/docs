# du

**Уровень:** Начинающий

Оценка использования дискового пространства файлами и каталогами.

## Синтаксис

```bash
du [опции] [файл...]
```

## Опции

| Опция | Описание |
|-------|----------|
| `-h` | Человекочитаемый формат |
| `-s` | Только итоговый размер |
| `-a` | Показать размеры файлов |
| `-d глубина` | Глубина рекурсии |
| `--max-depth=N` | Максимальная глубина |
| `-x` | Только текущая файловая система |
| `--exclude=паттерн` | Исключить файлы/каталоги |
| `--include=паттерн` | Включить только совпадающие |
| `-b` | Размер в байтах |
| `-k` | В килобайтах (по умолчанию) |
| `-m` | В мегабайтах |
| `-S` | Не включать вложенные каталоги |
| `-L` | Следовать символическим ссылкам |
| `--apparent-size` | Показать apparent size |
| `--time` | Показать время изменения |
| `-c` | Показать итог |

## Примеры

### Размер текущего каталога

```bash
du -sh .
```

### Размеры файлов и каталогов

```bash
du -ah
```

### Глубина 1 уровень

```bash
du -h --max-depth=1
```

### Итоговый размер

```bash
du -sh /home/*
```

### Исключить каталоги

```bash
du -sh --exclude='.git' --exclude='node_modules'
```

### Только текущая файловая система

```bash
du -xsh /*
```

### Сортировка по размеру

```bash
du -h --max-depth=1 | sort -hr
```

### Размер конкретного файла

```bash
du -h file.txt
```

### В мегабайтах

```bash
du -sm /var/log/*
```

### С временем изменения

```bash
du -h --time --max-depth=1
```

### Размер без вложенных

```bash
du -Sh /home
```

### Найти большие файлы

```bash
du -ah / | sort -rh | head -20
```

### Размер с глубиной 2

```bash
du -h -d 2 /var
```

### Показать итог

```bash
du -shc /home/*
```

## Практические сценарии

### Поиск самых больших каталогов

```bash
du -h --max-depth=1 / | sort -hr | head -10
```

### Очистка места

```bash
# Найти большие каталоги
du -sh /var/log/* | sort -hr | head -5

# Найти старые файлы
find /tmp -type f -mtime +30 -exec du -sh {} \; | sort -hr
```

### Мониторинг роста

```bash
du -sh /var/log > /tmp/size_$(date +%Y%m%d).txt
```

:::tip
Используйте `du -sh --max-depth=1` для быстрого обзора размеров каталогов верхнего уровня.
:::

:::warning
`du` показывает размер на диске, а не фактический размер файлов. Используйте `--apparent-size` для получения реального размера.
:::

### Анализ использования пространства

```bash
#!/bin/bash
echo "Top 10 largest directories:"
du -h --max-depth=1 / 2>/dev/null | sort -hr | head -10
```

### Проверка перед резервным копированием

```bash
du -sh /home/user/Documents
# Оценка размера для резервной копии
```

## Связки с другими командами

```bash
# Топ-10 самых больших каталогов в текущей директории
du -sh * | sort -rh | head -10

# Самые большие каталоги с логами
du -sh /var/log/* | sort -rh | head -5

# Найти каталоги размером более 10 ГБ
du -sh * | awk '$1 ~ /G/ && $1+0 > 10 {print}'

# Самые большие лог-файлы
find . -type f -name "*.log" -exec du -sh {} + | sort -rh | head

# Размер проекта без node_modules
du -sh --exclude='node_modules' . | tail -1

# Размеры домашних каталогов пользователей
du -sh /home/* | sort -rh | column -t

# Сравнить размер директории до и после очистки
echo "Before: $(du -sh /var/log | awk '{print $1}')"; find /var/log -name "*.gz" -delete; echo "After: $(du -sh /var/log | awk '{print $1}')"

# Найти файлы, изменённые за последние 24 часа, и посчитать их общий размер
find . -type f -mtime -1 -exec du -sh {} + | awk '{sum+=$1} END {print sum " total"}'

# Показать размеры подкаталогов /var, исключая /var/log
du -sh --exclude='log' /var/* | sort -rh | head -10

# Автоматическая очистка при нехватке места (если < 5 ГБ свободно)
AVAIL=$(df -h / | awk 'NR==2 {print $4}'); if [[ "$AVAIL" == *G* ]] && (( ${AVAIL%G} < 5 )); then find /tmp -type f -mtime +7 -delete; echo "Cleaned /tmp"; fi
```
