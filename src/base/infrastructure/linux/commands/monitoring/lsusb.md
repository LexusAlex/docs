# lsusb

Отображение информации о USB-устройствах в системе.

## Синтаксис

```bash
lsusb [опции]
```

## Опции

| Опция | Описание |
|-------|----------|
| `-v` | Подробный вывод |
| `-d [vendor]:[product]` | Фильтр по ID устройства |
| `-s [[шаг]:][устройство[.интерфейс]]` | Фильтр по адресу |
| `-t` | Дерево USB-устройств |
| `-D устройство` | Показать только указанное устройство |
| `-V` | Версия usbutils |

## Поля вывода

| Поле | Описание |
|------|----------|
| `Bus` | Номер USB-шины |
| `Device` | Номер устройства |
| `ID` | Vendor ID:Product ID |
| `Description` | Описание устройства |

## Примеры

### Список всех USB-устройств

```bash
lsusb
```

### Подробная информация

```bash
lsusb -v
```

### Дерево устройств

```bash
lsusb -t
```

### Конкретное устройство

```bash
lsusb -s 001:003
```

### Фильтр по производителю

```bash
lsusb -d 8086:
# Все устройства Intel
```

### Фильтр по ID устройства

```bash
lsusb -d 046d:c077
```

### Подробная информация об устройстве

```bash
lsusb -v -d 046d:c077
```

### Дерево с подробностями

```bash
lsusb -tv
```

### Поиск конкретного устройства

```bash
lsusb | grep -i "storage\|flash"
```

### Информация о хабе

```bash
lsusb -v -s 001:001
```

### Все устройства в формате ID

```bash
lsusb | awk '{print $6}'
```

### Проверка USB 3.0

```bash
lsusb -t | grep "5000M"
```

### Поиск устройства по имени

```bash
lsusb | grep -i "camera\|webcam"
```

### Версия usbutils

```bash
lsusb -V
```

## Практические сценарии

### Определение скорости USB

```bash
lsusb -t
# Ищите "480M" (USB 2.0), "5000M" (USB 3.0), "10000M" (USB 3.1)
```

### Поиск драйвера для USB-устройства

```bash
# Найдите ID устройства
lsusb
# Bus 001 Device 003: ID 046d:c077 Logitech, Inc. M105 Optical Mouse

# Найдите драйвер
dmesg | grep "046d:c077"
```

### Проверка подключенных устройств

```bash
lsusb | wc -l
# Количество USB-устройств
```

:::tip
Используйте `lsusb -t` для визуализации иерархии USB-хабов и устройств с указанием скоростей.
:::

:::warning
Для получения полной информации о PCI-устройствах используйте `lspci`, а не `lsusb`.
:::

### Мониторинг подключения устройств

```bash
# Следить за подключением
dmesg -w | grep -i usb

# Или
watch -n 1 lsusb
```

### Проверка питания USB

```bash
lsusb -v | grep -i "maxpower"
```

## См. также

- `lspci` — информация о PCI-устройствах
- `usb-devices` — подробная информация об USB
- `dmesg` — сообщения ядра о подключении
- `/sys/bus/usb/` — файловая система sysfs для USB
