# iostat

Статистика ввода-вывода для устройств и процессоров.

## Синтаксис

```bash
iostat [опции] [интервал [количество]]
```

## Опции

| Опция | Описание |
|-------|----------|
| `-c` | Показать только статистику CPU |
| `-d` | Показать только статистику устройств |
| `-x` | Расширенная статистика |
| `-p [устройство]` | Статистика по разделам |
| `-t` | Добавить timestamp |
| `-k` | В килобайтах |
| `-m` | В мегабайтах |
| `-h` | Человекочитаемый формат |
| `-N` | Показать имена устройств |
| `-j ID` | Формат идентификатора (LABEL, UUID) |
| `--human` | Человекочитаемые размеры |

## Поля вывода (расширенный режим -x)

### Поля устройств

| Поле | Описание |
|------|----------|
| `rrqm/s` | Считанных запросов в секунду, объединённых |
| `wrqm/s` | Записанных запросов в секунду, объединённых |
| `r/s` | Считанных операций в секунду |
| `w/s` | Записанных операций в секунду |
| `rkB/s` | Считанных килобайт в секунду |
| `wkB/s` | Записанных килобайт в секунду |
| `avgrq-sz` | Средний размер запроса |
| `avgqu-sz` | Средняя длина очереди |
| `await` | Среднее время ожидания (мс) |
| `svctm` | Среднее время обслуживания (мс) |
| `%util` | Процент использования устройства |

### Поля CPU

| Поле | Описание |
|------|----------|
| `%user` | Время пользователя |
| `%nice` | Время с nice |
| `%system` | Время системы |
| `%iowait` | Ожидание ввода-вывода |
| `%steal` | Украденное время |
| `%idle` | Время простоя |

## Примеры

### Статистика устройств каждые 2 секунды

```bash
iostat -d 2
```

### Расширенная статистика

```bash
iostat -x
```

### Только CPU

```bash
iostat -c
```

### В мегабайтах

```bash
iostat -dm
```

### С timestamp

```bash
iostat -xt
```

### Статистика по разделам

```bash
iostat -p sda
```

### 5 обновлений с интервалом 1 секунда

```bash
iostat -x 1 5
```

### Человекочитаемый формат

```bash
iostat -x --human
```

### Конкретное устройство

```bash
iostat -x sda sdb
```

### Логирование

```bash
iostat -xt 5 100 > iostat.log
```

### С именами устройств

```bash
iostat -xN
```

### Комбинированный вывод

```bash
iostat -cdxt 2
```

## Практические сценарии

### Определение узкого места дисковой подсистемы

```bash
iostat -x 1
# Если %util > 90% — диск перегружен
# Если await > 10 мс для SSD — проблема
```

### Анализ времени ожидания

```bash
iostat -x | awk '$10 > 10 {print "Slow device:", $1, "await:", $10}'
```

### Мониторинг в реальном времени

```bash
iostat -xmt 2
```

:::tip
Используйте `%util` для оценки загрузки диска. Значения > 90% указывают на перегрузку, особенно для SSD.
:::

:::warning
Для NVMe SSD значения `%util` могут быть неточными из-за параллельных операций. Ориентируйтесь на `await` и `avgqu-sz`.
:::

### Сравнение устройств

```bash
iostat -dx | sort -k7 -nr
# Сортировка по %util
```

### Проверка IOPS

```bash
iostat -dx | awk 'NR>3 {print $1, "read:", $4, "write:", $5, "IOPS:", $4+$5}'
```
