# Мониторинг системы

Информация о системе: загрузка CPU, использование памяти, дисковое пространство, блочные устройства.

## Команды

| Команда | Описание |
|---------|----------|
| [top](top.md) | Процессы в реальном времени |
| [htop](htop.md) | Интерактивный монитор процессов |
| [free](free.md) | Использование оперативной памяти |
| [vmstat](vmstat.md) | Статистика виртуальной памяти |
| [iostat](iostat.md) | Статистика ввода-вывода |
| [df](df.md) | Дисковое пространство |
| [du](du.md) | Размер файлов и директорий |
| [uptime](uptime.md) | Время работы и загрузка |
| [uname](uname.md) | Информация о ядре и системе |
| [lspci](lspci.md) | PCI-устройства |
| [lsusb](lsusb.md) | USB-устройства |
| [lscpu](lscpu.md) | Информация о процессоре |
| [dmesg](dmesg.md) | Сообщения ядра |

::: tip
Команда `lsblk` описана в разделе [Диски и монтирование](/base/infrastructure/linux/commands/disks-and-mount/lsblk).
:::
