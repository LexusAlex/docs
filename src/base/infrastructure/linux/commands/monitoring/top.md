# top

**Уровень:** Средний

Интерактивная утилита для мониторинга системных процессов в реальном времени.

## Синтаксис

```bash
top [опции]
```

## Опции

| Опция | Описание |
|-------|----------|
| `-b` | Пакетный режим (для перенаправления в файл) |
| `-d задержка` | Интервал обновления в секундах |
| `-u пользователь` | Показать процессы только указанного пользователя |
| `-p PID` | Мониторить только указанные процессы |
| `-n количество` | Количество обновлений и выход |
| `-o поле` | Сортировка по указанному полю |
| `-H` | Показать отдельные потоки |

## Поля вывода

| Поле | Описание |
|------|----------|
| `VIRT` | Виртуальная память процесса |
| `RES` | Резидентная (физическая) память |
| `SHR` | Разделяемая память |
| `%CPU` | Использование процессора |
| `%MEM` | Использование оперативной памяти |
| `NI` | Приоритет (nice) |
| `TIME+` | Общее время CPU |

## Интерактивные команды

| Клавиша | Действие |
|---------|----------|
| `k` | Завершить процесс (отправить сигнал) |
| `r` | Изменить приоритет процесса (renice) |
| `M` | Сортировка по использованию памяти |
| `P` | Сортировка по использованию CPU |
| `T` | Сортировка по времени выполнения |
| `1` | Показать все ядра CPU |
| `c` | Показать полную командную строку |
| `h` | Помощь |
| `q` | Выход |
| `f` | Выбор отображаемых полей |
| `H` | Показать потоки |
| `V` | Дерево процессов |

## Примеры

### Запуск с интервалом обновления 2 секунды

```bash
top -d 2
```

### Мониторинг процессов пользователя

```bash
top -u alex
```

### Пакетный режим для логирования

```bash
top -b -n 5 > top_output.txt
```

### Мониторинг конкретного процесса

```bash
top -p 1234
```

### Сортировка по памяти

```bash
top -o %MEM
```

### Показать все ядра CPU

```bash
top -1
```

### Мониторинг с полными командами

```bash
top -c
```

### Экспорт статистики каждые 5 секунд

```bash
top -b -d 5 -n 10 > stats.log
```

### Мониторинг потоков

```bash
top -H
```

### Сортировка по PID

```bash
top -o PID
```

## Практические сценарии

### Поиск процесса, потребляющего много памяти

1. Запустите `top`
2. Нажмите `M` для сортировки по памяти
3. Процессы с наибольшим потреблением будут вверху

### Завершение зависшего процесса

1. Найдите процесс в top
2. Нажмите `k`
3. Введите PID процесса
4. Выберите сигнал (по умолчанию 15 — SIGTERM)

### Мониторинг в фоновом режиме

```bash
top -b -d 60 > /var/log/top_monitor.log &
```

:::tip
Используйте `top -b -n 1` для получения снимка состояния системы без интерактивного режима.
:::

:::warning
При использовании `k` для завершения процессов будьте осторожны с системными процессами.
:::

## Связки с другими командами

```bash
# Однократный снимок состояния системы (первые 20 строк)
top -bn1 | head -20

# Подсчитать количество процессов по имени команды
top -bn1 | awk 'NR>7 {print $12}' | sort | uniq -c | sort -rn

# Процессы, использующие более 50% CPU
top -bn1 | awk 'NR>7 && $9>50 {print $12, $9"%"}'

# Топ-15 процессов по использованию памяти (один снимок)
top -bn1 -o %MEM | head -15

# Обновлять вывод top каждые 5 секунд
watch -n 5 'top -bn1 | head -15'

# Сводка по задачам: общее количество, запущенные, спящие
top -bn1 | grep "Tasks" | awk '{print "Total:", $2, "Running:", $4, "Sleeping:", $6}'

# Логирование топ-10 процессов по CPU каждые 10 секунд
while true; do top -bn1 | head -8 | tail -1; top -bn1 | sort -k9 -nr | head -10; sleep 10; done

# Найти зомби-процессы через top
top -bn1 | awk 'NR>7 && $8=="Z" {print $1, $12}'

# Экспорт статистики CPU в CSV для анализа
top -bn1 | awk 'NR==3 {print $2","$4","$6","$8","$10}' > cpu_stats.csv

# Мониторинг конкретного процесса с автоматическим алертом
watch -n 5 'top -bn1 -p $(pgrep -d, nginx) | tail -n +7 | awk "\$9>80 {print \"ALERT:\", \$12, \"CPU:\", \$9}"'
```
