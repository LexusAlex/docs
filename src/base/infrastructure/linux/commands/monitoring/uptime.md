# uptime

**Уровень:** Начинающий

Показывает время работы системы и среднюю нагрузку.

## Синтаксис

```bash
uptime [опции]
```

## Опции

| Опция | Описание |
|-------|----------|
| `-p` | Красивый вывод (человекочитаемый) |
| `-s` | Дата и время запуска системы |
| `-h` | Помощь |

## Поля вывода

| Поле | Описание |
|------|----------|
| Текущее время | Текущее время на сервере |
| Время работы | Сколько времени система работает |
| Количество пользователей | Число залогиненных пользователей |
| Средняя нагрузка | Load averages за 1, 5 и 15 минут |

## Средняя нагрузка (Load Averages)

Три числа показывают среднюю нагрузку за:
- **1 минуту** — текущая нагрузка
- **5 минут** — средняя нагрузка
- **15 минут** — долгосрочная нагрузка

### Интерпретация значений

| Значение | Описание |
|----------|----------|
| < 0.7 × ядра | Система не загружена |
| 0.7–1.0 × ядра | Нормальная нагрузка |
| > 1.0 × ядра | Система загружена |
| > ядра × 2 | Серьёзная перегрузка |

## Примеры

### Базовый вывод

```bash
uptime
# 14:30:15 up 10 days, 3:45, 5 users, load average: 0.50, 0.75, 0.60
```

### Красивый вывод

```bash
uptime -p
# up 10 days, 3 hours, 45 minutes
```

### Время запуска

```bash
uptime -s
# 2024-01-15 10:45:30
```

### Только load average

```bash
uptime | awk -F'load average:' '{print $2}'
```

### Проверка перегрузки

```bash
uptime | awk '{if ($10 > 4) print "High load:", $10}'
```

### С timestamp

```bash
echo "$(date): $(uptime)"
```

### Логирование нагрузки

```bash
while true; do uptime >> /var/log/load.log; sleep 60; done
```

### Проверка количества ядер

```bash
nproc
# 4
uptime
# Сравните load average с количеством ядер
```

### Мониторинг в реальном времени

```bash
watch -n 5 uptime
```

### Автоматический алерт

```bash
#!/bin/bash
load=$(uptime | awk '{print $10}' | sed 's/,//')
cores=$(nproc)
if (( $(echo "$load > $cores * 2" | bc -l) )); then
    echo "High load: $load" | mail -s "Load Alert" admin@example.com
fi
```

### Проверка времени работы

```bash
uptime -p | grep -q "days" && echo "System running for days" || echo "Recently rebooted"
```

## Практические сценарии

### Определение проблем с производительностью

1. Проверьте `uptime` для общей нагрузки
2. Если load average > количество ядер × 2 — проблема
3. Сравните 1, 5 и 15 минутные значения:
   - Растущая нагрузка: 1 мин > 5 мин > 15 мин
   - Снижающаяся нагрузка: 1 мин < 5 мин < 15 мин

### Проверка после перезагрузки

```bash
uptime -p
# Если "up 0 minutes" — система только что перезагружена
```

:::tip
Сравнивайте load average с количеством ядер CPU (`nproc`). Идеальная нагрузка — от 0 до количества ядер.
:::

:::warning
Load average учитывает не только CPU, но и процессы, ожидающие ввода-вывод. Высокая нагрузка может быть вызвана медленными дисками.
:::
