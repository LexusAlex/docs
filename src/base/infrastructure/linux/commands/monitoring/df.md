# df

Отображение информации об использовании дискового пространства файловых систем.

## Синтаксис

```bash
df [опции] [файл...]
```

## Опции

| Опция | Описание |
|-------|----------|
| `-h` | Человекочитаемый формат |
| `-H` | Формат с степенями 1000 |
| `-k` | В килобайтах (по умолчанию) |
| `-m` | В мегабайтах |
| `-g` | В гигабайтах |
| `-T` | Показать тип файловой системы |
| `-i` | Показать информацию об inodes |
| `-a` | Показать все файловые системы |
| `-x тип` | Исключить тип файловой системы |
| `-t тип` | Показать только указанный тип |
| `--total` | Добавить строку итогов |
| `--sync` | Синхронизировать перед выводом |
| `--no-sync` | Не синхронизировать |
| `-B размер` | Размер блока |

## Поля вывода

| Поле | Описание |
|------|----------|
| `Filesystem` | Устройство или файловая система |
| `1K-blocks` | Размер в блоках |
| `Used` | Использовано |
| `Available` | Доступно |
| `Use%` | Процент использования |
| `Mounted on` | Точка монтирования |

## Примеры

### Человекочитаемый формат

```bash
df -h
```

### С типом файловой системы

```bash
df -hT
```

### Информация об inodes

```bash
df -i
```

### Конкретная файловая система

```bash
df -h /home
```

### Исключить tmpfs

```bash
df -h -x tmpfs
```

### Только ext4

```bash
df -h -t ext4
```

### С итогами

```bash
df -h --total
```

### В мегабайтах

```bash
df -m
```

### Все файловые системы

```bash
df -ha
```

### По точке монтирования

```bash
df -h / /home /var
```

### Без заголовка

```bash
df -h | tail -n +2
```

### Сортировка по использованию

```bash
df -h | sort -k5 -nr
```

### Проверка конкретного раздела

```bash
df -hT /dev/sda1
```

## Практические сценарии

### Поиск переполненных разделов

```bash
df -h | awk '$5 > 80 {print "Warning:", $6, "is", $5, "full"}'
```

### Мониторинг inodes

```bash
df -i | awk '$5 > 80 {print "Low inodes:", $6}'
```

### Проверка свободного места

```bash
df -h / | awk 'NR==2 {print $4, "available on /"}'
```

:::tip
Используйте `df -hT` для получения типа файловой системы вместе с размерами. Это полезно при работе с разными типами разделов.
:::

:::warning
Раздел может быть заполнен не только данными, но и inodes. Проверяйте `df -i` при ошибках "No space left on device".
:::

### Логирование использования дисков

```bash
df -h > /var/log/disk_usage_$(date +%Y%m%d).log
```

### Автоматическая проверка

```bash
#!/bin/bash
df -h | awk 'NR>1 && $5+0 > 90 {print "ALERT:", $6, $5, "full"}'
```

## Связки с другими командами

```bash
# Найти разделы, заполненные более чем на 80%
df -h | awk 'NR>1 {gsub(/%/,"",$5); if($5>80) print $6, $5"%"}'

# Физические диски, отсортированные по использованию
df -h | grep -E "^/dev" | awk '{print $5, $6}' | sort -rn

# Проверить использование inodes более 80%
df -i | awk 'NR>1 && $5>80 {print $6, "inodes:", $5}'

# Мониторинг использования дисков каждую минуту
watch -n 60 'df -h | grep -E "^/dev"'

# Общий объём использования всех дисков
df -h --total | tail -1

# Форматированный вывод в виде таблицы
df -h | column -t

# Отправить алерт в Slack, если диск заполнен более 90%
df -h | awk 'NR>1 {gsub(/%/,"",$5); if($5>90) print $6, $5"%"}' | while read line; do curl -X POST -H 'Content-type: application/json' --data "{\"text\":\"DISK ALERT: $line\"}" "$SLACK_WEBHOOK"; done

# Сравнить использование дисков сейчас и час назад
df -h > /tmp/df_now.txt; sleep 3600; diff /tmp/df_now.txt <(df -h)

# Найти все точки монтирования с менее чем 1 ГБ свободного места
df -h | awk 'NR>1 && $4~/G/ && $4+0 < 1 {print $6, $4, "left"}'

# Логирование использования дисков с временной меткой
echo "=== $(date) ===" >> /var/log/disk_history.log; df -h >> /var/log/disk_history.log
```
