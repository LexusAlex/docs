# apropos

**Уровень:** Средний

Поиск man-страниц по описанию. Эквивалентен `man -k`.

## Синтаксис

```bash
apropos [опции] ключевое слово [ключевое слово...]
```

## Опции

| Опция | Описание |
|-------|----------|
| `-e` | Точное совпадение (все слова должны присутствовать) |
| `-a` | Все ключевые слова должны совпадать (логическое И) |
| `-r` | Использовать регулярное выражение |
| `-w` | Использовать подстановочные знаки (wildcard) |
| `-s список` | Ограничить поиск секциями |
| `--regex` | Использовать regex |

## Примеры

### Простой поиск

```bash
apropos "copy file"
```

### Точное совпадение

```bash
apropos -e "network configuration"
```

### Все слова должны совпадать

```bash
apropos -a "copy" "file"
```

### Регулярное выражение

```bash
apropos -r "^zip"
```

### Поиск по секции

```bash
apropos -s 1 "compress"
```

### Поиск целых слов

```bash
apropos -w "mount"
```

### Несколько секций

```bash
apropos -s "1,8" "user"
```

### Подстановочные знаки

```bash
apropos --wildcard "net*"
```

### Поиск инструментов архивации

```bash
apropos "archive"
```

### Поиск команд мониторинга

```bash
apropos "monitor" "system"
```

## Практические сценарии

### Найти команду по описанию

```bash
apropos "change file permission"
```

### Найти все команды для работы с сетью

```bash
apropos "network"
```

### Найти команды длясжатия

```bash
apropos "compress"
```

### Поиск инструментов для бэкапа

```bash
apropos "backup" "restore"
```

### Найти утилиты для мониторинга

```bash
apropos "monitor" "process" "system"
```

### Поиск по regex

```bash
apropos -r "^(list|show).*file"
```

## Обновление базы whatis

```bash
# Обновить базу данных man
sudo mandb

# Для систем с makewhatis
sudo makewhatis
```

:::tip
`apropos` ищет по базе данных `whatis`. Если поиск не даёт результатов, обновите базу через `sudo mandb`.
:::

:::warning
Результаты `apropos` зависят от установленных man-страниц. Если пакет не установлен, его команды не будут найдены.
:::
