# info

**Уровень:** Средний

Просмотр документации в формате GNU Info. Предоставляет структурированную документацию с навигацией по узлам.

## Синтаксис

```bash
info [опции] [тема]
```

## Опции

| Опция | Описание |
|-------|----------|
| `-f файл` | Открытьопределённный инфо-файл |
| `-n узел` | Открытьопределённный узел |
| `-o файл` | Вывести в файл |
| `--subnodes` | Показать подузлы |
| `--vi-keys` | Использовать клавиши vi |

## Навигация в info

| Клавиша | Действие |
|---------|----------|
| `Space` / `Backspace` | Прокрутка вниз / вверх |
| `n` / `p` | Следующий / предыдущий узел |
| `u` | Родительский узел |
| `l` | Вернуться к предыдущей позиции |
| `d` | Главное меню (Top) |
| `g` | Перейти к узлу по имени |
| `m имя` | Выбрать пункт меню |
| `f ссылка` / `Enter` | Перейти по ссылке |
| `Tab` | Следующая ссылка |
| `/шаблон` | Поиск |
| `q` | Выход |

## Примеры

### Информация о команде

```bash
info coreutils
```

### Конкретный узел

```bash
info grep
```

### Открытьопределённный файл

```bash
info -f /usr/share/info/gcc.info
```

### Вывод в текст

```bash
info --output=coreutils.txt coreutils
```

### С подузлами

```bash
info --subnodes gcc
```

### Просмотр конкретного узла

```bash
info -n "Introduction" bash
```

### Выводопределённного раздела

```bash
info -o bash-invocation.txt -n "Invoking Bash" bash
```

## Практические сценарии

### Изучение утилит GNU

```bash
info coreutils
info bash
info gcc
```

### Сравнение с man

```bash
# man — краткая справка
man ls

# info — подробная документация с примерами
info coreutils 'ls invocation'
```

## Структура info-файлов

```
Узел Top
├── Узел 1: Основы
│   ├── Узел 1.1: Введение
│   └── Узел 1.2: Примеры
└── Узел 2: Продвинутое
```

## info vs man

| Параметр | man | info |
|----------|-----|------|
| Формат | troff | Texinfo |
| Структура | Плоская | Иерархическая |
| Навигация | Линейная | Гипертекстовая |
| Подробность | Краткая | Подробная |

## Дополнительные примеры

### Просмотр всех узлов команды

```bash
info --subnodes coreutils
```

### Вывод в текстовый файл

```bash
info --output=bash_info.txt bash
```

### Открытие конкретного узла

```bash
info -n "Invoking Grep" grep
```

### Просмотр с клавишами vi

```bash
info --vi-keys bash
```

### Список всех info-файлов

```bash
ls /usr/share/info/
```

### Просмотр в неинтерактивном режиме

```bash
info --output=- coreutils | head -50
```

## Подробная таблица навигации

| Клавиша | Действие | Примечание |
|---------|----------|------------|
| `Space` | Прокрутка вниз | Одна страница |
| `Backspace` | Прокрутка вверх | Одна страница |
| `n` | Следующий узел | На том же уровне |
| `p` | Предыдущий узел | На том же уровне |
| `u` | Родительский узел | На уровень выше |
| `l` | Назад | К предыдущей позиции |
| `d` | Главное меню | Top node |
| `g имя` | Перейти к узлу | По имени |
| `m имя` | Пункт меню | Выбор из меню |
| `f ссылка` | Перейти по ссылке | Или `Enter` |
| `Tab` | Следующая ссылка | Циклически |
| `/шаблон` | Поиск | Вперёд |
| `}` | Следующее совпадение | После поиска |
| `{` | Предыдущее совпадение | После поиска |
| `q` | Выход | Закрыть info |
| `?` | Справка | Помощь по навигации |

## Сравнение: info vs man vs --help

| Критерий | `info` | `man` | `--help` |
|----------|--------|-------|----------|
| Подробность | Максимальная | Средняя | Минимальная |
| Структура | Иерархическая | Плоская | Плоская |
| Примеры | Много | Немного | Редко |
| Навигация | Гипертекст | Линейная | Нет |
| Доступность | Не для всех команд | Почти для всех | Для всех |
| Формат | Texinfo | troff | Текст |

## Практические сценарии

### Изучение конкретной опции команды

```bash
info coreutils 'ls invocation'
# Найти раздел с нужной опцией
```

### Поиск по теме

```bash
info --subnodes bash
# Просмотреть все подразделы
```

### Создание шпаргалки

```bash
info --output=- coreutils 'chmod invocation' > chmod_cheat.txt
```

### Сравнение документации

```bash
# Краткая справка
whatis chmod

# Подробная man-страница
man chmod

# Максимальная документация
info coreutils 'chmod invocation'
```

:::
