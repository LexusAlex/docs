# man

Система просмотра справочных страниц (manual). Основной источник документации в Linux.

## Синтаксис

```bash
man [секция] команда
man [опции] [команда]
```

## Секции справки

| Секция | Содержимое |
|--------|------------|
| `1` | Пользовательские команды |
| `2` | Системные вызовы |
| `3` | Библиотечные функции |
| `4` | Файлы устройств |
| `5` | Форматы файлов |
| `6` | Игры |
| `7` | Разное (стандарты, соглашения) |
| `8` | Команды администратора |

## Опции

| Опция | Описание |
|-------|----------|
| `-k ключевое слово` | Поиск по описанию (apropos) |
| `-f команда` | Краткое описание (whatis) |
| `-a` | Показать все страницы из всех секций |
| `-w` | Показать путь к man-файлу |
| `-S список` | Ограничить поиск секциями |
| `-P пейджер` | Указать пейджер |

## Навигация внутри man

| Клавиша | Действие |
|---------|----------|
| `Space` / `Page Down` | Следующая страница |
| `b` / `Page Up` | Предыдущая страница |
| `j` / `↓` | Строка вниз |
| `k` / `↑` | Строка вверх |
| `g` / `G` | Начало / конец документа |
| `/шаблон` | Поиск вперёд |
| `?шаблон` | Поиск назад |
| `n` / `N` | Следующее / предыдущее совпадение |
| `q` | Выход |

## Примеры

### Открыть man-страницу

```bash
man ls
```

### Страница изопределённной секции

```bash
man 5 crontab
man 2 open
```

### Поиск по ключевому слову

```bash
man -k "copy file"
```

### Краткое описание

```bash
man -f ls
```

### Все страницы для команды

```bash
man -a printf
```

### Показать путь к man-файлу

```bash
man -w passwd
```

### Указать пейджер

```bash
MANPAGER=less man ls
```

### Вывод в текстовый файл

```bash
man ls | col -bx > ls-man.txt
```

### Просмотр формата файла

```bash
man 5 passwd
man 5 sshd_config
```

## Практические сценарии

### Быстрый поиск нужной команды

```bash
man -k "network" | grep -i "config"
```

### Создание cheatsheet

```bash
for cmd in ls grep find awk; do
  echo "=== $cmd ===" && man -f "$cmd"
done
```

### Проверка наличия man-страницы

```bash
man -w mycommand > /dev/null 2>&1 && echo "Есть" || echo "Нет"
```

## Переменные окружения

| Переменная | Описание |
|------------|----------|
| `MANPATH` | Путь к man-страницам |
| `MANPAGER` | Пейджер для просмотра |
| `LANG` | Язык man-страниц |

:::tip
Используйте `man -k` (или `apropos`) когда не знаете точное имя команды. Это поиск по описанию.
:::

:::warning
На минимальных установках man-страницы могут отсутствовать. Установите пакет `man-db` и `manpages` для полной документации.
:::
