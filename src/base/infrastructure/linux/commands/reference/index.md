# Справка и документация

Получение информации о командах, их параметрах и использовании.

## Команды

| Команда | Описание |
|---------|----------|
| [man](man.md) | Полное руководство по команде |
| [info](info.md) | Info-документация (гипертекстовая) |
| [apropos](apropos.md) | Поиск команд по ключевому слову |
| [whatis](whatis.md) | Краткое описание команды |
| [tldr](tldr.md) | Упрощённая справка с примерами |

## Когда что использовать

| Задача | Команда |
|--------|---------|
| Полная документация | `man command` |
| Быстрая справка | `command --help` |
| Найти команду по описанию | `apropos keyword` |
| Краткое описание | `whatis command` |
| Примеры использования | `tldr command` |
| О встроенных командах bash | `help command` |

## Навигация в man

| Клавиша | Действие |
|---------|----------|
| `q` | Выход |
| `Space` | Следующая страница |
| `b` | Предыдущая страница |
| `/pattern` | Поиск вперёд |
| `n` | Следующее совпадение |
| `N` | Предыдущее совпадение |
| `g` | Начало документа |
| `G` | Конец документа |
