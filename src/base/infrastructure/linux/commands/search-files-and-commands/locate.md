# locate

Быстрый поиск файлов по базе данных. Работает значительно быстрее `find`, но требует обновления базы через `updatedb`.

## Синтаксис

```bash
locate [опции] шаблон
```

## Опции

| Опция | Описание |
|-------|----------|
| `-i` | Игнорировать регистр |
| `-c` | Показать только количество совпадений |
| `-e` | Показать только существующие файлы |
| `-l N` | Ограничить количество результатов |
| `-r regex` | Использовать регулярное выражение |
| `-S` | Показать статистику базы данных |
| `-b` | Искать только по имени файла |

## locate vs find

| Параметр | locate | find |
|----------|--------|------|
| Скорость | Очень высокая | Низкая |
| Актуальность | Зависит от `updatedb` | Всегда актуально |
| Критерии | Только имя файла | Множество критериев |
| Установка | Требует `mlocate`/`plocate` | Встроен в систему |

## Примеры

### Простой поиск

```bash
locate nginx.conf
```

### Поиск без учёта регистра

```bash
locate -i readme.md
```

### Подсчёт совпадений

```bash
locate -c "*.py"
```

### Ограничение результатов

```bash
locate -l 20 "*.log"
```

### Поиск существующих файлов

```bash
locate -e /usr/bin/python
```

### Поиск по regex

```bash
locate -r "\.conf$"
```

### Поиск только по имени файла

```bash
locate -b "passwd"
```

### Статистика базы

```bash
locate -S
```

### Комбинация с другими командами

```bash
locate "*.log" | xargs ls -lh
```

## Практические сценарии

### Обновление базы данных

```bash
sudo updatedb
```

### Поиск всех версий Python

```bash
locate -r "python[0-9]"
```

### Быстрый поиск бинарников

```bash
locate -b "ffmpeg"
```

### Проверка установки пакета

```bash
locate -c "/usr/share/doc/package-name"
```

## Настройка updatedb

Конфигурационный файл: `/etc/updatedb.conf`

```bash
PRUNEPATHS="/tmp /var/spool /media"
PRUNEFS="nfs smbfs cifs fuse"
PRUNENAMES=".git .hg .svn"
```

### Автоматическое обновление

```bash
# Обычно настроено в /etc/cron.daily/mlocate
cat /etc/cron.daily/mlocate
```

:::tip
После установки новых пакетов выполните `sudo updatedb`, чтобы `locate` нашёл их.
:::

:::warning
`locate` ищет в базе данных, а не в реальном времени. Недавно созданные файлы могут не отображаться до обновления базы.
:::
