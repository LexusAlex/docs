# type

**Уровень:** Средний

Определяет тип команды: встроенная, алиас, функция или внешний файл.

## Синтаксис

```bash
type [опции] команда [команда...]
```

## Опции

| Опция | Описание |
|-------|----------|
| `-t` | Вывести только тип (одно слово) |
| `-p` | Показать путь к файлу (если это внешняя команда) |
| `-a` | Показать все определения команды |
| `-P` | Искать только в PATH (игнорировать алиасы и функции) |

## Типы команд

| Тип | Описание |
|-----|----------|
| `builtin` | Встроенная команда shell |
| `alias` | Алиас |
| `function` | Функция shell |
| `file` | Внешний исполняемый файл |
| `keyword` | Зарезервированное слово shell |

## Примеры

### Определить тип команды

```bash
type ls
```

### Только тип

```bash
type -t cd
```

### Показать путь

```bash
type -p python3
```

### Все определения

```bash
type -a ls
```

### Проверка встроенности

```bash
type -t echo
```

### Поиск только в PATH

```bash
type -P grep
```

### Проверка нескольких команд

```bash
type ls cd python3 alias_function
```

### Использование в скрипте

```bash
if [ "$(type -t mycommand)" = "file" ]; then
  echo "Команда найдена"
fi
```

### Показать все ls

```bash
type -a ls
```

### Проверка builtin

```bash
[[ $(type -t read) == "builtin" ]] && echo "builtin"
```

## Практические сценарии

### Определение приоритета команд

```bash
type -a python
```

### Проверка наличия функции

```bash
type -t my_function > /dev/null 2>&1 && echo "Функция существует"
```

### Отладка PATH

```bash
type -a -p java
```

### Проверка в скрипте

```bash
case $(type -t "$1") in
  file)     echo "Внешняя команда: $(type -p "$1")";;
  builtin)  echo "Встроенная команда";;
  alias)    echo "Алиас";;
  function) echo "Функция";;
  *)        echo "Не найдено";;
esac
```

### Проверка переопределения

```bash
type -a grep
```

:::tip
`type` — лучший способ определить, что именно выполняется при вызове команды. Он показывает алиасы, функции и внешние программы в правильном порядке приоритета.
:::

:::warning
`type -p` не покажет путь для встроенных команд и алиасов. Используйте `-a` для полного списка определений.
:::
