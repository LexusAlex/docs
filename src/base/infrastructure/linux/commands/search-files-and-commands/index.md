# Поиск файлов и команд

Поиск файлов в файловой системе, поиск текста в файлах, определение расположения команд.

## Команды

| Команда | Описание |
|---------|----------|
| [find](find.md) | Поиск файлов по имени, типу, размеру, дате |
| [locate](locate.md) | Быстрый поиск по базе данных файлов |
| [which](which.md) | Путь к исполняемому файлу команды |
| [whereis](whereis.md) | Расположение команды, исходников и man-страниц |
| [type](type.md) | Определение типа команды (встроенная, файл, алиас) |
| [xargs](xargs.md) | Построение аргументов из stdin |

::: tip
Команда `grep` описана в разделе [Просмотр и обработка текста](/base/infrastructure/linux/commands/viewing-and-processing-text/grep).
:::
