# Поиск файлов и команд

Поиск файлов в файловой системе, поиск текста в файлах, определение расположения команд.

## Команды

| Команда | Описание |
|---------|----------|
| [find](find.md) | Поиск файлов по имени, типу, размеру, дате |
| [locate](locate.md) | Быстрый поиск по базе данных файлов |
| [which](which.md) | Путь к исполняемому файлу команды |
| [whereis](whereis.md) | Расположение команды, исходников и man-страниц |
| [type](type.md) | Определение типа команды (встроенная, файл, алиас) |
| [xargs](xargs.md) | Построение аргументов из stdin |

## Сравнение команд поиска

| Задача | Команда | Скорость | Полнота |
|--------|---------|----------|---------|
| Найти файл по имени | `find` | Медленнее | Точнее (live) |
| Найти файл по имени (быстро) | `locate` | Быстрее | По базе (не live) |
| Путь к команде | `which` | Мгновенно | Только в PATH |
| Расположение команды | `whereis` | Мгновенно | bin + man + src |
| Тип команды | `type` | Мгновенно | builtin/alias/file |
| Поиск текста в файлах | `grep` | Быстро | Все файлы |
| Построение аргументов | `xargs` | — | Из stdin |

### find vs locate

| Характеристика | find | locate |
|----------------|------|--------|
| Скорость | Медленнее (сканирует ФС) | Быстрее (по базе) |
| Актуальность | Всегда актуально | Зависит от `updatedb` |
| Критерии поиска | Имя, размер, дата, тип... | Только имя |
| Рекурсия | Встроенная | Встроенная |
| Сложность | Высокая | Низкая |

### grep vs awk vs sed для поиска

| Задача | Лучший выбор |
|--------|-------------|
| Найти строки с совпадением | `grep pattern file` |
| Найти + показать столбец | `awk '/pattern/ {print $2}' file` |
| Найти + заменить | `sed '/pattern/s/old/new/' file` |
| Подсчитать совпадения | `grep -c pattern file` |
| Инвертировать поиск | `grep -v pattern file` |

::: tip
Команда `grep` описана в разделе [Просмотр и обработка текста](../viewing-and-processing-text/).
:::
