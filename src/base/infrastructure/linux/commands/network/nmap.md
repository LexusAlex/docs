# nmap

Мощная утилита для сканирования сетей и аудита безопасности.

## Синтаксис

```bash
nmap [опции] цель
```

## Опции

| Опция | Описание |
|-------|----------|
| `-sS` | SYN-сканирование (полуоткрытое) |
| `-sT` | TCP Connect-сканирование |
| `-sU` | UDP-сканирование |
| `-sV` | Определение версий сервисов |
| `-O` | Определение ОС |
| `-A` | Агрессивное сканирование |
| `-p порты` | Указать порты |
| `-T[0-5]` | Скорость сканирования |
| `-oN файл` | Вывод в текстовом формате |
| `-oX файл` | Вывод в XML |
| `--top-ports N` | Сканировать N популярных портов |
| `-sn` | Только обнаружение хостов (без сканирования портов) |
| `-Pn` | Пропустить обнаружение хостов |
| `-n` | Без DNS-разрешения |
| `-v` | Подробный вывод |
| `--script скрипт` | Запустить NSE-скрипт |

## Примеры

### Базовое сканирование

```bash
nmap 192.168.1.1
```

### SYN-сканирование

```bash
nmap -sS 192.168.1.1
```

### TCP Connect

```bash
nmap -sT 192.168.1.1
```

### UDP-сканирование

```bash
nmap -sU 192.168.1.1
```

### Определение версий

```bash
nmap -sV 192.168.1.1
```

### Определение ОС

```bash
nmap -O 192.168.1.1
```

### Агрессивное сканирование

```bash
nmap -A 192.168.1.1
```

### Сканирование портов

```bash
nmap -p 22,80,443 192.168.1.1
```

### Диапазон портов

```bash
nmap -p 1-1000 192.168.1.1
```

### Все порты

```bash
nmap -p- 192.168.1.1
```

### Топ-100 портов

```bash
nmap --top-ports 100 192.168.1.1
```

### Сканирование подсети

```bash
nmap 192.168.1.0/24
```

### Быстрое сканирование

```bash
nmap -T4 192.168.1.0/24
```

### Без DNS

```bash
nmap -n 192.168.1.0/24
```

### Обнаружение хостов

```bash
nmap -sn 192.168.1.0/24
```

### Сохранить результат

```bash
nmap -oN scan.txt 192.168.1.0/24
```

### XML-вывод

```bash
nmap -oX scan.xml 192.168.1.0/24
```

### Скрипты

```bash
nmap --script=http-title 192.168.1.0/24
```

### Проверка уязвимостей

```bash
nmap --script=vuln 192.168.1.1
```

### Сканирование нескольких хостов

```bash
nmap 192.168.1.1 192.168.1.2 192.168.1.3
```

### Из файла

```bash
nmap -iL hosts.txt
```

### Исключить хосты

```bash
nmap 192.168.1.0/24 --exclude 192.168.1.1,192.168.1.2
```

### Проверка одного порта

```bash
nmap -p 443 -sV 192.168.1.1
```

### Скрытное сканирование

```bash
nmap -sS -T2 --data-length 100 192.168.1.1
```

## Практические сценарии

### Аудит безопасности сервера

```bash
nmap -sV -sC -O -oN audit.txt 192.168.1.100
```

### Обзор сети

```bash
nmap -sn 192.168.1.0/24 | grep "report" | awk '{print $NF}'
```

### Проверка открытых портов

```bash
nmap --top-ports 1000 -T4 192.168.1.0/24 -oN top-ports.txt
```

### Поиск сервисов

```bash
nmap -sV --open 192.168.1.0/24
```

### Проверка файрвола

```bash
nmap -sA 192.168.1.1
```

### Скрипт мониторинга

```bash
#!/bin/bash
nmap -sn 192.168.1.0/24 | grep "report" | awk '{print $NF}' > /tmp/hosts.txt
diff /tmp/hosts.txt /var/known_hosts.txt || echo "Обнаружены изменения!"
```

:::tip
Используйте `-T4` для быстрого сканирования в доверенных сетях. Для внешних целей используйте `-T2` или `-T3`.
:::

:::warning
Сканирование чужих сетей без разрешения может быть незаконным. Используйте `nmap` только на своих ресурсах.
:::

## Связки с другими командами

```bash
# Все живые хосты в подсети
nmap -sS -T4 192.168.1.0/24 | grep "Nmap scan" | awk '{print $5}'

# Определение веб-сервисов на портах 80 и 443
nmap -sV -p 80,443 192.168.1.1 | grep -E "open|filtered"

# Ping sweep — обнаружение активных хостов
nmap -sn 192.168.1.0/24 | grep "Nmap scan" | awk '{print $5}'

# Все открытые порты на цели
nmap -sS -p- --open -T4 target | grep "open" | awk '{print $1}'

# Определение ОС (только результат)
nmap -O target 2>/dev/null | grep "Running:"

# Версии всех обнаруженных сервисов
nmap -sV target | grep -E "^[0-9]" | awk '{print $3, $4, $5}'

# Проверка версии SSH на всех живых хостах в подсети
for ip in $(nmap -sn 192.168.1.0/24 -oG - | grep "Up" | awk '{print $2}'); do
  nmap -sV -p 22 $ip
done

# Сохранить результат сканирования в grep-формате и найти хосты с портом 22
nmap -p 22 192.168.1.0/24 -oG - | grep "22/open" | awk '{print $2}'

# Быстрое сканирование топ-100 портов с выводом только открытых
nmap --top-ports 100 --open -T4 192.168.1.0/24 | grep -E "^(Nmap|^[0-9])"
```
