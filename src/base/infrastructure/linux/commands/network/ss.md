# ss

Утилита для просмотра сокетов и сетевых соединений. Заменяет `netstat`.

## Синтаксис

```bash
ss [опции] [фильтр]
```

## Опции

| Опция | Описание |
|-------|----------|
| `-t` | Только TCP |
| `-u` | Только UDP |
| `-l` | Только слушающие сокеты |
| `-n` | Числовой вывод (без разрешения имён) |
| `-p` | Показать процесс (PID/name) |
| `-a` | Все сокеты |
| `-s` | Статистика |
| `-r` | Разрешить имена |
| `-e` | Расширенная информация |
| `-m` | Информация о памяти |
| `-i` | Внутренняя информация TCP |
| `-4` | Только IPv4 |
| `-6` | Только IPv6 |

## Фильтры состояний

| Фильтр | Описание |
|--------|----------|
| `established` | Установленные соединения |
| `listen` | Слушающие сокеты |
| `time-wait` | TIME-WAIT |
| `close-wait` | CLOSE-WAIT |
| `syn-recv` | SYN-RECV |
| `syn-sent` | SYN-SENT |
| `fin-wait` | FIN-WAIT |

## Примеры

### Все TCP-соединения

```bash
ss -t
```

### Все UDP-соединения

```bash
ss -u
```

### Слушающие сокеты

```bash
ss -l
```

### Слушающие TCP с портами

```bash
ss -tl
```

### Все соединения с процессами

```bash
ss -tulap
```

### Числовой вывод

```bash
ss -tln
```

### Статистика

```bash
ss -s
```

### Соединения на порту

```bash
ss -tlnp | grep :80
```

### Установленные соединения

```bash
ss -t state established
```

### Соединения в TIME-WAIT

```bash
ss -t state time-wait
```

### Соединения с конкретным хостом

```bash
ss -tn dst 192.168.1.1
```

### Расширенная информация

```bash
ss -tlnpe
```

### Информация о памяти

```bash
ss -tm
```

### Внутренняя информация TCP

```bash
ss -ti
```

### Количество соединений по состояниям

```bash
ss -s | head -10
```

### Соединения на определённом порту

```bash
ss -tn sport = :443
```

### Соединения к определённому порту

```bash
ss -tn dport = :3306
```

### Соединения с диапазоном портов

```bash
ss -tn sport = :80 or sport = :443
```

### Показать таймеры TCP

```bash
ss -to
```

## Практические сценарии

### Проверка запущенного сервиса

```bash
ss -tlnp | grep :8080
```

### Подсчёт соединений

```bash
ss -tn | tail -n +2 | wc -l
```

### Мониторинг соединений

```bash
watch -n 2 'ss -s'
```

### Поиск утечки соединений

```bash
ss -tn state established | awk '{print $4}' | cut -d: -f1 | sort | uniq -c | sort -rn | head
```

### Проверка порта

```bash
ss -tln | grep -q ":22 " && echo "SSH запущен"
```

:::tip
`ss` быстрее `netstat`, так как читает напрямую из netlink, а не из `/proc/net/tcp`.
:::

:::warning
Для просмотра процессов (`-p`) нужны права root или capability `CAP_NET_ADMIN`.
:::

## Связки с другими командами

```bash
# Кто слушает порт 80
ss -tlnp | grep :80 | awk '{print $4, $6}'

# Все слушающие порты (уникальные, отсортированные)
ss -tlnp | awk 'NR>1 {print $4}' | sed 's/.*://' | sort -un

# Краткая сводка по соединениям
ss -s | head -5

# Соединения по IP-адресам (топ по количеству)
ss -tn state established | awk 'NR>1 {print $4, $5}' | cut -d: -f1 | sort | uniq -c | sort -rn

# Клиентские IP nginx (установленные соединения)
ss -tnp | awk '/ESTAB/ && /nginx/ {print $5}' | cut -d: -f1 | sort | uniq -c | sort -rn

# Мониторинг соединений в реальном времени
watch -n 2 'ss -s'

# Все слушающие порты (только номера)
ss -tlnp | awk '{print $4}' | grep -oP ':\K[0-9]+' | sort -n | uniq

# Подсчёт соединений в TIME_WAIT
ss -tn state time-wait | wc -l

# Топ-10 IP с наибольшим числом соединений
ss -tn | awk 'NR>1 {print $5}' | cut -d: -f1 | sort | uniq -c | sort -rn | head -10

# Проверка, слушает ли порт, с выводом PID
ss -tlnp | awk -v port=":3306" '$4 ~ port {print $4, $6}'
```
