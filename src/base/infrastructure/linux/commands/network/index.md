# Сеть

Конфигурация сетевых интерфейсов, диагностика соединений, передача данных.

## Команды

| Команда | Описание |
|---------|----------|
| [ip](ip.md) | Конфигурация сетевых интерфейсов |
| [ss](ss.md) | Информация о сокетах |
| [ping](ping.md) | Проверка доступности хоста |
| [traceroute](traceroute.md) | Трассировка маршрута |
| [dig](dig.md) | DNS-запросы |
| [nslookup](nslookup.md) | DNS-запросы (упрощённый) |
| [host](host.md) | DNS-запросы |
| [curl](curl.md) | HTTP-запросы и передача данных |
| [wget](wget.md) | Скачивание файлов |
| [nc](nc.md) | netcat — TCP/UDP соединения |
| [nmap](nmap.md) | Сканирование портов |
| [tcpdump](tcpdump.md) | Захват сетевого трафика |
| [mtr](mtr.md) | Комбинация ping + traceroute |

::: tip
Команды `scp` и `rsync` описаны в разделе [SSH](/base/infrastructure/linux/commands/ssh/).
:::

## Полезные файлы

| Файл | Описание |
|------|----------|
| `/etc/hosts` | Локальное разрешение имён |
| `/etc/resolv.conf` | DNS-серверы |
| `/etc/hostname` | Имя хоста |
| `/etc/network/interfaces` | Сетевые интерфейсы (Debian) |
| `/etc/netplan/*.yaml` | Сетевые интерфейсы (Ubuntu 18+) |

## Сравнение сетевых команд

| Задача | Команда | Альтернатива |
|--------|---------|-------------|
| IP-адреса | `ip addr` | `ifconfig` (устарел) |
| Сетевые соединения | `ss` | `netstat` (устарел) |
| Проверка связи | `ping` | `fping` (несколько хостов) |
| Трассировка маршрута | `traceroute` | `mtr` (непрерывная) |
| DNS-запросы | `dig` | `nslookup`, `host` |
| HTTP-запросы | `curl` | `wget`, `httpie` |
| Скачивание файлов | `wget` | `curl -O`, `aria2c` |
| Сканирование портов | `nmap` | `masscan` (быстрый) |
| Захват трафика | `tcpdump` | `tshark`, `wireshark` |

### curl vs wget

| Характеристика | curl | wget |
|----------------|------|------|
| Протоколы | HTTP, HTTPS, FTP, SCP, SFTP... | HTTP, HTTPS, FTP |
| Загрузка файлов | `-O`, `-o` | Встроенная |
| Рекурсивная загрузка | Нет | `-r`, `--mirror` |
| Продолжение загрузки | `-C -` | `-c` |
| POST-запросы | `-d`, `-X POST` | `--post-data` |
| Заголовки | `-H` | `--header` |
| Тихий режим | `-s` | `-q` |
| Вывод в stdout | По умолчанию | `-O -` |

### ss vs netstat

`ss` — современная замена `netstat`. Быстрее, показывает больше информации.

| Операция | ss | netstat |
|----------|-----|---------|
| TCP-соединения | `ss -t` | `netstat -t` |
| Слушающие порты | `ss -tlnp` | `netstat -tlnp` |
| UDP | `ss -u` | `netstat -u` |
| Процессы | `-p` | `-p` |
| Числовой формат | `-n` | `-n` |
| Статистика | `ss -s` | `netstat -s` |
