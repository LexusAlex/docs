# dpkg

**Уровень:** Начинающий

Низкоуровневый менеджер пакетов Debian. Работает с `.deb` файлами напрямую.

## Синтаксис

```bash
dpkg [опции] [действие] [пакет]
```

## Действия

| Действие | Описание |
|----------|----------|
| `-i файл.deb` | Установить пакет |
| `-r пакет` | Удалить пакет (сохранить конфиги) |
| `-P пакет` | Удалить с конфигами |
| `--unpack файл.deb` | Распаковать без настройки |
| `--configure пакет` | Настроить распакованный пакет |
| `-l [шаблон]` | Список установленных |
| `-L пакет` | Файлы пакета |
| `-s пакет` | Статус пакета |
| `-S файл` | Найти пакет по файлу |
| `-c файл.deb` | Содержимое .deb |
| `--print-architecture` | Архитектура системы |
| `--configure -a` | Настроить все ненастроенные |

## Опции

| Опция | Описание |
|-------|----------|
| `--force-all` | Принудительное выполнение |
| `--no-act` | Симуляция |
| `--recursive` | Рекурсивная установка |

## Примеры

### Установка из .deb файла

```bash
sudo dpkg -i package.deb
```

### Удаление пакета

```bash
sudo dpkg -r nginx
```

### Полное удаление

```bash
sudo dpkg -P nginx
```

### Список установленных

```bash
dpkg -l
```

### Поиск пакета

```bash
dpkg -l | grep nginx
```

### Файлы пакета

```bash
dpkg -L nginx
```

### Статус пакета

```bash
dpkg -s nginx
```

### Какой пакет содержит файл

```bash
dpkg -S /usr/bin/nginx
```

### Содержимое .deb файла

```bash
dpkg -c package.deb
```

### Архитектура системы

```bash
dpkg --print-architecture
```

### Проверка всех пакетов

```bash
dpkg --audit
```

### Настройка ненастроенных

```bash
sudo dpkg --configure -a
```

### Установка нескольких пакетов

```bash
sudo dpkg -i *.deb
```

## Исправление проблем

### Исправление сломанных зависимостей

```bash
sudo apt-get install -f
```

## Практические сценарии

### Установка скачанного .deb

```bash
wget https://example.com/app.deb
sudo dpkg -i app.deb
sudo apt-get install -f
```

:::tip
`dpkg` не разрешает зависимости автоматически. После установки через `dpkg -i` запустите `sudo apt-get install -f` для исправления зависимостей.
:::

:::warning
Используйте `--force-all` только в крайних случаях. Это может привести к нестабильной системе.
:::
