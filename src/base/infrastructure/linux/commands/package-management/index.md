# Управление пакетами

Установка, обновление и удаление программного обеспечения.

## Семейства дистрибутивов

| Семейство | Формат | Менеджер пакетов |
|-----------|--------|-----------------|
| Debian/Ubuntu | `.deb` | apt, dpkg |
| RHEL/Fedora/CentOS | `.rpm` | dnf, yum, rpm |
| Arch | `.pkg.tar.zst` | pacman |
| openSUSE | `.rpm` | zypper |
| Alpine | `.apk` | apk |

## Подкатегории

- [Debian/Ubuntu](debian-ubuntu/) — apt, apt-get, dpkg, snap
- [RHEL/Fedora](rhel-fedora/) — dnf, yum, rpm
