# at

**Уровень:** Средний

Планирует однократное выполнение команды в указанное время. В отличие от crontab, задача выполняется только один раз.

## Синтаксис

```bash
at [опции] время
echo "команда" | at время
at -f файл время
at -l                          # список задач
at -d номер                    # удалить задачу
at -c номер                    # просмотреть задачу
```

## Основные опции

| Опция | Описание |
|-------|----------|
| `-f файл` | Читать команды из файла |
| `-l`, `-q` | Показать список ожидающих задач (также `atq`) |
| `-d номер` | Удалить задачу по номеру (также `atrm`) |
| `-c номер` | Показать содержимое задачи |
| `-m` | Отправить письмо после выполнения (даже если нет вывода) |
| `-M` | Не отправлять письмо никогда |
| `-q буква` | Указать очередь (a-z, по умолчанию a) |
| `-t время` | Время в формате `[[CC]YY]MMDDhhmm[.ss]` |
| `-v` | Показать время выполнения |
| `-V` | Показать версию |

## Форматы времени

| Формат | Пример | Описание |
|--------|--------|----------|
| `HH:MM` | `at 14:30` | В указанное время (если уже прошло — завтра) |
| `HH:MM YYYY-MM-DD` | `at 14:30 2024-01-15` | Конкретная дата и время |
| `now + N minutes` | `at now + 30 minutes` | Через 30 минут |
| `now + N hours` | `at now + 2 hours` | Через 2 часа |
| `now + N days` | `at now + 3 days` | Через 3 дня |
| `now + N weeks` | `at now + 1 week` | Через неделю |
| `midnight` | `at midnight` | В полночь |
| `noon` | `at noon` | В полдень |
| `teatime` | `at teatime` | В 16:00 |
| `tomorrow` | `at tomorrow` | Завтра в то же время |
| `next + weekday` | `at next Mon` | В следующий понедельник |
| `MMDDYY` | `at 011524` | 15 января 2024 |
| `MM/DD/YY` | `at 01/15/24` | 15 января 2024 |
| `DD.MM.YYYY` | `at 15.01.2024` | 15 января 2024 |

## Команды-спутники

### atq — список задач

```bash
atq
# 1    Mon Jan 15 14:30:00 2024 a alex
# 2    Tue Jan 16 10:00:00 2024 b alex

atq -q b                   # только очередь b
```

### atrm — удаление задачи

```bash
atrm 1                     # удалить задачу №1
atrm 1 2 3                 # удалить несколько задач
```

### batch — выполнение при низкой нагрузке

```bash
batch                      # выполнить, когда нагрузка снизится
echo "тяжёлая_задача" | batch
```

## Управление доступом

Файлы контроля доступа:

- `/etc/at.allow` — только перечисленные пользователи могут использовать at
- `/etc/at.deny` — перечисленные пользователи НЕ могут использовать at

```bash
# Посмотреть, кто может использовать at
cat /etc/at.allow
cat /etc/at.deny

# Добавить пользователя в allow
echo "username" >> /etc/at.allow
```

Логика проверки:
1. Если существует `at.allow` — только пользователи из него могут использовать at
2. Если `at.allow` не существует, проверяется `at.deny`
3. Если ни один файл не существует — только root может использовать at

## Примеры

### 1. Задача через 30 минут

```bash
echo "echo 'Задача выполнена' > /tmp/at_result.txt" | at now + 30 minutes
```

### 2. Задача в конкретное время

```bash
echo "/usr/bin/backup.sh" | at 23:00
```

### 3. Задача из файла

```bash
cat > /tmp/at_task.sh << 'EOF'
#!/bin/bash
echo "Выполнение задачи в $(date)" >> /tmp/at_log.txt
cp /important/data /backup/
EOF

at -f /tmp/at_task.sh 02:00
```

### 4. Интерактивный ввод

```bash
at 14:30
# Появляется приглашение at>
echo "Задача выполнена в $(date)" > /tmp/result.txt
# Ctrl+D для завершения ввода
```

### 5. Задача с конкретной датой

```bash
echo "/usr/bin/certbot renew" | at 03:00 2024-02-01
```

### 6. Просмотр задачи

```bash
at -c 1
# Показывает полный контекст выполнения (переменные окружения, команды)
```

### 7. Удаление задачи

```bash
atq
# 1    Mon Jan 15 14:30:00 2024 a alex
atrm 1
```

### 8. Отправка уведомления

```bash
echo "echo 'Готово!' | mail -s 'Задача завершена' admin@example.com" | at now + 1 hour
```

### 9. Перезагрузка сервера

```bash
echo "shutdown -r now" | at 04:00
```

### 10. Резервное копирование

```bash
cat << 'EOF' | at 02:00 tomorrow
tar -czf /backup/full_$(date +%Y%m%d).tar.gz /data/
find /backup -mtime +30 -delete
EOF
```

## Практические сценарии

### Отложенный перезапуск сервиса

```bash
# Перезапустить nginx через 5 минут
echo "systemctl restart nginx" | at now + 5 minutes
```

### Одноразовое резервное копирование

```bash
cat << 'SCRIPT' | at 03:00
#!/bin/bash
mysqldump --all-databases > /backup/db_$(date +%Y%m%d).sql
tar -czf /backup/files_$(date +%Y%m%d).tar.gz /var/www/
SCRIPT
```

### Уведомление о событии

```bash
echo 'notify-send "Встреча через 15 минут"' | at 14:45
```

### Очистка временных файлов

```bash
echo "find /tmp -type f -mtime +7 -delete" | at now + 1 day
```

### Проверка сертификатов

```bash
echo 'certbot certificates 2>&1 | mail -s "Cert check" admin@' | at next Mon
```

## Советы

:::tip
Используйте `at -f script.sh time` вместо pipe — удобнее для сложных задач.
:::

:::warning
Задачи at выполняются в окружении, отличном от текущего. Всегда используйте полные пути к командам и файлам.
:::

:::tip
`at -v time` покажет точное время выполнения — полезно для проверки.
:::

:::warning
Если `/etc/at.allow` существует и пуст — только root может использовать at.
:::

## Связки с другими командами

- **crontab** — для повторяющихся задач (at — для одноразовых)
- **systemctl** — перезапуск служб по расписанию
- **batch** — выполнение при низкой нагрузке
- **mail** — отправка уведомлений о выполнении
- **shutdown** — отложенное выключение/перезагрузка
