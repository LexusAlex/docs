# Планировщики задач (at/batch)

Утилиты для одноразового планирования задач. В отличие от crontab, который выполняет задачи повторно по расписанию, `at` и `batch` предназначены для однократного выполнения.

## Команды

| Команда | Описание |
|---------|----------|
| [at](at.md) | Выполнить задачу в указанное время |
| [batch](batch.md) | Выполнить задачу при снижении нагрузки на систему |

## at vs batch vs crontab

| Характеристика | at | batch | crontab |
|---------------|-----|-------|---------|
| Количество выполнений | 1 | 1 | Повторяющееся |
| Условие | Конкретное время | Низкая нагрузка | Расписание |
| Формат времени | `HH:MM`, `now + N min` | Нет (автоматически) | cron-выражение |
| Сценарии | Отложенная задача | Тяжёлая задача | Регулярные задачи |

## Когда использовать

- **at** — перезапуск сервиса через 10 минут, отложенная отправка, одноразовый бэкап
- **batch** — компиляция ядра, индексация, обработка видео
- **crontab** — ежедневные бэкапы, очистка логов, мониторинг
