# chmod

**Уровень:** Начинающий

Изменение прав доступа к файлам и каталогам.

## Синтаксис

```bash
chmod [опции] режим файл...
```

## Опции

| Опция | Описание |
|-------|----------|
| `-R` | Рекурсивно |
| `-v` | Подробный вывод |
| `-c` | Показать только изменения |
| `--preserve-root` | Не рекурсивно для / |
| `--reference=файл` | Использовать права другого файла |
| `--help` | Помощь |
| `--version` | Версия |

## Символьный режим

### Категории

| Категория | Описание |
|-----------|----------|
| `u` | Владелец (user) |
| `g` | Группа (group) |
| `o` | Остальные (others) |
| `a` | Все (all) |

### Права

| Право | Описание | Числовое |
|-------|----------|----------|
| `r` | Чтение | 4 |
| `w` | Запись | 2 |
| `x` | Выполнение | 1 |

### Операции

| Операция | Описание |
|----------|----------|
| `+` | Добавить |
| `-` | Убрать |
| `=` | Установить |

## Числовой режим (восьмеричный)

| Код | Права | Описание |
|-----|-------|----------|
| `7` | `rwx` | Чтение, запись, выполнение |
| `6` | `rw-` | Чтение, запись |
| `5` | `r-x` | Чтение, выполнение |
| `4` | `r--` | Только чтение |
| `3` | `-wx` | Запись, выполнение |
| `2` | `-w-` | Только запись |
| `1` | `--x` | Только выполнение |
| `0` | `---` | Нет прав |

## Специальные биты

| Бит | Код | Описание |
|-----|-----|----------|
| SUID | `4000` | Выполнять от имени владельца |
| SGID | `2000` | Выполнять от имени группы |
| Sticky | `1000` | Только владелец может удалять |

## Популярные комбинации

| Код | Права | Использование |
|-----|-------|---------------|
| `755` | `rwxr-xr-x` | Исполняемые файлы, скрипты |
| `644` | `rw-r--r--` | Обычные файлы |
| `700` | `rwx------` | Приватные директории |
| `600` | `rw-------` | Приватные файлы |
| `777` | `rwxrwxrwx` | Полный доступ (осторожно!) |
| `666` | `rw-rw-rw-` | Чтение/запись для всех |

## Примеры

### Символьный режим

```bash
chmod u+x script.sh
chmod g+w file.txt
chmod o-r file.txt
chmod a+r file.txt
```

### Числовой режим

```bash
chmod 755 script.sh
chmod 644 file.txt
chmod 700 ~/.ssh
chmod 600 ~/.ssh/id_rsa
```

### Рекурсивно

```bash
# X добавляет execute каталогам и уже исполняемым файлам, но не всем обычным файлам
chmod -R u=rwX,go=rX /var/www/html
chmod -R u+rwX /home/alex
```

### Подробный вывод

```bash
chmod -v 755 script.sh
```

### Только изменения

```bash
chmod -c 644 file.txt
```

### По образцу

```bash
chmod --reference=file1.txt file2.txt
```

### SUID

```bash
chmod u+s /usr/bin/program
chmod 4755 /usr/bin/program
```

### SGID

```bash
chmod g+s /shared/directory
chmod 2755 /shared/directory
```

### Sticky bit

```bash
chmod +t /tmp
chmod 1777 /tmp
```

### Убрать все права

```bash
chmod 000 file.txt
```

### Полный доступ для владельца

```bash
chmod u=rwx,go= file.txt
```

### Добавить выполнение для всех

```bash
chmod +x script.sh
```

## Практические сценарии

### Безопасные права для SSH

```bash
chmod 700 ~/.ssh
chmod 600 ~/.ssh/id_rsa
chmod 644 ~/.ssh/id_rsa.pub
chmod 644 ~/.ssh/authorized_keys
```

### Права для веб-сервера

```bash
# Каталогам нужен execute-бит для обхода, обычным файлам — нет
find /var/www/html -type d -exec chmod 755 {} +
find /var/www/html -type f -exec chmod 644 {} +
```

### Права для скриптов

```bash
chmod +x script.sh
```

:::tip
Используйте `chmod -R` с осторожностью. Неправильные права могут сломать систему или создать уязвимости.
:::

:::warning
Никогда не давайте `777` на системные файлы. Это позволяет любому пользователю читать, записывать и выполнять файлы.
:::

### Проверка прав

```bash
ls -l file.txt
# -rw-r--r-- 1 alex alex 100 Jan 15 10:00 file.txt
```

### Восстановление прав

```bash
# Для файлов
find /path -type f -exec chmod 644 {} \;

# Для директорий
find /path -type d -exec chmod 755 {} \;
```

## Связки с другими командами

```bash
# Установить 644 на все файлы рекурсивно
find . -type f -exec chmod 644 {} \;

# Установить 755 на все директории рекурсивно
find . -type d -exec chmod 755 {} \;

# Сделать все shell-скрипты исполняемыми
find . -name "*.sh" -exec chmod +x {} \;

# Стандартные права для веб-сервера
find /var/www -type d -exec chmod 755 {} \; && find /var/www -type f -exec chmod 644 {} \;

# Рекурсивно: владелец всё, группа и остальные — чтение
chmod -R u+rwX,go+rX,go-w /project/

# Вывести права всех файлов в текущей директории
stat -c "%a %n" * | sort

# Найти файлы с открытыми правами для всех (777)
find . -perm 777 -exec ls -la {} \;

# Исправить права на приватные ключи SSH
find ~/.ssh -name "id_*" ! -name "*.pub" -exec chmod 600 {} \;

# Найти и исправить права на конфиги
find /etc -name "*.conf" -perm /o+w -exec chmod o-w {} \;

# Установить sticky bit на директорию
chmod +t /shared && ls -ld /shared
```
