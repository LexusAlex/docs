# umask

**Уровень:** Средний

Управление маской прав доступа по умолчанию.

## Синтаксис

```bash
umask [маска]
```

## Опции

| Опция | Описание |
|-------|----------|
| `-S` | Символьный формат |
| `-p` | Формат для вставки в скрипт |
| `--help` | Помощь |

## Как работает umask

umask определяет, какие права будут **убраны** из прав по умолчанию:

- **Файлы**: `666 - umask` (без выполнения)
- **Каталоги**: `777 - umask`

## Популярные значения

| umask | Права файлов | Права каталогов | Описание |
|-------|--------------|-----------------|----------|
| `022` | `644` (`rw-r--r--`) | `755` (`rwxr-xr-x`) | Стандартное значение |
| `027` | `640` (`rw-r-----`) | `750` (`rwxr-x---`) | Более строгое |
| `077` | `600` (`rw-------`) | `700` (`rwx------`) | Максимально строгое |
| `002` | `664` (`rw-rw-r--`) | `775` (`rwxrwxr-x`) | Для групповой работы |
| `000` | `666` (`rw-rw-rw-`) | `777` (`rwxrwxrwx`) | Без ограничений (опасно!) |

## Примеры

### Показать текущую маску

```bash
umask
```

### В символьном формате

```bash
umask -S
```

### Установить маску

```bash
umask 022
```

### Строгая маска

```bash
umask 077
```

### Для групповой работы

```bash
umask 002
```

### Проверка действия маски

```bash
umask 027
touch test_file
mkdir test_dir
ls -l test_file test_dir
# Файл: 640, Каталог: 750
```

### Временная маска

```bash
# Только для текущей сессии
umask 027
```

### В скрипте

```bash
#!/bin/bash
umask 077
# Все создаваемые файлы будут приватными
```

### Проверка в разных форматах

```bash
echo "Octal: $(umask)"
echo "Symbolic: $(umask -S)"
```

### Сброс на стандартное значение

```bash
umask 022
```

### Понимание вычитания

```bash
# umask 027
# Файлы: 666 - 027 = 640 (rw-r-----)
# Каталоги: 777 - 027 = 750 (rwxr-x---)
```

## Практические сценарии

### Приватная маска для безопасности

```bash
# В ~/.bashrc или ~/.profile
umask 077
# Все новые файлы будут доступны только владельцу
```

### Для совместной работы

```bash
# Разрешить группе чтение и запись
umask 002
```

### Проверка перед созданием файлов

```bash
# Показать, какие права будут установлены
echo "Current umask: $(umask -S)"
echo "New files will get: $(printf '%04o' $(( 0666 & ~$(umask) )) )"
echo "New dirs will get: $(printf '%04o' $(( 0777 & ~$(umask) )) )"
```

:::tip
Добавьте `umask` в `~/.bashrc` или `/etc/profile` для установки маски по умолчанию для всех пользователей.
:::

:::warning
Маска `000` даёт полный доступ всем. Это небезопасно и не рекомендуется.
:::

### Временная маска для скрипта

```bash
#!/bin/bash
# Сохранить текущую маску
OLD_UMASK=$(umask)

# Установить строгую маску
umask 077

# Создать файлы
touch sensitive_file.txt

# Восстановить маску
umask $OLD_UMASK
```

### Проверка системной маски

```bash
# Проверить /etc/profile
grep umask /etc/profile

# Проверить /etc/login.defs
grep UMASK /etc/login.defs
```
