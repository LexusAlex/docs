# Права доступа

Управление правами на файлы и директории. Базовые (rwx) и расширенные (ACL) права.

## Команды

| Команда | Описание |
|---------|----------|
| [chmod](chmod.md) | Изменение прав доступа |
| [chown](chown.md) | Изменение владельца файла |
| [chgrp](chgrp.md) | Изменение группы файла |
| [umask](umask.md) | Маска прав по умолчанию |
| [getfacl](getfacl.md) | Просмотр расширенных прав (ACL) |
| [setfacl](setfacl.md) | Установка расширенных прав (ACL) |

## Структура прав

```
 -rwxr-xr--  1  user  group  4096  Jan 01 00:00  file
 │╰┬╯╰┬╯╰┬╯
 │  │   │   └─ другие (r-- = 4)
 │  │   └───── группа (r-x = 5)
 │  └───────── владелец (rwx = 7)
 └──────────── тип (- файл, d директория, l ссылка)
```

## Цифровые обозначения

| Цифра | Права | Буквы |
|-------|-------|-------|
| 0 | Нет прав | `---` |
| 1 | Только выполнение | `--x` |
| 2 | Только запись | `-w-` |
| 3 | Запись + выполнение | `-wx` |
| 4 | Только чтение | `r--` |
| 5 | Чтение + выполнение | `r-x` |
| 6 | Чтение + запись | `rw-` |
| 7 | Полный доступ | `rwx` |
