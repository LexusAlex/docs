# lsof

**Уровень:** Средний

Список открытых файлов и процессов, их использующих.

## Синтаксис

```bash
lsof [options] [names]
```

## Опции

| Опция | Описание |
|-------|----------|
| `-i [4\|6][protocol][@host][:port]` | Интернет-файлы |
| `-p PID` | Файлы конкретного процесса |
| `-u user` | Файлы пользователя |
| `-c command` | Файлы команды |
| `-d fd` | Файловые дескрипторы |
| `-t` | Только PID (terse) |
| `+D dir` | Рекурсивный поиск в директории |
| `+d dir` | Поиск в директории |
| `-n` | Без DNS-разрешения |
| `-P` | Без разрешения портов |
| `-l` | UID вместо имён пользователей |
| `+w` | Без предупреждений |
| `+L [n]` | Связанные файлы (link count ≤ n) |
| `-a` | Логическое И между условиями |
| `-r [n]` | Повторять каждые n секунд |
| `-s` | Размер файлов |
| `-S [t]` | Таймаут для TCP |

## Примеры

### 1. Все открытые файлы

```bash
sudo lsof
```

### 2. Файлы конкретного процесса

```bash
lsof -p 1234
```

### 3. Файлы пользователя

```bash
lsof -u alex
```

### 4. Исключение пользователя

```bash
lsof -u ^root
```

### 5. Интернет-соединения

```bash
lsof -i
```

### 6. TCP-соединения

```bash
lsof -i tcp
```

### 7. UDP-соединения

```bash
lsof -i udp
```

### 8. Конкретный порт

```bash
lsof -i :80
lsof -i :22
```

### 9. Диапазон портов

```bash
lsof -i :80-443
```

### 10. Конкретный хост

```bash
lsof -i @192.168.1.1
```

### 11. Без DNS-разрешения

```bash
lsof -i -n
```

### 12. Без разрешения портов

```bash
lsof -i -P
```

### 13. Процесс на порту

```bash
lsof -i :80 -t
```

### 14. Файлы в директории

```bash
lsof +D /var/log
```

### 15. Открытые файлы команды

```bash
lsof -c nginx
```

## Практические сценарии

### Кто использует порт?

```bash
sudo lsof -i :8080 -n -P
```

### Какие файлы открыты процессом?

```bash
lsof -p $(pgrep -f "myapp") | head -20
```

### Восстановление удалённого файла

```bash
# Найти PID и FD
lsof | grep deleted

# Восстановить
cp /proc/PID/fd/FD /path/to/restored
```

### Мониторинг соединений

```bash
lsof -i -n -P -r 2
```

### Сколько файлов открыто пользователем?

```bash
lsof -u alex | wc -l
```

### Проверка лимитов файловых дескрипторов

```bash
lsof -p $(pgrep myapp) | wc -l
cat /proc/$(pgrep myapp)/limits | grep "open files"
```

### Какие процессы держат файл?

```bash
lsof /var/log/syslog
```

### Проверка ESTABLISHED соединений

```bash
lsof -i -n -P | grep ESTABLISHED
```

### Проверка LISTEN портов

```bash
lsof -i -n -P | grep LISTEN
```

### Мониторинг в реальном времени

```bash
watch -n 1 'lsof -i -n -P | grep -c ESTABLISHED'
```

## Формат вывода

| Колонка | Описание |
|---------|----------|
| COMMAND | Имя команды |
| PID | ID процесса |
| USER | Владелец |
| FD | Файловый дескриптор |
| TYPE | Тип файла |
| DEVICE | Номер устройства |
| SIZE/OFF | Размер |
| NODE | Индекс inode |
| NAME | Имя файла |

## Типы FD

| FD | Описание |
|----|----------|
| `cwd` | Текущая директория |
| `rtd` | Корневая директория |
| `txt` | Текстовый сегмент |
| `mem` | Отображённый файл |
| `0r` | Стандартный ввод (read) |
| `1w` | Стандартный вывод (write) |
| `2w` | Стандартная ошибка |
| `3u` | Файловый дескриптор (read/write) |

:::tip Флаг -t для скриптов
Используйте `lsof -t` для получения только PID. Удобно для использования в скриптах: `kill $(lsof -t -i :8080)`.
:::

:::warning Права доступа
Некоторые опции lsof требуют root-прав. Для просмотра файлов чужих процессов используйте `sudo`.
:::

## Советы

:::tip Быстрый поиск процесса на порту
```bash
lsof -tiTCP:8080 -sTCP:LISTEN | xargs -r kill -TERM --
```
:::

:::warning Производительность
На системах с большим количеством открытых файлов lsof может работать медленно. Используйте фильтры для ограничения вывода.
:::

## Связки с другими командами

```bash
# Кто использует порт 80 (имя, PID, соединение)
lsof -i :80 | awk 'NR>1 {print $1, $2, $9}'

# Все слушающие сервисы (имя и адрес)
lsof -i -P -n | grep LISTEN | awk '{print $1, $9}'

# Подсчитать количество открытых файлов пользователя www-data
lsof -u www-data | wc -l

# Подсчитать открытые файлы в директории /var/log
lsof +D /var/log | wc -l

# Подсчитать файловые дескрипторы конкретного процесса
lsof -p $(pgrep -o nginx) | wc -l

# Убить процесс, занимающий порт 8080
lsof -tiTCP:8080 -sTCP:LISTEN | xargs -r kill -TERM --

# Найти удалённые файлы, которые всё ещё открыты (утечка дискового пространства)
lsof | grep deleted | awk '{print $1, $2, $7}'

# TCP-соединения по пользователям (отсортированные по количеству)
lsof -i tcp | awk 'NR>1 {print $1, $3, $9}' | sort | uniq -c | sort -rn

# Проверить, какие процессы держат соединения к конкретному серверу
lsof -i @192.168.1.100 -n -P | awk 'NR>1 {print $1, $2, $9}'

# Мониторинг количества ESTABLISHED-соединений в реальном времени
watch -n 2 'lsof -i -n -P | grep -c ESTABLISHED'

# Найти утечки файловых дескрипторов (процессы с >1000 открытыми файлами)
for pid in $(ps -eo pid --no-headers); do count=$(lsof -p "$pid" 2>/dev/null | wc -l); [ "$count" -gt 1000 ] && echo "PID $pid: $count files"; done
```
