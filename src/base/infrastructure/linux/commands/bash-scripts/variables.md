# Переменные bash

**Уровень:** Продвинутый

Объявление, использование и манипуляция переменными в bash.

## Синтаксис

```bash
VAR="value"           # объявление
echo "$VAR"           # использование
unset VAR             # удаление
```

## Специальные переменные

| Переменная | Описание |
|------------|----------|
| `$0` | Имя скрипта |
| `$1`..`$9` | Позиционные аргументы |
| `${10}`.. | Аргументы с номером ≥ 10 |
| `$@` | Все позиционные аргументы; в `"$@"` каждый остаётся отдельным shell-словом |
| `$*` | Все позиционные аргументы; в `"$*"` объединяются первым символом `IFS` |
| `$#` | Количество аргументов |
| `$$` | PID текущего процесса |
| `$!` | PID последнего фонового процесса |
| `$?` | Код возврата последней команды |
| `$-` | Флаги текущей оболочки |

## Кавычки

| Тип | Пример | Переменные | Спецсимволы |
|-----|--------|------------|-------------|
| Двойные | `"Hello $USER"` | Раскрываются | Экранируются |
| Одинарные | `'Hello $USER'` | Не раскрываются | Не экранируются |
| Обратные кавычки | `` `date` `` | Подкоманда | Устаревший синтаксис |
| `$()` | `$(date)` | Подкоманда | Предпочтительный |

## Подстановка параметров

| Синтаксис | Описание | Пример |
|-----------|----------|--------|
| `${var:-default}` | Значение по умолчанию (без присваивания) | `${name:-"Anonymous"}` |
| `${var:=default}` | Значение по умолчанию (с присваиванием) | `${name:="Anonymous"}` |
| `${var:+value}` | Альтернативное значение | `${name:+"exists"}` |
| `${var:?error}` | Ошибка если не задана | `${name:?"Required"}` |
| `${#var}` | Длина строки | `${#name}` |
| `${var%pattern}` | Удалить суффикс (короткий) | `${file%.txt}` |
| `${var%%pattern}` | Удалить суффикс (длинный) | `${file%%.*}` |
| `${var#pattern}` | Удалить префикс (короткий) | `${path#*/}` |
| `${var##pattern}` | Удалить префикс (длинный) | `${path##*/}` |
| `${var/old/new}` | Замена первого вхождения | `${name/old/new}` |
| `${var//old/new}` | Замена всех вхождений | `${name//old/new}` |
| `${var:offset:length}` | Подстрока | `${name:0:3}` |
| `${var^^}` | В верхний регистр | `${name^^}` |
| `${var,,}` | В нижний регистр | `${name,,}` |
| `${var^}` | Первый символ в верхний | `${name^}` |
| `${var,}` | Первый символ в нижний | `${name,}` |

## Примеры

### 1. Объявление переменных

```bash
name="Alex"
age=30
readonly PI=3.14159
```

### 2. Использование кавычек

```bash
greeting="Hello"
echo "$greeting World"    # Hello World
echo '$greeting World'    # $greeting World
```

### 3. Значение по умолчанию

```bash
echo "${username:-guest}"
username=${username:-guest}
```

### 4. Длина строки

```bash
text="Hello"
echo "${#text}"   # 5
```

### 5. Удаление префикса/суффикса

```bash
path="/home/user/file.txt"
echo "${path##*/}"   # file.txt
echo "${path%/*}"    # /home/user
ext="${file##*.}"    # txt
name="${file%.*}"    # file
```

### 6. Замена в строке

```bash
text="Hello World"
echo "${text/World/Bash}"   # Hello Bash
echo "${text//l/L}"         # HeLLo WorLd
```

### 7. Подстрока

```bash
text="Hello World"
echo "${text:6:5}"   # World
echo "${text:0:5}"   # Hello
```

### 8. Регистр

```bash
name="alex"
echo "${name^^}"   # ALEX
echo "${name,,}"   # alex
echo "${name^}"    # Alex
```

### 9. Арифметика

```bash
a=10
b=3
echo "$((a + b))"    # 13
echo "$((a % b))"    # 1
echo "$((a ** 2))"   # 100
```

### 10. Объявление с declare

```bash
declare -i count=0      # целое число
declare -r CONST="val"  # только для чтения
declare -a arr=(1 2 3)  # массив
declare -A map=([key]="val")  # ассоциативный массив
declare -x EXPORTED="val"    # экспорт
```

### 11. Массивы

```bash
fruits=("apple" "banana" "cherry")
echo "${fruits[0]}"      # apple
echo "${fruits[@]}"      # все элементы
echo "${#fruits[@]}"     # длина
fruits+=("date")         # добавление
unset fruits[1]          # удаление
```

### 12. Ассоциативные массивы

```bash
declare -A config
config[host]="localhost"
config[port]="8080"
echo "${config[host]}:${config[port]}"
echo "${!config[@]}"     # все ключи
```

### 13. Локальные переменные в функциях

```bash
function greet() {
    local name="$1"
    echo "Hello, $name"
}
```

### 14. Переменные окружения vs shell

```bash
export PATH="$PATH:/new/path"  # экспорт
env                            # просмотр env
printenv HOME                  # конкретная переменная
set                            # все shell-переменные
```

### 15. Многострочные переменные

```bash
text="Line 1
Line 2
Line 3"
echo "$text"
```

:::tip Кавычки обязательны
Всегда заключайте переменные в двойные кавычки: `"$var"`. Без кавычек происходит разделение по пробелам и подстановка спецсимволов.
:::

:::warning declare -i и арифметика
При `declare -i` правая часть вычисляется как арифметическое выражение. Неизвестное имя переменной обычно даёт `0`; ошибка возникает у синтаксически неверного выражения и операций вроде деления на ноль.
:::

## Советы

:::tip Отладка переменных
Используйте `declare -p var` для просмотра типа и значения переменной. Для вывода всех переменных: `set | grep pattern`.
:::

:::warning Экспорт переменных
Переменные, объявленные без `export`, не доступны дочерним процессам. Используйте `export VAR="value"` для передачи в дочерние процессы.
:::
