# bg

Возобновляет выполнение остановленного задания в фоновом режиме.

## Синтаксис

```bash
bg [задание]
```

## Опции

| Опция | Описание |
|-------|----------|
| `%номер` | Номер задания из `jobs` |
| `%строка` | Задание, начинающееся со строки |
| `%?строка` | Задание, содержащее строку |
| `%+` или `%%` | Текущее задание |
| `%-` | Предыдущее задание |

## Примеры

### Возобновить текущее задание

```bash
bg
```

### Возобновить задание по номеру

```bash
bg %1
```

### Возобновить задание по имени

```bash
bg %vim
```

### Возобновить предыдущее задание

```bash
bg %-
```

### Возобновить задание по части имени

```bash
bg %?py
```

### Типичный workflow

```bash
# Запускаем задачу
./long-task.sh
# Нажимаем Ctrl+Z (приостановка)
# Переводим в фон
bg
```

### Несколько заданий

```bash
./task1.sh
# Ctrl+Z
./task2.sh
# Ctrl+Z
bg %1  # Возобновляем task1
bg %2  # Возобновляем task2
```

### Проверка статуса

```bash
bg %1 && jobs
```

### Скрипт с bg

```bash
#!/bin/bash
./heavy-task &
bg_pid=$!
echo "Задача запущена в фоне, PID: $bg_pid"
```

### Возобновление после паузы

```bash
# Запускаем vim
vim file.txt
# Ctrl+Z
bg
# Vim продолжает работать в фоне
```

### Список заданий перед bg

```bash
jobs -l
bg %1
```

### Возобновить все остановленные

```bash
for job in $(jobs -s | awk '{print $1}'); do
    bg "$job"
done
```

## Практические сценарии

### Редактирование во время выполнения задачи

```bash
./build.sh
# Ctrl+Z
bg
vim config.yaml
# Проверяем статус сборки
jobs
```

### Параллельная обработка

```bash
./process-file1.sh
# Ctrl+Z
bg
./process-file2.sh
# Ctrl+Z
bg
jobs
```

:::tip
Используйте `Ctrl+Z` для приостановки, затем `bg` для перевода в фон. Или запускайте команды сразу с `&`.
:::

:::warning
Фоновые задания могут писать вывод в терминал. Перенаправляйте вывод: `./task.sh > output.log 2>&1 &`
:::
