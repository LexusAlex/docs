# jobs

Отображает список заданий текущей оболочки.

## Синтаксис

```bash
jobs [опции] [задание ...]
```

## Опции

| Опция | Описание |
|-------|----------|
| `-l` | Вывести PID заданий |
| `-n` | Только задания, изменившиеся с последнего уведомления |
| `-p` | Вывести только PID |
| `-r` | Только выполняющиеся задания |
| `-s` | Только остановленные задания |

## Примеры

### Список всех заданий

```bash
jobs
```

### Список с PID

```bash
jobs -l
```

### Только выполняющиеся

```bash
jobs -r
```

### Только остановленные

```bash
jobs -s
```

### Только PID

```bash
jobs -p
```

### Изменившиеся задания

```bash
jobs -n
```

### Проверка перед bg/fg

```bash
jobs -l
bg %1
```

### В скриптах

```bash
# Запускаем задачи
./task1.sh &
./task2.sh &
# Проверяем
jobs -l
# Ждём завершения
wait
```

### Получение PID задания

```bash
./background-task.sh &
JOB_PID=$(jobs -p %1)
echo "PID: $JOB_PID"
```

### Проверка завершения

```bash
./long-task.sh &
while jobs -r | grep -q .; do
    sleep 1
done
echo "Все задания завершены"
```

### Статус заданий

```bash
jobs -l | awk '{print $1, $2, $NF}'
```

### Остановленные задания

```bash
if jobs -s | grep -q .; then
    echo "Есть остановленные задания"
    jobs -s
fi
```

### Все задания с подробностями

```bash
jobs -l 2>&1
```

### Проверка наличия заданий

```bash
if [ -z "$(jobs -r)" ]; then
    echo "Нет активных заданий"
fi
```

## Практические сценарии

### Мониторинг фоновых задач

```bash
while true; do
    clear
    echo "=== Фоновые задания ==="
    jobs -l
    sleep 5
done
```

### Ожидание завершения всех задач

```bash
./task1.sh &
./task2.sh &
./task3.sh &
# Ждём завершения
wait
echo "Все задачи завершены"
```

### Автоматическая обработка

```bash
for file in *.csv; do
    process_file "$file" &
done
# Проверяем статус
jobs -l
```

:::tip
Задания существуют только в текущей сессии оболочки. После закрытия терминала список заданий теряется.
:::

:::warning
В неинтерактивных оболочках (скрипты) job control по умолчанию отключён. Используйте `set -m` для включения.
:::
