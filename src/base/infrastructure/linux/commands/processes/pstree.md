# pstree

Отображает процессы в виде дерева, показывая иерархию родитель-потомок.

## Синтаксис

```bash
pstree [опции] [PID|пользователь]
```

## Опции

| Опция | Описание |
|-------|----------|
| `-p` | Показать PID процессов |
| `-u` | Показать переключения UID |
| `-a` | Показать аргументы командной строки |
| `-h` | Подсветить текущий процесс |
| `-l` | Длинные строки (без обрезки) |
| `-n` | Сортировка по PID |
| `-s` | Показать родительские процессы |
| `-G` | Изображение формата (graphviz) |
| `-H PID` | Подсветить процесс по PID |

## Примеры

### Дерево всех процессов

```bash
pstree
```

### С PID

```bash
pstree -p
```

### С аргументами командной строки

```bash
pstree -a
```

### Дерево конкретного процесса

```bash
pstree 1234
```

### С подсветкой

```bash
pstree -h
```

### Сортировка по PID

```bash
pstree -n
```

### Показать переключения пользователя

```bash
pstree -u
```

### Длинные строки без обрезки

```bash
pstree -l
```

### Показать предков процесса

```bash
pstree -s 1234
```

### Дерево процессов пользователя

```bash
pstree www-data
```

### Все процессы с PID и аргументами

```bash
pstree -ap
```

### Подсветить конкретный процесс

```bash
pstree -H 1234
```

### Экспорт в граф

```bash
pstree -G > process_tree.dot
```

## Практические сценарии

### Анализ дочерних процессов сервиса

```bash
pstree -ap $(pidof -s nginx)
```

### Отладка дочерних процессов

```bash
pstree -apu
```

### Проверка процессов-зомби

```bash
pstree -p | grep -i zombie
```

:::tip
`pstree` объединяет одинаковые ветви с помощью `[N*N]`, что делает вывод компактнее.
:::

:::warning
`pstree` показывает снимок состояния. Для динамического мониторинга используйте `top` или `htop`.
:::
