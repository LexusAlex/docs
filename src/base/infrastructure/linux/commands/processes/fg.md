# fg

Переводит фоновое задание на передний план (foreground).

## Синтаксис

```bash
fg [задание]
```

## Опции

| Опция | Описание |
|-------|----------|
| `%номер` | Номер задания из `jobs` |
| `%строка` | Задание, начинающееся со строки |
| `%?строка` | Задание, содержащее строку |
| `%+` или `%%` | Текущее задание |
| `%-` | Предыдущее задание |

## Примеры

### Перевести текущее задание

```bash
fg
```

### Перевести задание по номеру

```bash
fg %1
```

### Перевести задание по имени

```bash
fg %vim
```

### Перевести предыдущее задание

```bash
fg %-
```

### Перевести задание по части имени

```bash
fg %?py
```

### Типичный workflow

```bash
# Запускаем в фоне
./long-task.sh &
# Проверяем задания
jobs
# Переводим на передний план
fg %1
```

### После приостановки

```bash
vim file.txt
# Ctrl+Z
bg
# Работаем в другой программе
fg
```

### Проверка перед fg

```bash
jobs -l
fg %2
```

### Переключение между заданиями

```bash
./task1.sh &
./task2.sh &
fg %1
# Ctrl+Z
fg %2
# Ctrl+Z
fg %1
```

### fg с переменной

```bash
fg %$JOB_NUMBER
```

### Скрипт с fg

```bash
#!/bin/bash
./background-task &
sleep 5
fg
```

## Практические сценарии

### Переключение между задачами

```bash
# Запускаем сборку
./build.sh &
# Работаем с кодом
vim src/main.go
# Проверяем сборку
fg %1
```

### Временная приостановка

```bash
# Запускаем сервер
./start-server.sh
# Нужно что-то проверить
# Ctrl+Z
bg
# Проверяем
curl localhost:8080
# Возвращаемся к серверу
fg
```

### Интерактивная программа в фоне

```bash
# Запускаем top
top
# Ctrl+Z
bg
# Делаем другие дела
fg
```

:::tip
Используйте `Ctrl+Z` + `bg` для временного переключения, затем `fg` для возврата к задаче.
:::

:::warning
Если в фоне несколько заданий, `fg` без аргумента переведёт текущее (последнее приостановленное).
:::
