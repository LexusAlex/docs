# pkill

Завершает процессы по имени и другим атрибутам.

## Синтаксис

```bash
pkill [опции] шаблон
```

## Опции

| Опция | Описание |
|-------|----------|
| `-f` | Сопоставление с полной командной строкой |
| `-u пользователь` | Фильтр по пользователю |
| `-P PPID` | Фильтр по родительскому PID |
| `-t терминал` | Фильтр по терминалу |
| `-x` | Точное совпадение имени |
| `-c` | Подсчёт совпадений |
| `-o` | Самый старый процесс |
| `-n` | Самый новый процесс |
| `-s сигнал` | Отправить указанный сигнал |
| `--older-than время` | Только старше указанного времени |
| `--younger-than время` | Только моложе указанного времени |

## Примеры

### Завершить процессы по имени

```bash
pkill nginx
```

### Принудительное завершение

```bash
pkill -9 nginx
```

### Поиск по полной команде

```bash
pkill -f "python manage.py"
```

### Процессы пользователя

```bash
pkill -u testuser
```

### Дочерние процессы родителя

```bash
pkill -P 1234
```

### Процессы на терминале

```bash
pkill -t pts/0
```

### Точное совпадение имени

```bash
pkill -x "node"
```

### Подсчёт процессов

```bash
pkill -c -f "worker"
```

### Самый старый процесс

```bash
pkill -o sshd
```

### Самый новый процесс

```bash
pkill -n sshd
```

### Отправить SIGHUP

```bash
pkill -s HUP nginx
```

### Завершить старые процессы

```bash
pkill --older-than 1h myapp
```

### Завершить дочерние процессы

```bash
pkill -P $(pidof -s parent-daemon)
```

### Паттерн pgrep + pkill

```bash
# Сначала проверяем, потом завершаем
pgrep -f "stale-worker" && pkill -f "stale-worker"
```

## Практические сценарии

### Завершение всех процессов пользователя

```bash
pkill -u testuser -TERM
sleep 5
pkill -u testuser -KILL
```

### Очистка зависших сессий

```bash
pkill -t pts/1
```

### Завершение дочерних процессов

```bash
pkill -P $(pidof -s myserver)
```

### Автоматический перезапуск

```bash
if pgrep -x myapp > /dev/null; then
    pkill -x myapp
    sleep 2
fi
myapp &
```

:::tip
Используйте `pgrep` для предварительного просмотра, затем `pkill` для завершения. Это безопаснее.
:::

:::warning
`pkill` по умолчанию завершает процессы с совпадающим именем. Используйте `-x` для точного совпадения.
:::
