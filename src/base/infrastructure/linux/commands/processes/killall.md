# killall

**Уровень:** Средний

Завершает процессы по имени.

## Синтаксис

```bash
killall [опции] имя_процесса
```

## Опции

| Опция | Описание |
|-------|----------|
| `-i` | Интерактивный режим (подтверждение) |
| `-v` | Подробный вывод |
| `-u пользователь` | Только процессы пользователя |
| `-e` | Точное совпадение имени |
| `-I` | Игнорировать регистр |
| `-r` | Использовать регулярные выражения |
| `-s сигнал` | Отправить указанный сигнал |
| `--older-than время` | Только старше указанного времени |
| `--younger-than время` | Только моложе указанного времени |

## Примеры

### Завершить все процессы по имени

```bash
killall nginx
```

### Принудительное завершение

```bash
killall -9 firefox
```

### Интерактивный режим

```bash
killall -i chrome
```

### Подробный вывод

```bash
killall -v myapp
```

### Процессы конкретного пользователя

```bash
killall -u www-data apache2
```

### Точное совпадение имени

```bash
killall -e node
```

### С игнорированием регистра

```bash
killall -I Nginx
```

### По регулярному выражению

```bash
killall -r "^python.*"
```

### Отправить SIGHUP

```bash
killall -s HUP sshd
```

### Завершить старые процессы

```bash
killall --older-than 1h myworker
```

### Завершить процессы моложе 5 минут

```bash
killall --younger-than 5m myapp
```

### Список всех сигналов

```bash
killall -l
```

### Завершить все процессы Python

```bash
killall -r "python[0-9.]*"
```

### Завершить процессы на определённом порту

```bash
killall -v node
```

## Практические сценарии

### Перезапуск сервиса

```bash
killall -s HUP mydaemon
```

### Очистка зависших процессов

```bash
killall -9 zombie-process
```

### Завершение процессов перед деплоем

```bash
killall -TERM myapp && sleep 5 && killall -KILL myapp 2>/dev/null
```

:::tip
Используйте `-e` для точного совпадения, чтобы случайно не завершить процессы с похожими именами.
:::

:::warning
`killall` без `-e` может завершить процессы с похожими именами. На Solaris `killall` завершает ВСЕ процессы — будьте осторожны!
:::
