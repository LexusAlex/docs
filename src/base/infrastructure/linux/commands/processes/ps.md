# ps

**Уровень:** Начинающий

Выводит информацию о текущих процессах системы.

## Синтаксис

```bash
ps [опции]
```

## Опции

| Опция | Описание |
|-------|----------|
| `aux` | BSD-синтаксис: все процессы всех пользователей |
| `-ef` | UNIX-синтаксис: все процессы в полном формате |
| `-o формат` | Пользовательский формат вывода |
| `--sort поле` | Сортировка по полю (+ по возрастанию, - по убыванию) |
| `-p PID` | Выбор по PID |
| `-u пользователь` | Выбор по пользователю |
| `-C имя` | Выбор по имени команды |
| `--forest` | Древовидный вид процессов |
| `-e` | Все процессы |
| `-f` | Полный формат |
| `-H` | Древовидный формат (UNIX) |
| `-L` | Потоки (LWP и NLWP) |

## Столбцы вывода

| Столбец | Описание |
|---------|----------|
| `PID` | Идентификатор процесса |
| `USER` | Владелец процесса |
| `%CPU` | Использование CPU в % |
| `%MEM` | Использование памяти в % |
| `VSZ` | Виртуальный размер памяти (КБ) |
| `RSS` | Резидентный размер памяти (КБ) |
| `TTY` | Управляющий терминал |
| `STAT` | Состояние процесса |
| `START` | Время запуска |
| `TIME` | Накопленное время CPU |
| `COMMAND` | Команда с аргументами |

## Состояния процессов

| Символ | Состояние |
|--------|-----------|
| `R` | Running — выполняется |
| `S` | Sleeping — спит (ожидание) |
| `D` | Disk sleep — ожидание диска (не прерывается) |
| `Z` | Zombie — зомби |
| `T` | Stopped — остановлен |

## Примеры

### Все процессы (BSD)

```bash
ps aux
```

### Все процессы (UNIX)

```bash
ps -ef
```

### Процессы конкретного пользователя

```bash
ps -u www-data
```

### Процесс по PID

```bash
ps -p 1234
```

### Процессы по имени команды

```bash
ps -C nginx
```

### Пользовательский формат вывода

```bash
ps -eo pid,user,%cpu,%mem,stat,cmd
```

### Сортировка по использованию CPU

```bash
ps aux --sort=-%cpu
```

### Сортировка по использованию памяти

```bash
ps aux --sort=-%mem
```

### Древовидный вид

```bash
ps aux --forest
```

### Топ-10 процессов по CPU

```bash
ps aux --sort=-%cpu | head -11
```

### Топ-10 процессов по памяти

```bash
ps aux --sort=-%mem | head -11
```

### Показать потоки процесса

```bash
ps -L -p 1234
```

### Процессы с полным путём команды

```bash
ps -eo pid,user,cmd --cols 132
```

## Практические сценарии

### Поиск утечки памяти

```bash
watch -n 5 'ps aux --sort=-%mem | head -20'
```

### Мониторинг процесса по PID

```bash
watch -n 2 'ps -p 1234 -o pid,user,%cpu,%mem,etime,cmd'
```

### Найти все дочерние процессы

```bash
ps --ppid 1234
```

:::tip
Для интерактивного мониторинга используйте `htop` или `top`. Команда `ps` лучше подходит для скриптов и одноразового вывода.
:::

:::warning
Поле `COMMAND` может быть обрезано. Используйте `-o cmd --cols 200` для полного вывода.
:::

## Связки с другими командами

```bash
# Получить PID процессов nginx (исключая сам grep)
ps aux | grep nginx | grep -v grep | awk '{print $2}'

# Топ-10 процессов по использованию CPU
ps aux --sort=-%cpu | head -10

# Топ-10 процессов по использованию памяти
ps aux --sort=-%mem | head -10

# Общий объём памяти, используемый всеми процессами (в МБ)
ps aux | awk '{sum+=$6} END {print sum/1024 " MB"}'

# Топ-20 процессов по CPU с родительским PID
ps -eo pid,ppid,cmd,%mem,%cpu --sort=-%cpu | head -20

# Подсчитать количество зомби-процессов
ps aux | grep -c "defunct"

# Команды, использующие более 50% CPU
ps aux | awk '$3>50 {print $11}'

# Полная информация о процессах nginx через pgrep
pgrep -x nginx | xargs ps -p

# Найти все дочерние процессы конкретного родителя и показать их потребление ресурсов
ps --ppid $(pgrep -o sshd) -o pid,ppid,%cpu,%mem,cmd

# Список процессов, работающих дольше 1 часа, с использованием памяти
ps -eo pid,etime,%mem,cmd --sort=-%mem | awk 'NR>1 && $2~/^([0-9]+-)?([0-9]{2}):/ {print}'
```
