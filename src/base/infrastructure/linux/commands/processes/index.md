# Управление процессами

Просмотр, управление и мониторинг процессов. Приоритеты, сигналы, фоновые задачи.

## Команды

| Команда | Описание |
|---------|----------|
| [ps](ps.md) | Список процессов |
| [pgrep](pgrep.md) | Поиск PID по имени процесса |
| [pidof](pidof.md) | PID запущенной программы |
| [pstree](pstree.md) | Дерево процессов |
| [kill](kill.md) | Отправка сигнала процессу |
| [killall](killall.md) | Убить процессы по имени |
| [pkill](pkill.md) | Убить процессы по шаблону |
| [nice](nice.md) | Запуск с заданным приоритетом |
| [renice](renice.md) | Изменение приоритета запущенного процесса |
| [nohup](nohup.md) | Игнорирование SIGHUP при закрытии терминала |
| [bg](bg.md) | Перевод задачи в фон |
| [fg](fg.md) | Перевод задачи на передний план |
| [jobs](jobs.md) | Список фоновых задач |
| [timeout](timeout.md) | Ограничение времени выполнения |

## Сигналы

| Сигнал | Номер | Описание |
|--------|-------|----------|
| `SIGHUP` | 1 | Перезапуск (закрытие терминала) |
| `SIGINT` | 2 | Прерывание (Ctrl+C) |
| `SIGKILL` | 9 | Принудительное завершение |
| `SIGTERM` | 15 | Корректное завершение (по умолчанию) |
| `SIGSTOP` | 19 | Приостановка (Ctrl+Z) |
| `SIGCONT` | 18 | Продолжение выполнения |
