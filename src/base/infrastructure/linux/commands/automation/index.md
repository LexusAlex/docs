# Автоматизация

Утилиты для автоматизации интерактивных задач и изоляции окружений.

## Команды

| Команда | Описание |
|---------|----------|
| [expect](expect.md) | Автоматизация интерактивных программ (ввод паролей, диалоги) |
| [chroot](chroot.md) | Изоляция процессов в отдельном корневом каталоге |

## Когда использовать

### expect

- Автоматический SSH-вход с паролем
- Смена паролей через скрипт
- Интерактивные установщики
- Управление сетевым оборудованием (Cisco, MikroTik)
- Пакетное выполнение команд на серверах

### chroot

- Восстановление системы (загрузчик, пароли)
- Тестирование в изолированной среде
- Сборка пакетов
- Ограничение доступа приложений
