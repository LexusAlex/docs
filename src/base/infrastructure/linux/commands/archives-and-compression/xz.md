# xz

**Уровень:** Средний

Утилита сжатия на основе алгоритма LZMA2. Обеспечивает наилучшую степень сжатия среди стандартных утилит Linux.

## Синтаксис

```bash
xz [опции] [файлы]
```

## Опции

| Опция | Описание |
|-------|----------|
| `-d` | Распаковать (эквивалент `unxz`) |
| `-k` | Сохранить исходный файл |
| `-0` .. `-9` | Уровень сжатия (0 — быстро, 9 — максимально) |
| `--extreme` | Экстремальное сжатие (медленнее, но лучше) |
| `-T потоков` | Количество потоков (многопоточность) |
| `-v` | Подробный вывод |
| `-l` | Показать информацию о сжатом файле |
| `-t` | Проверить целостность |
| `-c` | Вывод в stdout |
| `-f` | Принудительная перезапись |
| `-M лимит` | Ограничение памяти |

## Сравнение с gzip и bzip2

| Параметр | gzip | bzip2 | xz |
|----------|------|-------|----|
| Алгоритм | DEFLATE | BWT | LZMA2 |
| Скорость | Высокая | Средняя | Низкая |
| Сжатие | Среднее | Хорошее | Лучшее |
| Память | 1-8 МБ | 1-8 МБ | 5-95 МБ |
| Многопоточность | Нет | Нет | Да |
| Расширение | `.gz` | `.bz2` | `.xz` |

## Примеры

### Сжатие файла

```bash
xz file.txt
```

### Сжатие с сохранением оригинала

```bash
xz -k file.txt
```

### Максимальное сжатие

```bash
xz -9 hugefile.tar
```

### Экстремальное сжатие

```bash
xz -9 --extreme archive.tar
```

### Многопоточное сжатие

```bash
xz -T 4 largefile.tar
```

### Автоматическое определение потоков

```bash
xz -T 0 largefile.tar
```

### Распаковка

```bash
xz -d file.txt.xz
```

### Просмотр информации

```bash
xz -l archive.xz
```

### Проверка целостности

```bash
xz -t archive.xz
```

### Сжатие в stdout

```bash
xz -c file.txt > file.txt.xz
```

## Практические сценарии

### Архивное сжатие с максимальным сжатием

```bash
xz -9 --extreme -k important-backup.tar
```

### Параллельное сжатие больших файлов

```bash
xz -T $(nproc) -k huge-database-dump.sql
```

### Создание tar.xz

```bash
tar -cJf system-backup.tar.xz /etc
```

### Сравнение размеров

```bash
ls -lh data.tar
gzip -k data.tar && ls -lh data.tar.gz
bzip2 -k data.tar && ls -lh data.tar.bz2
xz -k data.tar && ls -lh data.tar.xz
```

:::tip
Используйте `-T 0` для автоматического использования всех доступных ядер процессора. Это значительно ускоряет сжатие больших файлов.
:::

:::warning
`xz` потребляет значительно больше памяти чем `gzip` или `bzip2`. На серверах с ограниченными ресурсами используйте `-M` для ограничения или выберите `-1` для быстрого сжатия.
:::
