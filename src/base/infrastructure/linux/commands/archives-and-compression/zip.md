# zip

**Уровень:** Средний

Утилита для создания архивов в формате ZIP. Широко используется для совместимости с Windows и веб-загрузками.

## Синтаксис

```bash
zip [опции] архив.zip [файлы/директории]
```

## Опции

| Опция | Описание |
|-------|----------|
| `-r` | Рекурсивное добавление директорий |
| `-e` | Шифрование паролем |
| `-9` | Максимальное сжатие |
| `-q` | Тихий режим |
| `-v` | Подробный вывод |
| `-u` | Обновление (добавить новые/изменённые файлы) |
| `-x паттерн` | Исключить файлы по шаблону |
| `-i паттерн` | Включить только указанные файлы |
| `-0` | Без сжатия (только упаковка) |
| `-1` | Минимальное сжатие (быстро) |
| `-6` | Сжатие по умолчанию |
| `-P пароль` | Задать пароль (небезопасно в командной строке) |
| `-F` | Исправить повреждённый архив |
| `-z` | Добавить комментарий |

## Примеры

### Создание архива из файлов

```bash
zip archive.zip file1.txt file2.txt file3.txt
```

### Архивирование директории рекурсивно

```bash
zip -r archive.zip /home/user/docs
```

### Максимальное сжатие

```bash
zip -9 -r archive.zip /var/www/site
```

### Шифрование паролем

```bash
zip -e -r secure.zip /home/user/important
```

### Исключение файлов

```bash
zip -r archive.zip project/ -x "*.log" -x "*.tmp"
```

### Обновление архива

```bash
zip -u archive.zip newfile.txt updated-file.txt
```

### Добавление файлов в существующий архив

```bash
zip archive.zip additional-file.txt
```

### Тихий режим

```bash
zip -q -r archive.zip /large/directory
```

### Архивирование без сжатия

```bash
zip -0 -r archive.zip /path/to/files
```

### Включение только определённых файлов

```bash
zip -r archive.zip project/ -i "*.py" "*.js"
```

### Сборка с комментарием

```bash
zip -r -z archive.zip /project
```

### Архивирование с паролем через переменную

```bash
read -s PASS && zip -P "$PASS" secure.zip file.txt
```

## Практические сценарии

### Бэкап веб-сайта

```bash
zip -r /backup/site-$(date +%F).zip /var/www/html \
  -x "*.log" -x "cache/*"
```

### Архивирование исходников без зависимостей

```bash
zip -r src.zip project/ -x "node_modules/*" -x ".git/*" -x "*.pyc"
```

### Создание архива для загрузки

```bash
zip -9 -r release.zip dist/ README.md LICENSE
```

### Проверка размера архива перед созданием

```bash
zip -r -q archive.zip large-dir/ && ls -lh archive.zip
```

:::tip
Для шифрования используйте `-e` интерактивно (запросит пароль). Не передавайте пароль через `-P` в командной строке — он будет виден в `ps` и истории.
:::

:::warning
Формат ZIP не поддерживает Unix-права файлов полностью. Для сохранения прав используйте `tar` с сжатием.
:::
