# Архивы и сжатие

Создание архивов, сжатие и распаковка файлов.

| Команда | Описание |

| [bzip2](bzip2.md) | Сжатие bzip2 |

## Сравнение алгоритмов сжатия

| Алгоритм | Скорость | Степень сжатия | Расширение |
|----------|----------|----------------|------------|
| gzip | Быстрая | Средняя | `.gz` |
| bzip2 | Средняя | Высокая | `.bz2` |
| xz | Медленная | Максимальная | `.xz` |
| zstd | Быстрая | Высокая | `.zst` |

## Типичные паттерны

```bash
# Создать архив
tar -czf archive.tar.gz /path/to/dir

# Распаковать архив
tar -xzf archive.tar.gz

# Посмотреть содержимое
tar -tzf archive.tar.gz

# Сжать файл
gzip file.txt          # file.txt → file.txt.gz

# Распаковать
gunzip file.txt.gz     # file.txt.gz → file.txt
```

## tar vs zip vs 7z

| Характеристика | tar (+ gzip) | zip | 7z |
|----------------|-------------|-----|-----|
| Unix/Linux | Стандарт | Распространён | Дополнительно |
| Windows | Нужен 7-Zip | Встроен | Нужен 7-Zip |
| Сжатие | Внешнее (gzip/bzip2/xz) | Встроенное | Встроенное |
| Права Unix | Сохраняет | Не сохраняет | Сохраняет |
| Символьные ссылки | Сохраняет | Не сохраняет | Сохраняет |
| Многотомные архивы | Да | Нет | Да |

### Когда что использовать

- **tar.gz** — стандарт для Linux-архивов, сохраняет права и ссылки
- **zip** — когда нужно открыть на Windows без дополнительного ПО
- **tar.xz** — максимальное сжатие (используется в дистрибутивах)
- **7z** — лучшее сжатие, пароли, мультитомность
