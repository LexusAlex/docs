# unzip

Утилита для распаковки архивов формата ZIP.

## Синтаксис

```bash
unzip [опции] архив.zip [файлы] [-d директория]
```

## Опции

| Опция | Описание |
|-------|----------|
| `-l` | Показать содержимое без распаковки |
| `-d директория` | Распаковать в указанную директорию |
| `-o` | Перезаписать существующие файлы без запроса |
| `-n` | Не перезаписывать существующие файлы |
| `-q` | Тихий режим |
| `-v` | Подробная информация о содержимом |
| `-t` | Проверить целостность архива |
| `-p` | Извлечь в stdout (без путей) |
| `-j` | Игнорировать структуру директорий |
| `-x паттерн` | Исключить файлы |
| `-P пароль` | Пароль для зашифрованного архива |
| `-f` | Обновить только существующие файлы |

## Примеры

### Распаковка архива

```bash
unzip archive.zip
```

### Распаковка вопределённную директорию

```bash
unzip archive.zip -d /tmp/extract
```

### Просмотр содержимого

```bash
unzip -l archive.zip
```

### Подробная информация о содержимом

```bash
unzip -v archive.zip
```

### Перезапись без запроса

```bash
unzip -o archive.zip
```

### Без перезаписи

```bash
unzip -n archive.zip
```

### Проверка целостности

```bash
unzip -t archive.zip
```

### Извлечениеопределённных файлов

```bash
unzip archive.zip "docs/*.md"
```

### Извлечение без структуры директорий

```bash
unzip -j archive.zip
```

### Извлечение зашифрованного архива

```bash
unzip -P mypassword secure.zip
```

### Тихий режим

```bash
unzip -q archive.zip
```

### Обновление существующих файлов

```bash
unzip -f archive.zip
```

## Практические сценарии

### Просмотр содержимого перед распаковкой

```bash
unzip -l unknown-archive.zip | head -20
```

### Извлечениеопределённного файла

```bash
unzip archive.zip path/to/config.json
```

### Распаковка с фильтрацией

```bash
unzip archive.zip "*.txt" -d /tmp/text-files
```

### Проверка архива перед использованием

```bash
unzip -t suspicious.zip && echo "OK" || echo "CORRUPTED"
```

### Извлечение в stdout для piping

```bash
unzip -p archive.zip data.csv | head -50
```

### Массовая распаковка

```bash
for f in *.zip; do unzip -o "$f" -d "${f%.zip}"; done
```

:::tip
Используйте `-l` для предварительного просмотра содержимого архива перед распаковкой. Это помогает избежать перезаписи важных файлов.
:::

:::warning
При распаковке непроверенных архивов может произойти перезапись системных файлов. Всегда проверяйте содержимое через `-l` или распаковывайте в изолированную директорию.
:::
