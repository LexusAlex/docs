# bzip2

Утилита сжатия на основе алгоритма Burrows-Wheeler. Обеспечивает лучшее сжатие чем gzip, но работает медленнее.

## Синтаксис

```bash
bzip2 [опции] [файлы]
```

## Опции

| Опция | Описание |
|-------|----------|
| `-d` | Распаковать (эквивалент `bunzip2`) |
| `-k` | Сохранить исходный файл |
| `-1` .. `-9` | Уровень сжатия (1 — быстро, 9 — максимально) |
| `-v` | Подробный вывод |
| `-t` | Проверить целостность |
| `-c` | Вывод в stdout |
| `-f` | Принудительная перезапись |
| `-s` | Экономный режим (меньше памяти, больше времени) |

## Сравнение с gzip

| Параметр | gzip | bzip2 |
|----------|------|-------|
| Алгоритм | DEFLATE | Burrows-Wheeler |
| Скорость сжатия | Выше | Ниже |
| Степень сжатия | Средняя | Выше |
| Использование памяти | Меньше | Больше |
| Расширение | `.gz` | `.bz2` |

## Примеры

### Сжатие файла

```bash
bzip2 file.txt
```

### Сжатие с сохранением оригинала

```bash
bzip2 -k file.txt
```

### Максимальное сжатие

```bash
bzip2 -9 largefile.tar
```

### Быстрое сжатие

```bash
bzip2 -1 data.csv
```

### Распаковка

```bash
bzip2 -d file.txt.bz2
```

### Проверка целостности

```bash
bzip2 -t archive.bz2
```

### Подробный вывод

```bash
bzip2 -v *.txt
```

### Сжатие в stdout

```bash
bzip2 -c file.txt > file.txt.bz2
```

### Распаковка в stdout

```bash
bzip2 -dc file.txt.bz2
```

### Сжатие нескольких файлов

```bash
bzip2 file1.txt file2.txt file3.txt
```

### Экономный режим

```bash
bzip2 -s hugefile.tar
```

## Практические сценарии

### Сжатие логов старше 7 дней

```bash
find /var/log -name "*.log" -mtime +7 -exec bzip2 -v {} \;
```

### Создание tar.bz2 архива

```bash
tar -cjf backup.tar.bz2 /home/user
```

### Сравнение размеров после сжатия

```bash
ls -lh file.txt && bzip2 -k file.txt && ls -lh file.txt.bz2
```

### Пакетное сжатие

```bash
find . -name "*.xml" -exec bzip2 -k {} \;
```

:::tip
Используйте `bzip2` когда степень сжатия важнее скорости. Для лог-файлов и текстовых данных `bzip2` даёт на 10-15% лучшее сжатие чем `gzip`.
:::

:::warning
`bzip2` требует больше оперативной памяти (до 8 МБ для уровня 9). На системах с ограниченной памятью используйте `-s` или низкие уровни сжатия.
:::
