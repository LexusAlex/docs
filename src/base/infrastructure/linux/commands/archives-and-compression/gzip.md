# gzip

**Уровень:** Средний

Утилита сжатия файлов с использованием алгоритма DEFLATE. Заменяет исходный файл сжатым с добавлением расширения `.gz`.

## Синтаксис

```bash
gzip [опции] [файлы]
```

## Опции

| Опция | Описание |
|-------|----------|
| `-d` | Распаковать (эквивалент `gunzip`) |
| `-k` | Сохранить исходный файл |
| `-1` .. `-9` | Уровень сжатия (1 — быстро, 9 — максимально) |
| `-r` | Рекурсивное сжатие директорий |
| `-v` | Подробный вывод (имя, процент сжатия) |
| `-l` | Показать информацию о сжатом файле |
| `-t` | Проверить целостность сжатого файла |
| `-c` | Вывод в stdout, исходный файл не изменяется |
| `-f` | Принудительная перезапись |
| `-N` | Сохранить/восстановить имя и время файла |

## Уровни сжатия

| Уровень | Скорость | Степень сжатия | Использование |
|---------|----------|----------------|---------------|
| `-1` | Максимальная | Минимальная | Временные файлы |
| `-6` | Средняя | Средняя | По умолчанию |
| `-9` | Минимальная | Максимальная | Архивное хранение |

## Примеры

### Сжатие файла

```bash
gzip file.txt
```

### Сжатие с сохранением исходного файла

```bash
gzip -k file.txt
```

### Максимальное сжатие

```bash
gzip -9 archive.tar
```

### Быстрое сжатие

```bash
gzip -1 largefile.log
```

### Распаковка файла

```bash
gzip -d file.txt.gz
```

### Просмотр информации о сжатом файле

```bash
gzip -l file.txt.gz
```

### Проверка целостности

```bash
gzip -t file.txt.gz
```

### Сжатие с подробным выводом

```bash
gzip -v *.txt
```

### Рекурсивное сжатие директории

```bash
gzip -r /var/log/old-logs/
```

### Сжатие в stdout

```bash
gzip -c file.txt > /backup/file.txt.gz
```

### Сжатие нескольких файлов

```bash
gzip file1.txt file2.txt file3.txt
```

## Практические сценарии

### Сжатие лог-файлов

```bash
find /var/log -name "*.log" -mtime +7 -exec gzip -v {} \;
```

### Просмотр размеров до и после сжатия

```bash
gzip -lv *.gz
```

### Быстрое сжатие для передачи по сети

```bash
gzip -1 -c largefile > largefile.fast.gz
```

### Архивное сжатие с максимальной степенью

```bash
gzip -9 -k important-data.csv
```

:::tip
Уровень сжатия по умолчанию — `-6`. Для лог-файлов и текста разница между `-6` и `-9` обычно составляет 5-10%, но время сжатия увеличивается значительно.
:::

:::warning
`gzip` заменяет исходный файл сжатым. Используйте `-k` для сохранения оригинала, если он ещё нужен.
:::
