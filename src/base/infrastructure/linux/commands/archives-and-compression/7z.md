# 7z

Командная обёртка для 7-Zip (p7zip). Поддерживает множество форматов: 7z, ZIP, GZIP, TAR, BZIP2, XZ и другие.

## Синтаксис

```bash
7z [команда] [опции] архив [файлы]
```

## Команды

| Команда | Описание |
|---------|----------|
| `a` | Добавить файлы в архив |
| `x` | Извлечь с сохранением путей |
| `e` | Извлечь без путей (все в одну директорию) |
| `l` | Показать содержимое |
| `t` | Проверить целостность |
| `u` | Обновить архив |
| `d` | Удалить файлы из архива |

## Опции

| Опция | Описание |
|-------|----------|
| `-p[пароль]` | Задать пароль |
| `-m0=[метод]` | Метод сжатия (LZMA, LZMA2, PPMd, BZip2) |
| `-mx=[0-9]` | Уровень сжатия |
| `-mhe=on` | Шифровать заголовок архива |
| `-t=[тип]` | Тип архива (7z, zip, gzip, tar, bzip2) |
| `-r` | Рекурсивно |
| `-y` | Подтвердить все запросы |
| `-o[директория]` | Директория для извлечения |

## Примеры

### Создание 7z архива

```bash
7z a archive.7z /home/user/docs
```

### Извлечение архива

```bash
7z x archive.7z
```

### Просмотр содержимого

```bash
7z l archive.7z
```

### Проверка целостности

```bash
7z t archive.7z
```

### Шифрование паролем

```bash
7z a -pMySecret -mhe=on secure.7z /important/data
```

### Создание ZIP архива

```bash
7z a -tzip archive.zip /project
```

### Максимальное сжатие LZMA2

```bash
7z a -m0=LZMA2 -mx=9 archive.7z hugefile.tar
```

### Извлечение без путей

```bash
7z e archive.7z -o/tmp/extract
```

### Обновление архива

```bash
7z u archive.7z newfile.txt
```

### Удаление файла из архива

```bash
7z d archive.7z unwanted-file.txt
```

### Рекурсивное добавление

```bash
7z a -r archive.7z /var/log/*.log
```

## Практические сценарии

### Бэкап с шифрованием

```bash
7z a -p$(cat /root/.backup-pass) -mhe=on \
  /backup/secure-$(date +%F).7z /home /etc
```

### Конвертация между форматами

```bash
7z x archive.zip -o/tmp/src && 7z a -m0=LZMA2 archive.7z /tmp/src/*
```

### Проверка скачанного архива

```bash
7z t downloaded-archive.7z
```

### Создание самораспаковывающегося архива

```bash
7z a -sfx archive.exe /project
```

### Извлечениеопределённных файлов

```bash
7z x archive.7z "*.txt" "*.md"
```

:::tip
`7z` поддерживает множество форматов (7z, zip, gzip, bzip2, xz, tar, wim, и др.). Используйте `-tтип` для явного указания формата при создании.
:::

:::warning
Архивы 7z с LZMA2 и высоким уровнем сжатия потребляют много памяти. На серверах с ограниченными ресурсами используйте `-mx=5` или ниже.
:::
