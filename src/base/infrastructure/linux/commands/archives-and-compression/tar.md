# tar

**Уровень:** Средний

Утилита для создания, извлечения и управления архивами. Поддерживает сжатие через внешние компрессоры (gzip, bzip2, xz).

## Синтаксис

```bash
tar [опции] [файл архива] [файлы/директории]
```

## Опции

| Опция | Описание |
|-------|----------|
| `-c` | Создать новый архив |
| `-x` | Извлечь файлы из архива |
| `-t` | Показать содержимое архива |
| `-f файл` | Указать имя архива |
| `-v` | Подробный вывод (verbose) |
| `-z` | Сжатие через gzip (.tar.gz, .tgz) |
| `-j` | Сжатие через bzip2 (.tar.bz2) |
| `-J` | Сжатие через xz (.tar.xz) |
| `-a` | Автоопределение сжатия по расширению |
| `-C директория` | Извлечение в указанную директорию |
| `--exclude=паттерн` | Исключить файлы по шаблону |
| `--strip-components=N` | Удалить N компонентов пути при извлечении |
| `-p` | Сохранить права файлов |
| `-h` | Следовать символическим ссылкам |
| `--totals` | Показать объём записанных данных |
| `-W` | Проверить целостность архива |

## Примеры

### Создание архива из директории

```bash
tar -cf archive.tar /home/user/docs
```

### Создание архива с сжатием gzip

```bash
tar -czf archive.tar.gz /home/user/docs
```

### Создание архива с сжатием bzip2

```bash
tar -cjf archive.tar.bz2 /home/user/docs
```

### Создание архива с сжатием xz

```bash
tar -cJf archive.tar.xz /home/user/docs
```

### Автоопределение сжатия

```bash
tar -caf archive.tar.gz /home/user/docs
```

### Извлечение архива

```bash
tar -xzf archive.tar.gz
```

### Извлечение вопределённную директорию

```bash
tar -xzf archive.tar.gz -C /tmp/extract
```

### Просмотр содержимого архива

```bash
tar -tzf archive.tar.gz
```

### Подробный вывод при создании

```bash
tar -czvf backup.tar.gz /etc /home
```

### Исключение файлов

```bash
tar -czf backup.tar.gz --exclude='*.log' --exclude='.cache' /home/user
```

### Извлечение с удалением лишних компонентов пути

```bash
tar -xzf archive.tar.gz --strip-components=1
```

### Резервное копирование с сохранением прав

```bash
tar -czpf system-backup.tar.gz --exclude=/proc --exclude=/sys --exclude=/dev /
```

### Добавление файлов в существующий архив

```bash
tar -rf archive.tar newfile.txt
```

## Практические сценарии

### Ежедневный бэкап

```bash
tar -czf /backup/home-$(date +%F).tar.gz /home
```

### Инкрементальный бэкап

```bash
tar -czf /backup/inc-$(date +%F).tar.gz \
  --newer-mtime="2026-01-01" /home
```

### Извлечение одного файла из архива

```bash
tar -xzf archive.tar.gz path/to/file.txt
```

### Просмотр размеров файлов в архиве

```bash
tar -tvf archive.tar | awk '{print $3, $NF}' | sort -n
```

:::tip
Используйте `-a` для автоматического определения типа сжатия по расширению файла. Это избавит от необходимости помнить флаги `-z`, `-j`, `-J`.
:::

:::warning
При извлечении архива из непроверенного источника всегда сначала просматривайте содержимое через `-t`, чтобы избежать перезаписи системных файлов (атака «tar slip»).
:::
