# Текстовые редакторы

Редактирование текстовых файлов из командной строки.

## Редакторы

| Команда | Описание |
|---------|----------|
| [nano](nano.md) | Простой редактор для новичков |
| [vim](vim.md) | Продвинутый редактор с модальным вводом |

## Сравнение

| Характеристика | nano | vim |
|----------------|------|-----|
| Сложность | Низкая | Высокая |
| Горячие клавиши | Показаны внизу | Нужно знать |
| Режимы | Один | Несколько (Normal, Insert, Visual) |
| Скрипты | Нет | VimScript, Lua |
| Плагины | Нет | Огромная экосистема |
| Производительность | Средняя | Высокая |

## Когда что использовать

| Сценарий | Редактор | Почему |
|----------|----------|--------|
| Быстрая правка конфига | `nano` | Простой, подсказки внизу |
| Длительная работа с кодом | `vim` | Мощные команды, макросы |
| Нет графики, сервер | `vim` или `nano` | Оба работают в терминале |
| Нужно что-то быстро записать | `nano` | Минимум нажатий |
| Поиск и замена по файлам | `vim` (`:%s/old/new/g`) | Regex, множественные замены |
| Работа с несколькими файлами | `vim` (`:tabedit`, `:split`) | Вкладки и сплиты |

## Шпаргалка vim

### Режимы

| Режим | Клавиша | Описание |
|-------|---------|----------|
| Normal | `Esc` | Навигация и команды |
| Insert | `i`, `a`, `o` | Ввод текста |
| Visual | `v`, `V`, `Ctrl+v` | Выделение |
| Command | `:` | Команды |

### Самые частые команды

| Действие | Команда |
|----------|---------|
| Сохранить | `:w` |
| Выйти | `:q` |
| Сохранить и выйти | `:wq` |
| Выйти без сохранения | `:q!` |
| Отменить | `u` |
| Повторить | `Ctrl+r` |
| Найти | `/pattern` |
| Заменить | `:%s/old/new/g` |
| Перейти к строке | `:42` |
| Удалить строку | `dd` |
| Скопировать строку | `yy` |
| Вставить | `p` |
