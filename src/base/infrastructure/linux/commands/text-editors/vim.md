# vim

Мощный текстовый редактор с modal-интерфейсом. Стандарт де-факто в системном администрировании и разработке на Linux.

## Синтаксис

```bash
vim [опции] [файл]
```

## Опции

| Опция | Описание |
|-------|----------|
| `+N` | Открыть файл на строке N |
| `+command` | Выполнить команду после открытия |
| `-R` | Только для чтения |
| `-d file1 file2` | Сравнение двух файлов |
| `-O file1 file2` | Открыть файлы вертикально |
| `-o file1 file2` | Открыть файлы горизонтально |
| `-p N` | Открыть N вкладок |
| `-u vimrc` | Использовать свой vimrc |
| `-c "cmd"` | Выполнить команду vim |
| `-r` | Восстановить после сбоя |
| `--clean` | Без пользовательских настроек |

## Режимы vim

| Режим | Активация | Назначение |
|-------|-----------|------------|
| Normal | `Esc` | Навигация, команды |
| Insert | `i`, `a`, `o`, `I`, `A`, `O` | Ввод текста |
| Visual | `v`, `V`, `Ctrl+v` | Выделение текста |
| Command-line | `:`, `/`, `?` | Команды и поиск |

## Поиск и замена

| Команда | Действие |
|---------|----------|
| `/pattern` | Поиск вперёд |
| `?pattern` | Поиск назад |
| `n` | Следующее совпадение |
| `N` | Предыдущее совпадение |
| `:noh` | Сбросить подсветку |
| `:s/old/new/` | Замена в текущей строке |
| `:s/old/new/g` | Все вхождения в строке |
| `:%s/old/new/g` | Все вхождения в файле |
| `:%s/old/new/gc` | С подтверждением |
| `:10,20s/old/new/g` | В строках 10-20 |

## Примеры

### Открытие файла на строке

```bash
vim +42 /etc/nginx.conf
```

### Сравнение файлов

```bash
vim -d file1.conf file2.conf
```

### Открытие в сплитах

```bash
vim -O main.py utils.py
```

### Режим только для чтения

```bash
vim -R /var/log/syslog
```

### Выполнение команды при открытии

```bash
vim -c "set number" -c "syntax on" file.txt
```

### Восстановление после сбоя

```bash
vim -r file.txt
```

### Открытие нескольких вкладок

```bash
vim -p file1.txt file2.txt file3.txt
```

### Замена во всём файле

```vim
:%s/старое/новое/g
```

### Замена с подтверждением

```vim
:%s/old/new/gc
```

### Удаление пустых строк

```vim
:g/^$/d
```

### Сортировка строк

```vim
:%!sort
```

### Блочное редактирование

```
Ctrl+v → выделить блок → I → ввести текст → Esc
```

## Практические сценарии

### Массовая замена в конфигах

```bash
vim -c "%s/localhost/production.example.com/g" -c "wq" config.yaml
```

### Добавление префикса к строкам

```bash
# В visual block mode:
Ctrl+v → выделить начало строк → I → ввести '#' → Esc
```

### Быстрое комментирование

```bash
# Выделить строки (V), затем:
:s/^/#/
```

### Форматирование JSON

```bash
vim -c "%!python3 -m json.tool" -c "wq" data.json
```

## Конфигурация ~/.vimrc

```vim
" ~/.vimrc — базовые настройки
set number              " Номера строк
set relativenumber      " Относительные номера
set tabstop=4           " Ширина табуляции
set shiftwidth=4        " Ширина отступа
set expandtab           " Пробелы вместо табов
set autoindent          " Автоотступ
set smartindent         " Умный отступ
set syntax=on           " Подсветка синтаксиса
set hlsearch            " Подсветка поиска
set incsearch           " Инкрементальный поиск
set ignorecase          " Игнорировать регистр
set smartcase           " Умный регистр
set mouse=a             " Поддержка мыши
set clipboard=unnamedplus " Системный буфер
set encoding=utf-8      " Кодировка
set wildmenu            " Автодополнение команд
set laststatus=2        " Всегда показывать статусную строку
set cursorline          " Подсветка текущей строки
set scrolloff=5         " Отступ при скроллинге
colorscheme desert      " Цветовая схема
```

:::tip Совет
Запустите `vimtutor` в терминале для интерактивного обучения vim прямо в редакторе. Доступно на многих языках, включая русский: `vimtutor ru`.
:::

:::tip Совет
Используйте `.` (точку) для повторения последнего действия — это один из самых мощных инструментов vim для эффективного редактирования.
:::

:::warning Внимание
Не выходите из vim командой `:qa!` если открыто несколько файлов — это закроет все буферы без сохранения. Используйте `:wqa` для сохранения всех файлов.
:::

## Шпаргалка

```
Выйти:          :q! (без сохранения) / :wq (с сохранением) / ZZ
Сохранить:      :w
Отменить:       u
Повторить:      Ctrl+r
Поиск:          /pattern
Замена:         :%s/old/new/g
Перейти к строке: :N или NG
Вырезать строку: dd
Вставить:       p
Макрос:         qa...q, @a
```
