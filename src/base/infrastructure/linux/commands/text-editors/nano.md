# nano

**Уровень:** Начинающий

Текстовый редактор для терминала с простым и интуитивным интерфейсом. Идеален для начинающих и быстрого редактирования файлов.

## Синтаксис

```bash
nano [опции] [файл]
```

## Опции

| Опция | Описание |
|-------|----------|
| `-m` | Включить поддержку мыши |
| `-l` | Показать номера строк |
| `-w` | Отключить перенос длинных строк |
| `-B` | Создать резервную копию при сохранении |
| `-c` | Показать позицию курсора |
| `-i` | Автоотступ |
| `-k` | Вырезать от курсора до конца строки |
| `-n` | Не использовать файл конфигурации |
| `-v` | Режим просмотра (только чтение) |
| `-T N` | Размер табуляции N пробелов |
| `+N` | Перейти к строке N при открытии |

## Навигация

| Клавиши | Действие |
|---------|----------|
| `← → ↑ ↓` | Перемещение курсора |
| `Page Up / Page Down` | Прокрутка по экрану |
| `Home / End` | Начало / конец строки |
| `Ctrl+_` | Переход к строке (по номеру) |
| `Ctrl+A` | Начало строки |
| `Ctrl+E` | Конец строки |
| `Alt+\` | Начало файла |
| `Alt+/` | Конец файла |

## Редактирование

| Клавиши | Действие |
|---------|----------|
| `Backspace` | Удалить символ слева |
| `Delete` | Удалить символ справа |
| `Ctrl+K` | Вырезать строку |
| `Ctrl+U` | Вставить вырезанное |
| `Alt+A` | Начать выделение текста |
| `Alt+6` | Копировать выделенное |
| `Ctrl+K` | Вырезать выделенное |
| `Ctrl+J` | Выровнять абзац |
| `Alt+U` | Отменить (undo) |
| `Alt+E` | Повторить (redo) |

## Поиск и замена

| Клавиши | Действие |
|---------|----------|
| `Ctrl+W` | Поиск строки |
| `Alt+W` | Найти следующее |
| `Ctrl+\` | Поиск и замена |

## Файловые операции

| Клавиши | Действие |
|---------|----------|
| `Ctrl+O` | Сохранить файл |
| `Ctrl+X` | Выйти из редактора |
| `Ctrl+R` | Вставить содержимое файла |

## Примеры

### Открытие файла

```bash
nano file.txt
```

### Открытие файла с номерами строк

```bash
nano -l config.conf
```

### Переход к строке при открытии

```bash
nano +42 script.sh
```

### Включение поддержки мыши

```bash
nano -m file.txt
```

### Отключение переноса строк

```bash
nano -w long_file.txt
```

### Создание резервных копий

```bash
nano -B important.conf
```

### Показ позиции курсора

```bash
nano -c file.txt
```

### Режим только для чтения

```bash
nano -v /etc/passwd
```

### Комбинация опций

```bash
nano -lwcB config.yaml
```

### Редактирование с автоотступом

```bash
nano -i script.py
```

### Установка размера табуляции

```bash
nano -T 4 code.js
```

### Открытие нескольких файлов

```bash
nano file1.txt file2.txt
```

## Практические сценарии

### Быстрое редактирование конфигурации

```bash
sudo nano /etc/nginx/nginx.conf
# Внести изменения
# Ctrl+O — сохранить
# Ctrl+X — выйти
```

### Просмотр лог-файла

```bash
nano -v /var/log/syslog
```

### Создание нового скрипта

```bash
nano -l script.sh
chmod +x script.sh
```

## Конфигурация ~/.nanorc

Файл `~/.nanorc` позволяет настроить поведение nano:

```bash
# ~/.nanorc
set tabsize 4
set autoindent
set linenumbers
set mouse
set backup
set backupdir ~/.nano/backups
set smooth
set zap
include "/usr/share/nano/*.nanorc"
```

## Подсветка синтаксиса

Nano поддерживает подсветку синтаксиса через файлы `.nanorc`. Системные файлы находятся в `/usr/share/nano/`. Для включения всех подсветок добавьте в `~/.nanorc`:

```bash
include "/usr/share/nano/*.nanorc"
```

:::tip Совет
Используйте `Ctrl+G` для вызова справки внутри nano — там отображены все доступные сочетания клавиш.
:::

:::warning Внимание
При редактировании системных файлов всегда используйте `sudo`, иначе изменения не сохранятся.
