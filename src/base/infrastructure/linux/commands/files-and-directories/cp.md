# cp

**Уровень:** Начинающий

Копирует файлы и каталоги. Одна из основных утилит для работы с файловой системой.

## Синтаксис

```bash
cp [опции] источник... назначение
cp файл1 файл2
cp файл1 файл2 ... каталог/
cp -r каталог1 каталог2
cp файл каталог/новое_имя
```

## Основные опции

| Опция | Описание |
|-------|----------|
| `-r`, `-R` | Рекурсивное копирование каталогов |
| `-i` | Интерактивный режим — спрашивать перед перезаписью |
| `-u` | Копировать только если источник новее назначения |
| `-v` | Подробный вывод |
| `-p` | Сохранить права, владелец, timestamps |
| `-a` | Архивное копирование (сохраняет всё, включая ссылки) |
| `-f` | Принудительная перезапись |
| `-n` | Не перезаписывать существующие файлы |
| `-l` | Создать жёсткие ссылки вместо копирования |
| `-s` | Создать символические ссылки вместо копирования |
| `--backup` | Создать резервную копию перед перезаписью |
| `--backup=NUMBERED` | Нумерованные резервные копии |
| `--backup=SIMPLE` | Резервная копия с суффиксом `~` |
| `-S суффикс` | Задать суффикс для резервных копий |
| `--preserve=аттрибуты` | Сохранить указанные атрибуты |
| `--no-preserve=аттрибуты` | Не сохранять указанные атрибуты |
| `--parents` | Сохранить структуру каталогов источника |
| `-T` | Обрабатывать назначение как обычный файл |
| `--strip-trailing-slashes` | Удалить завершающие слеши |

## Примеры

### 1. Копирование файла

```bash
cp file.txt file_backup.txt
```

### 2. Копирование файла в каталог

```bash
cp file.txt /tmp/
# /tmp/file.txt
```

### 3. Копирование с новым именем

```bash
cp /etc/hosts ~/hosts_backup
```

### 4. Копирование нескольких файлов в каталог

```bash
cp file1.txt file2.txt file3.txt /backup/
```

### 5. Интерактивное копирование

```bash
cp -i file.txt /existing/file.txt
# cp: overwrite '/existing/file.txt'? (y/n)
```

### 6. Рекурсивное копирование каталога

```bash
cp -r source_dir/ dest_dir/
```

### 7. Сохранение атрибутов

```bash
cp -p important.conf /etc/important.conf
# Сохраняет права, владельца, timestamps
```

### 8. Архивное копирование

```bash
cp -a source/ /backup/source
# Сохраняет всё: права, ссылки, timestamps, владелец
```

### 9. Копирование только новых файлов

```bash
cp -u source/*.txt /destination/
# Копирует только если источник новее
```

### 10. Подробный вывод

```bash
cp -v *.txt /backup/
# 'file1.txt' -> '/backup/file1.txt'
# 'file2.txt' -> '/backup/file2.txt'
```

### 11. Копирование с резервными копиями

```bash
cp --backup file.txt /etc/file.txt
# Создаёт /etc/file.txt~ перед перезаписью

cp --backup=numbered file.txt /etc/file.txt
# Создаёт /etc/file.txt.~1~, /etc/file.txt.~2~, ...
```

### 12. Копирование с помощью шаблонов (wildcards)

```bash
cp *.log /var/backup/
cp file[0-9].txt /tmp/
cp report_*.csv /data/reports/
```

### 13. Создание ссылок вместо копирования

```bash
cp -l source.txt hardlink.txt    # жёсткая ссылка
cp -s source.txt symlink.txt     # символическая ссылка
```

### 14. Копирование с сохранением структуры каталогов

```bash
cp --parents src/main/app.java /backup/
# Создаёт /backup/src/main/app.java
```

### 15. Копирование в текущий каталог

```bash
cp /path/to/file.txt .
# Копировать файл в текущий каталог
```

## Архивное копирование (`cp -a`)

```bash
# cp -a эквивалентно cp -dR --preserve=all
# Сохраняет:
# - Права доступа
# - Владельца и группу
# - Временные метки
# - Расширенные атрибуты
# - Символические ссылки (как ссылки, не разворачивая)
cp -a /important/data /backup/
```

## Практические сценарии

### Резервное копирование конфигов

```bash
sudo cp -a /etc/nginx/nginx.conf /etc/nginx/nginx.conf.bak.$(date +%Y%m%d)
```

### Копирование с сохранением прав

```bash
sudo cp -p /etc/hosts /etc/hosts.backup
# Права и владелец сохраняются
```

### Синхронизация директорий

```bash
cp -ru source/ dest/
# Обновить только изменённые файлы
```

### Безопасное копирование критичных файлов

```bash
cp --backup=numbered important.conf /etc/important.conf
# Никогда не потеряем предыдущую версию
```

## Связки с другими командами

```bash
# Скопировать все .conf файлы в каталог backup
find . -name "*.conf" -exec cp {} /backup/ \;

# Скопировать все .txt файлы в каталог назначения
find . -maxdepth 1 -type f -name "*.txt" -exec cp -t /dest/ -- {} +

# Скопировать каталог на удалённый сервер через SSH
tar -czf - dir/ | ssh user@host "tar -xzf - -C /remote/path"

# Скопировать только .conf файлы с помощью rsync
rsync -avz --include='*.conf' --exclude='*' src/ dest/

# Создать резервную копию с текущей датой в имени
cp important.conf "important.conf.$(date +%Y%m%d_%H%M%S).bak"

# Скопировать файлы, найденные по содержимому
grep -rlZ -- "TODO" src/ | xargs -0 -r cp -t /backup/todos/ --

# Скопировать структуру каталогов без файлов
find . -type d -exec sh -c 'for dir do mkdir -p -- "/backup/${dir#./}"; done' sh {} +

# Скопировать только файлы больше 1МБ
find . -type f -size +1M -exec cp -t /large_files/ -- {} +

# Синхронизировать и показать разницу
rsync -avc --dry-run source/ dest/ && cp -ru source/ dest/

# Скопировать с сохранением структуры (архивный способ)
find . -name "*.conf" -exec cp --parents {} /backup/ \;
```

## Советы

:::tip
Используйте `cp -a` для резервного копирования — это самый надёжный способ сохранить все атрибуты файлов, включая права и ссылки.
:::

:::warning
`cp -r` не сохраняет права и timestamps по умолчанию. Для точного копирования используйте `cp -a` или `cp -rp`.
:::

:::tip
Для копирования больших объёмов данных с прогрессом используйте `rsync -avP` вместо `cp -r`.
:::

:::warning
Будьте осторожны с `cp -r dir1 dir2`: если `dir2` существует, `dir1` скопируется внутрь `dir2` (т.е. `dir2/dir1/`). Чтобы скопировать содержимое, используйте `cp -r dir1/* dir2/`.
:::
