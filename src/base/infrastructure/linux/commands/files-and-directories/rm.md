# rm

Удаляет файлы и каталоги. Одна из самых мощных и потенциально опасных команд Linux.

## Синтаксис

```bash
rm [опции] файл...
rm файл1 файл2
rm -r каталог/
rm -rf каталог/
```

## Основные опции

| Опция | Описание |
|-------|----------|
| `-r`, `-R` | Рекурсивное удаление каталогов и их содержимого |
| `-f` | Принудительное удаление — не спрашивать подтверждения |
| `-i` | Интерактивный режим — спрашивать перед каждым удалением |
| `-I` | Спрашивать один раз при удалении более 3 файлов или рекурсивно |
| `-v` | Подробный вывод |
| `--preserve-root` | Не удалять корневой каталог `/` (по умолчанию) |
| `--no-preserve-root` | Не защищать корневой каталог |
| `--one-file-system` | Не переходить на другие файловые системы |
| `-d` | Удалять пустые каталоги |
| `--interactive[=WHEN]` | Когда спрашивать: `never`, `once`, `always` |

## Примеры

### 1. Удаление одного файла

```bash
rm file.txt
```

### 2. Удаление нескольких файлов

```bash
rm file1.txt file2.txt file3.txt
```

### 3. Удаление с подтверждением

```bash
rm -i important.txt
# rm: remove regular file 'important.txt'? (y/n)
```

### 4. Удаление каталога рекурсивно

```bash
rm -r old_project/
```

### 5. Принудительное удаление каталога

```bash
rm -rf temp_dir/
# Удаляет без вопросов, игнорирует несуществующие файлы
```

### 6. Подробный вывод

```bash
rm -v *.tmp
# removed 'file1.tmp'
# removed 'file2.tmp'
```

### 7. Удаление файлов с шаблонами

```bash
rm *.log
rm *.tmp
rm backup_*.tar.gz
```

### 8. Удаление файлов с именем, начинающимся с `-`

```bash
rm -- -filename
rm ./-filename
```

### 9. Одно подтверждение для множества файлов

```bash
rm -I *.log
# rm: remove all 15 arguments? (y/n)
```

### 10. Удаление пустых каталогов

```bash
rm -d empty_dir/
# Удалит только пустой каталог
```

### 11. Удаление на одной файловой системе

```bash
rm -r --one-file-system /mnt/backup/
# Не удалит файлы на других смонтированных системах
```

### 12. Безопасное удаление с проверкой

```bash
rm -ri important_dir/
# Спросит для КАЖДОГО файла в каталоге
```

### 13. Удаление всех файлов в каталоге

```bash
rm /tmp/workdir/*
# Удаляет файлы, но не сам каталог
```

### 14. Удаление с игнорированием несуществующих

```bash
rm -f maybe_exists.txt
# Не выдаст ошибку, если файл не существует
```

### 15. Удаление скрытых файлов

```bash
rm -f .*.swp .*.swo
# Удалить файлы подкачки vim
```

## Опасность `rm -rf`

```bash
# НИКОГДА НЕ ЗАПУСКАЙТЕ:
rm -rf /              # Удалит ВСЮ файловую систему
rm -rf ~              # Удалит домашний каталог
rm -rf *              # Удалит всё в текущем каталоге
rm -rf .              # Удалит текущий каталог (и всё внутри)
rm -rf /*             # Удалит всё от корня
```

:::danger
Команда `rm -rf` не перемещает файлы в корзину — они удаляются безвозвратно. Восстановление крайне сложно и не гарантировано.
:::

## Безопасные альтернативы

### trash-cli — удаление в корзину

```bash
# Установка
sudo apt install trash-cli

# Использование
trash-put file.txt          # переместить в корзину
trash-put file1.txt file2.txt
trash-list                  # просмотреть корзину
trash-restore               # восстановить из корзины
trash-empty                 # очистить корзину
trash-rm file.txt           # удалить из корзины
```

### Алиас для безопасности

```bash
# Добавить в ~/.bashrc
alias rm='rm -i'
# или
alias rm='trash-put'
```

### Функция safe_rm

```bash
safe_rm() {
    local trash_dir="$HOME/.trash"
    mkdir -p "$trash_dir"
    for item in "$@"; do
        if [[ -e "$item" ]]; then
            mv "$item" "$trash_dir/$(basename "$item").$(date +%s)"
        fi
    done
}
```

## Практические сценарии

### Очистка временных файлов

```bash
rm -rf /tmp/myapp_cache_*
```

### Удаление старых логов

```bash
find /var/log/myapp -name "*.log" -mtime +30 -exec rm -f {} \;
```

### Очистка рабочего каталога

```bash
rm -rf build/ dist/ *.egg-info/ __pycache__/
```

### Безопасное удаление с проверкой

```bash
ls -la files_to_delete/
# Посмотреть, что будем удалять
rm -ri files_to_delete/
# Удалить с подтверждением каждого файла
```

## Связки с другими командами

```bash
# Удалить временные файлы старше 7 дней
find . -name "*.tmp" -mtime +7 -exec rm {} \;

# Удалить файлы больше 1ГБ
find . -type f -size +1G | xargs rm -f

# Завершить зомби-процессы
ps aux | grep zombie | awk '{print $2}' | xargs kill -9

# Удалить все Docker-контейнеры
docker ps -aq | xargs docker rm -f

# Удалить все .pyc файлы рекурсивно
find . -name "*.pyc" -type f | xargs rm -f

# Очистить кеш npm
npm cache ls 2>/dev/null | awk '{print $1}' | xargs npm cache clean

# Удалить пустые директории
find . -type d -empty | xargs rmdir 2>/dev/null

# Удалить файлы, найденные по содержимому (содержат "deprecated")
grep -rl "deprecated" src/ | xargs rm -f

# Очистить старые логи и показать что удалено
find /var/log -name "*.log" -mtime +30 -exec rm -v {} \;

# Удалить все контейнеры и образы Docker
docker ps -aq | xargs docker rm -f && docker images -q | xargs docker rmi -f

# Безопасное удаление с предпросмотром
find . -name "*.bak" | tee /dev/stderr | xargs rm -f
```

## Советы

:::warning
Никогда не выполняйте `rm -rf` с подстановкой без предварительной проверки. Сначала выполните `ls` с тем же шаблоном, чтобы увидеть, что будет удалено.
:::

:::tip
Используйте `trash-cli` вместо `rm` для повседневного удаления — файлы можно восстановить из корзины.
:::

:::warning
`rm -rf /` с `--no-preserve-root` удалит всю файловую систему. Никогда не используйте эту комбинацию.
:::

:::tip
Добавьте `alias rm='rm -i'` в `.bashrc` — это заставит `rm` спрашивать подтверждение перед каждым удалением.
:::
