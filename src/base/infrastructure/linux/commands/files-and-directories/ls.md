# ls

**Уровень:** Начинающий

Выводит содержимое каталога. Одна из наиболее часто используемых команд Linux для просмотра файлов и директорий.

## Синтаксис

```bash
ls [опции] [каталог...]
ls [опции] [файл...]
ls -l /etc
ls -la ~
```

## Основные опции

| Опция | Описание |
|-------|----------|
| `-l` | Длинный формат — права, владелец, размер, дата |
| `-a` | Показать все файлы, включая скрытые (начинающиеся с `.`) |
| `-A` | Как `-a`, но без `.` и `..` |
| `-h` | Читаемые размеры (КБ, МБ, ГБ) — работает только с `-l` |
| `-R` | Рекурсивный обход всех подкаталогов |
| `-t` | Сортировка по времени изменения (новые первыми) |
| `-S` | Сортировка по размеру (большие первыми) |
| `-r` | Обратный порядок сортировки |
| `-d` | Показать сам каталог, а не его содержимое |
| `-i` | Показать inode каждого файла |
| `-F` | Добавить символ-индикатор типа (`/` для каталогов, `*` для исполняемых, `@` для ссылок) |
| `--color` | Цветовая индикация типов файлов |
| `-1` | По одному файлу на строку |
| `-g` | Как `-l`, но без имени владельца |
| `-o` | Как `-l`, но без имени группы |
| `-n` | Как `-l`, но UID/GID числовые |
| `-G` | Не показывать имя группы |
| `-H` | Следовать символическим ссылкам в аргументах |
| `-L` | Показывать информацию о цели ссылки, а не о самой ссылке |
| `--sort=WORD` | Сортировка: `none`, `time`, `size`, `version`, `extension` |
| `--group-directories-first` | Каталоги перед файлами |

## Примеры

### 1. Простое содержимое каталога

```bash
ls /home
```

### 2. Длинный формат с подробностями

```bash
ls -l /etc
# -rw-r--r-- 1 root root 4096 Jan 15 10:30 config.conf
# ↑права      ↑ссылки ↑владелец ↑группа ↑размер ↑дата   ↑имя
```

### 3. Все файлы, включая скрытые

```bash
ls -la ~
# Показывает .bashrc, .profile, .gitconfig и т.д.
```

### 4. Читаемые размеры файлов

```bash
ls -lh /var/log
# 4.2K  12M  256K вместо байт
```

### 5. Рекурсивный обход с длинным форматом

```bash
ls -lR /home/user/projects
# Показывает все файлы во всех подкаталогах
```

### 6. Сортировка по времени (новые первыми)

```bash
ls -lt /tmp
# Самые недавно изменённые файлы в начале
```

### 7. Сортировка по размеру (большие первыми)

```bash
ls -lS /var/log
# Самые большие файлы в начале
```

### 8. Обратная сортировка

```bash
ls -ltr /tmp
# Самые старые файлы в начале (удобно для логов)
```

### 9. Показать inode

```bash
ls -li /etc/passwd
# 131073 -rw-r--r-- 1 root root 2048 Jan 15 10:30 /etc/passwd
```

### 10. Индикаторы типов файлов

```bash
ls -F /usr/bin
# script.sh*  config/  link@  archive.tar.gz
```

### 11. Показать только каталоги

```bash
ls -ld /home/*/
# Показывает только директории, а не их содержимое
```

### 12. Скрыть определённые файлы с glob

```bash
ls --hide='*.log' /var/log
ls -I '*.bak' -I '*.tmp' /project
```

### 13. Сортировка по расширению

```bash
ls -lX /project
# Файлы сгруппированы по типу: .c, .h, .o, .txt
```

### 14. Вывод по одной колонке

```bash
ls -1 /usr/bin | head -20
```

### 15. Цветной вывод

```bash
ls --color=auto
ls --color=never  # без цвета (для скриптов)
ls --color=always # всегда с цветом (для пайпов)
```

## Формат длинного вывода (`ls -l`)

```
-rwxr-xr-x  1  alex  developers  4096  Jan 15 10:30  script.sh
│╰──┬───╯   │  │     │           │     │             │
│   │        │  │     │           │     │             └─ Имя файла
│   │        │  │     │           │     └─ Дата изменения
│   │        │  │     │           └─ Размер в байтах
│   │        │  │     └─ Группа
│   │        │  └─ Владелец
│   │        └─ Количество жёстких ссылок
│   └─ Права доступа (owner/group/other)
└─ Тип файла (- файл, d каталог, l ссылка, c символ-устройство, b блок-устройство)
```

## Практические сценарии

### Поиск самых больших файлов

```bash
ls -lhS /var/log | head -20
# 20 самых больших файлов в /var/log
```

### Недавно изменённые файлы в проекте

```bash
ls -ltr --color=auto ~/projects/myapp/src
# Последние изменённые файлы в конце списка
```

### Подсчёт файлов в каталоге

```bash
ls -1 /var/log | wc -l
# Количество файлов (без подкаталогов)
```

### Просмотр скрытых конфигов в домашней директории

```bash
ls -la ~/.*rc ~/.config/
# .bashrc, .vimrc, .gitconfig и содержимое .config/
```

### Быстрая проверка прав доступа

```bash
ls -l /etc/shadow /etc/passwd
# Проверить, кто имеет доступ к критичным файлам
```

## Связки с другими командами

```bash
# Показать только директории в текущем каталоге
ls -la | grep "^d"

# Топ-10 самых больших файлов
ls -lhS | head -10

# 20 недавно изменённых файлов
ls -lt | head -20

# Файлы, отсортированные по размеру (имя + размер)
ls -la | awk '{print $5, $9}' | sort -rn | head

# Подсчитать количество строк во всех .log файлах
find . -maxdepth 1 -type f -name "*.log" -exec wc -l -- {} +

# Все файлы, отсортированные по размеру (исключая строку total)
ls -la | grep -v "^total" | sort -k5 -rn

# Подсчитать все .jpg файлы рекурсивно
ls -R | grep ".jpg" | wc -l

# Общий размер всех файлов в каталоге (в МБ)
ls -la | awk 'NR>1 {total+=$5} END {print total/1024/1024 " MB"}'

# Найти дубликаты имён файлов в текущем каталоге
ls | sort | uniq -d

# Показать только файлы, изменённые сегодня
ls -lt --time-style=+%Y-%m-%d | grep "$(date +%Y-%m-%d)"

# Подсчитать файлы по расширениям
ls | awk -F. '{print $NF}' | sort | uniq -c | sort -rn

# Показать файлы с правами доступа в восьмеричном формате
ls -la | awk '{print $1, $9}' | while read perm name; do stat -c "%a %n" "$name" 2>/dev/null; done
```

## Советы

:::tip
Используйте `ls -ltr` для быстрого поиска последних изменённых файлов в каталоге с логами — новые записи покажутся внизу.
:::

:::tip
Для использования в скриптах отключайте цвет: `ls --color=never`. Цветовые коды могут сломать парсинг вывода.
:::

:::warning
`ls -R` на каталогах с миллионами файлов может работать очень долго. Для больших деревьев лучше использовать `find` или `tree`.
:::

:::tip
Псевдоним `alias ll='ls -alF'` и `alias la='ls -A'` добавьте в `~/.bashrc` для ускорения работы.
:::
