# tree

Отображает структуру каталогов в виде дерева. Утилита для визуализации иерархии файловой системы.

## Синтаксис

```bash
tree [-adfghilnopqrstuvxACDFNS] [-L уровень] [-I шаблон] [-P шаблон] [каталог...]
tree --help
tree --version
```

## Основные опции

| Опция | Описание |
|-------|----------|
| `-a` | Показать все файлы, включая скрытые (начинающиеся с `.`) |
| `-d` | Показать только каталоги |
| `-L уровень` | Ограничить глубину рекурсии |
| `-I шаблон` | Исключить файлы/каталоги, совпадающие с шаблоном (glob) |
| `-P шаблон` | Показать только файлы, совпадающие с шаблоном |
| `-s` | Показать размер каждого файла |
| `-h` | Читаемые размеры (КБ, МБ, ГБ) |
| `--dirsfirst` | Каталоги перед файлами |
| `--filesfirst` | Файлы перед каталогами |
| `--sort=name` | Сортировка по имени (по умолчанию) |
| `--sort=size` | Сортировка по размеру |
| `--sort=time` | Сортировка по времени изменения |
| `-r` | Обратная сортировка |
| `-i` | Без отрисовки линий (компактный вывод) |
| `-f` | Показать полный путь для каждого файла |
| `-F` | Добавить индикаторы типов (`/`, `*`, `@`, `=`, `|`) |
| `-Q` | Обернуть имена в кавычки |
| `-D` | Показать дату последнего изменения |
| `--inodes` | Показать inode |
| `--device` | Показать номер устройства |
| `-o файл` | Записать вывод в файл |
| `--charset=кодировка` | Использовать указанную кодировку |
| `-C` | Цветной вывод (по умолчанию в терминале) |
| `-n` | Без цвета |
| `--noreport` | Не показывать итоговую статистику |

## Примеры

### 1. Простое отображение дерева

```bash
tree /home/alex/projects
# /home/alex/projects
# ├── project1
# │   ├── src
# │   │   ├── main.py
# │   │   └── utils.py
# │   └── README.md
# └── project2
#     └── index.html
```

### 2. Только каталоги

```bash
tree -d /etc
# Показывает только структуру каталогов без файлов
```

### 3. Ограничение глубины

```bash
tree -L 2 /home
# Показать только 2 уровня вложенности
```

### 4. Показать скрытые файлы

```bash
tree -a ~
# Включить .bashrc, .gitignore и т.д.
```

### 5. С размерами файлов

```bash
tree -sh /var/log
# Показать размер каждого файла в читаемом формате
```

### 6. Исключение по шаблону

```bash
tree -I 'node_modules|.git|__pycache__' ~/projects
# Исключить часто игнорируемые директории
```

### 7. Каталоги первыми

```bash
tree --dirsfirst /home/alex/project
# Все каталоги отображаются перед файлами
```

### 8. Полные пути

```bash
tree -f /tmp
# Показать полный путь для каждого элемента
```

### 9. Сохранение в файл

```bash
tree -L 3 /home/alex/projects > project_structure.txt
tree -L 3 -h -D /home/alex/projects -o structure.txt
```

### 10. С датами изменений

```bash
tree -D /home/alex/documents
# Показать дату последнего изменения каждого файла
```

### 11. Фильтрация по расширению

```bash
tree -P '*.py' ~/projects
# Показать только Python-файлы

tree -P '*.py|*.js' ~/projects
# Python и JavaScript файлы
```

### 12. Компактный вывод без линий

```bash
tree -i /home/alex/projects
# Без символов рисования дерева (удобно для парсинга)
```

### 13. С именами в кавычках

```bash
tree -Q /home/alex
# "file with spaces.txt"
```

### 14. Статистика типов файлов

```bash
tree --prune -P '*.py' ~/project
# Показать только Python-файлы с подсчётом
```

### 15. Сортировка по размеру

```bash
tree -sh --sort=size /var/log
# Самые большие файлы в начале каждого каталога
```

## Практические сценарии

### Обзор структуры проекта

```bash
tree -L 3 -I 'node_modules|.git|dist|build' --dirsfirst ~/projects/myapp
# Быстрый обзор проекта без мусора
```

### Экспорт документации

```bash
tree -L 2 -h -D --dirsfirst /home/alex/project -o README_structure.md
# Сохранить структуру для документации
```

### Поиск больших файлов

```bash
tree -sh --sort=size -L 2 /home | head -30
# Найти самые большие файлы
```

### Проверка конфигурационных файлов

```bash
tree -a -L 1 ~/
# Проверить, какие конфиги есть в домашнем каталоге
```

### Анализ логов

```bash
tree -sh -D /var/log --dirsfirst
# Структура логов с размерами и датами
```

## Советы

:::tip
Используйте `tree -L 2 --dirsfirst` для быстрого обзора любого проекта — это показывает структуру без перегрузки деталями.
:::

:::warning
На больших директориях (например, `/`) команда `tree` без ограничения `-L` может работать очень долго и вывести огромное количество данных.
:::

:::tip
Для парсинга вывода в скриптах используйте `tree -i --noreport` — компактный вывод без итоговой статистики легко обрабатывать.
:::

:::warning
`tree` может не быть установлен по умолчанию. Установка: `sudo apt install tree` (Debian/Ubuntu) или `sudo yum install tree` (CentOS/RHEL).
:::
