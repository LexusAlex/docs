# cd

**Уровень:** Начинающий

Сменяет текущий рабочий каталог. Встроенная команда оболочки (shell builtin), доступная в bash, zsh и других shell.

## Синтаксис

```bash
cd [каталог]
cd                    # переход в домашний каталог
cd ~                  # переход в домашний каталог
cd -                  # возврат в предыдущий каталог
cd ..                 # на уровень вверх
cd ../..              # на два уровня вверх
cd /absolute/path     # абсолютный путь
cd relative/path      # относительный путь
```

## Основные опции

| Опция | Описание |
|-------|----------|
| `-P` | Не следовать символическим ссылкам — использовать физический путь |
| `-L` | Следовать символическим ссылкам (поведение по умолчанию) |
| `-e` | Вернуть ошибку, если текущий каталог не может быть определён |

## Специальные символы

| Символ | Значение |
|--------|----------|
| `~` | Домашний каталог текущего пользователя |
| `~user` | Домашний каталог указанного пользователя |
| `-` | Предыдущий каталог (значение переменной `$OLDPWD`) |
| `..` | Родительский каталог |
| `.` | Текущий каталог |
| `/` | Корневой каталог |

## Примеры

### 1. Переход в домашний каталог

```bash
cd
cd ~
echo $PWD
# /home/alex
```

### 2. Абсолютный путь

```bash
cd /var/log
pwd
# /var/log
```

### 3. Относительный путь

```bash
cd ~/projects
cd src/main/java
# Перешли в ~/projects/src/main/java
```

### 4. Переход на уровень вверх

```bash
cd ..
pwd
# Родительский каталог
```

### 5. Переход на несколько уровней вверх

```bash
cd ../../..
# Три уровня вверх от текущего каталога
```

### 6. Возврат в предыдущий каталог

```bash
cd /var/log
cd /etc
cd -
# /var/log
cd -
# /etc
# Переключение между двумя последними каталогами
```

### 7. Переход в каталог другого пользователя

```bash
cd ~root
pwd
# /root
cd ~www-data
pwd
# /var/www
```

### 8. Использование переменной PWD

```bash
echo "Текущий каталог: $PWD"
# Текущий каталог: /home/alex/projects
```

### 9. Переход с пробелами в имени

```bash
cd "My Documents"
cd My\ Documents
cd My' 'Documents
# Все три варианта эквивалентны
```

### 10. Использование подстановки (globbing)

```bash
cd /usr/share/doc/py*
# Перейдёт в первый匹配, например /usr/share/doc/python3
```

### 11. Физический vs логический путь

```bash
ln -s /var/log /tmp/logs
cd /tmp/logs
pwd -L
# /tmp/logs (логический — через ссылку)
pwd -P
# /var/log (физический — реальный путь)
```

### 12. Автодополнение

```bash
cd /et<Tab>
# Автодополнит до /etc/
cd /etc/hos<Tab>
# Автодополнит до /etc/hostname или /etc/hosts
```

## CDPATH — пути поиска каталогов

Переменная `CDPATH` задаёт каталоги, в которых `cd` будет искать целевой каталог.

```bash
# Добавим пути поиска
export CDPATH=".:$HOME/projects:/var/www"

# Теперь можно сделать:
cd myapp
# Оболочка сначала проверит ./myapp, затем ~/projects/myapp,
# затем /var/www/myapp
```

### Настройка CDPATH в .bashrc

```bash
# Постоянная настройка
echo 'export CDPATH=".:$HOME/projects:$HOME/work"' >> ~/.bashrc
source ~/.bashrc
```

:::warning
`CDPATH` может привести к неожиданному поведению — `cd dirname` может перейти не туда, куда вы ожидаете. Используйте с осторожностью.
:::

## pushd/popd — стек каталогов

Команды `pushd` и `popd` работают со стеком каталогов, что позволяет быстро переключаться между несколькими рабочими директориями.

```bash
# Добавить каталог в стек и перейти в него
pushd /var/log
# /var/log ~

pushd /etc
# /etc /var/log ~

pushd /tmp
# /tmp /etc /var/log ~

# Посмотреть стек
dirs -v
# 0  /tmp
# 1  /etc
# 2  /var/log
# 3  ~

# Извлечь из стека и перейти
popd
# /etc /var/log ~

popd
# /var/log ~
```

### Практическое использование pushd/popd

```bash
# Сохранить текущий каталог
pushd .

# Сделать работу в другом месте
cd /var/log
grep -l "error" *.log

# Вернуться обратно
popd
```

### Переключение по номерам

```bash
pushd /tmp
pushd /var
pushd /etc
dirs -v
# 0  /etc
# 1  /var
# 2  /tmp

pushd +2
# Переключиться на /tmp (позиция 2)
dirs -v
# 0  /tmp
# 1  /var
# 2  /etc
```

## Практические сценарии

### Быстрое перемещение по проекту

```bash
cd ~/projects/myapp
# Работаем...
cd -  # Вернуться в предыдущий каталог
```

### Навигация с автодополнением

```bash
cd /u/s/b<Tab><Tab>
# Показывает варианты: bin/ bash/
```

### Проверка текущего каталога

```bash
if [[ "$PWD" == "/root" ]]; then
    echo "Вы в корневом каталоге!"
fi
```

### Безопасный переход

```bash
cd /nonexistent 2>/dev/null || echo "Каталог не найден"
```

## Советы

:::tip
Используйте `cd -` для быстрого переключения между двумя последними каталогами — это экономит время при работе в двух директориях одновременно.
:::

:::tip
Добавьте в `.bashrc` функцию `mkcd()` для создания и одновременного перехода в каталог:
```bash
mkcd() { mkdir -p "$1" && cd "$1"; }
```
:::

:::warning
При использовании `CDPATH` всегда начинайте путь с `./` или используйте абсолютные пути в скриптах, чтобы избежать неожиданных переходов.
:::

:::tip
В bash 4.4+ включите `shopt -s autocd` — тогда можно просто ввести имя каталога без `cd` для перехода в него.
:::
