# watch

**Уровень:** Средний

Выполняет указанную команду периодически и выводит результат на экран. Удобна для мониторинга изменений в реальном времени.

## Синтаксис

```bash
watch [опции] команда
watch -n 2 df -h              # обновление каждые 2 секунды
watch -d free -m              # с подсветкой изменений
watch -n 5 -g 'ss -tln'      # остановка при изменении вывода
```

## Основные опции

| Опция | Описание |
|-------|----------|
| `-n секунды`, `--interval` | Интервал обновления (по умолчанию 2 сек) |
| `-d`, `--differences` | Подсвечивать изменения между обновлениями |
| `-d=cumulative` | Подсвечивать все изменения (включая накопленные) |
| `-t`, `--no-title` | Убрать заголовок (время, команду, интервал) |
| `-b`, `--beep` | Звуковой сигнал при ошибке команды |
| `-e`, `--errexit` | Заморозить обновление при ошибке команды |
| `-g`, `--chgexit` | Завершиться, когда вывод изменится |
| `-p`, `--precise` | Попытаться точно выдерживать интервал |
| `-c`, `--color` | Интерпретировать ANSI-цвета |
| `--no-wrap` | Не переносить длинные строки |
| `-x`, `--exec` | Передать команду в `exec` вместо `sh -c` |
| `--help` | Показать справку |
| `--version` | Показать версию |

## Примеры

### 1. Мониторинг использования дисков

```bash
watch df -h
# Обновление каждые 2 секунды (по умолчанию)

watch -n 5 df -h /home
# Каждые 5 секунд, только для /home
```

### 2. Мониторинг использования памяти

```bash
watch -n 1 free -m
# Обновление каждую секунду

watch -n 2 -d free -m
# С подсветкой изменений
```

### 3. Мониторинг процессов

```bash
watch -n 1 'ps aux | grep nginx | grep -v grep'
# Отслеживание процессов nginx

watch -n 2 'ps aux --sort=-%mem | head -10'
# Топ-10 процессов по памяти
```

### 4. Мониторинг сетевых подключений

```bash
watch -n 1 'ss -tln'
# Прослушиваемые TCP-порты

watch -n 2 'ss -s'
# Статистика соединений

watch -n 5 'netstat -i'
# Сетевые интерфейсы
```

### 5. Мониторинг размера файла

```bash
watch -n 1 'ls -lh /var/log/syslog'
# Размер лог-файла

watch -n 2 'du -sh /var/log/*'
# Размеры всех логов
```

### 6. Ожидание завершения задачи

```bash
watch -g 'test -f /tmp/done.flag && echo "DONE"'
# Завершится, когда файл появится

watch -g 'pgrep -x backup_script > /dev/null || echo "Finished"'
# Завершится, когда процесс завершится
```

### 7. Мониторинг Docker

```bash
watch -n 2 docker ps
# Список контейнеров

watch -n 5 'docker stats --no-stream'
# Статистика контейнеров
```

### 8. Мониторинг Kubernetes

```bash
watch kubectl get pods
# Статус подов

watch -n 10 kubectl get nodes
# Статус нод
```

### 9. Без заголовка (для скриптов)

```bash
watch -t -n 1 'date "+%H:%M:%S"'
# Только время, без заголовка watch
```

### 10. Подсветка изменений

```bash
watch -d -n 1 'cat /proc/loadavg'
# Подсвечивает изменившиеся значения

watch -d=cumulative -n 2 'ss -s'
# Подсвечивает все различия
```

### 11. Остановка при изменении

```bash
watch -g -n 1 'curl -s -o /dev/null -w "%{http_code}" http://localhost'
# Завершится, когда HTTP-код изменится
```

### 12. Мониторинг температуры

```bash
watch -n 2 'cat /sys/class/thermal/thermal_zone*/temp'
# Температура процессора
```

## Практические сценарии

### Ожидание завершения деплоя

```bash
watch -g -n 5 'kubectl rollout status deployment/myapp'
# Скрипт завершится когда деплой будет готов
echo "Деплой завершён!"
```

### Мониторинг логов в реальном времени

```bash
watch -n 1 'tail -5 /var/log/nginx/access.log | cut -d" " -f1,7'
# Последние 5 запросов (IP и URL)
```

### Ожидание освобождения порта

```bash
watch -g -n 2 "ss -H -ltn 'sport = :8080' | grep -q . || echo 'Порт свободен'"
```

### Проверка доступности серверов

```bash
watch -n 10 'for s in server1 server2 server3; do
    ping -c 1 -W 1 $s > /dev/null 2>&1 && echo "$s: OK" || echo "$s: FAIL"
done'
```

### Мониторинг очереди задач

```bash
watch -n 5 'redis-cli llen task_queue'
# Длина очереди в Redis

watch -n 3 'rabbitmqctl list_queues name messages'
# Очереди в RabbitMQ
```

## Советы

:::tip
Используйте `-d` для быстрого визуального обнаружения изменений — watch подсветит изменившиеся области.
:::

:::tip
Для сложных команд с pipe используйте кавычки: `watch 'cmd1 | cmd2'`.
:::

:::warning
По умолчанию watch не интерпретирует ANSI-цвета. Добавьте `-c` если команда выводит цветной текст (например, `--color=auto` в grep).
:::

:::tip
`watch -g` полезен в скриптах для ожидания определённого состояния (появление файла, завершение процесса, изменение HTTP-кода).
:::

## Связки с другими командами

- **df, du** — мониторинг использования дисков
- **free** — мониторинг памяти
- **ps, top** — мониторинг процессов
- **ss, netstat** — мониторинг сетевых соединений
- **docker** — мониторинг контейнеров
- **kubectl** — мониторинг Kubernetes
- **curl** — мониторинг HTTP-сервисов
