# Файлы и каталоги

Создание, копирование, перемещение, удаление файлов и директорий. Навигация по файловой системе.

## Команды

| Команда | Описание |
|---------|----------|
| [ls](ls.md) | Просмотр содержимого директории |
| [cd](cd.md) | Смена текущей директории |
| [pwd](pwd.md) | Вывод текущей директории |
| [tree](tree.md) | Дерево файлов и директорий |
| [touch](touch.md) | Создание файлов и обновление меток времени |
| [mkdir](mkdir.md) | Создание директорий |
| [cp](cp.md) | Копирование файлов и директорий |
| [mv](mv.md) | Перемещение и переименование |
| [rm](rm.md) | Удаление файлов и директорий |
| [rmdir](rmdir.md) | Удаление пустых директорий |
| [ln](ln.md) | Создание ссылок (hard и symbolic) |
| [install](install.md) | Копирование с установкой прав |
| [shred](shred.md) | Безопасное удаление с перезаписью |
| [rename](rename.md) | Пакетное переименование файлов |
