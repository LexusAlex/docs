# shred

**Уровень:** Средний

Безвозвратно удаляет файлы, перезаписывая их содержимое случайными данными. Предотвращает восстановление данных с диска.

## Синтаксис

```bash
shred [опции] файл...
shred -n 3 -z -u file.txt
shred -v file1.txt file2.txt
```

## Основные опции

| Опция | Описание |
|-------|----------|
| `-n число` | Количество проходов перезаписи (по умолчанию 3) |
| `-z` | Добавить нулевой проход в конце (заполнить нулями) |
| `-u` | Удалить файл после перезаписи |
| `-v` | Показать прогресс |
| `-f` | Изменить права для перезаписи, если необходимо |
| `--random-source=файл` | Источник случайных данных |
| `-s размер` | Перезаписать только указанное количество байт |
| `--remove[=HOW]` | Как удалить: `unlink` (по умолчанию) или `wipe` |
| `--iterations=N` | То же, что `-n` |
| `--zero` | То же, что `-z` |
| `--verbose` | То же, что `-v` |
| `--force` | То же, что `-f` |

## Примеры

### 1. Простое удаление с перезаписью

```bash
shred -u file.txt
# 3 прохода перезаписи + удаление
```

### 2. Указанное количество проходов

```bash
shred -n 5 file.txt
# 5 проходов случайными данными
```

### 3. С нулевым проходом

```bash
shred -n 3 -z file.txt
# 3 прохода случайными данными + 1 проход нулями
```

### 4. Подробный вывод

```bash
shred -v file.txt
# shred: file.txt: pass 1/3 (random)...
# shred: file.txt: pass 2/3 (random)...
# shred: file.txt: pass 3/3 (random)...
```

### 5. Удаление после перезаписи

```bash
shred -u secret.txt
# Перезаписать и удалить
```

### 6. Принудительное удаление

```bash
shred -f -u readonly.txt
# Изменить права и удалить
```

### 7. Частичная перезапись

```bash
shred -s 1M large_file.dat
# Перезаписать только первые 1 МБ
```

### 8. Перезапись нескольких файлов

```bash
shred -u secret1.txt secret2.txt secret3.txt
```

### 9. Использование /dev/urandom как источника

```bash
shred --random-source=/dev/urandom -n 5 file.txt
```

### 10. Нулевой проход для маскировки

```bash
shred -n 5 -z -u file.txt
# После случайных данных заполняет нулями —
# скрывает факт перезаписи
```

### 11. Перезапись и удаление с подтверждением

```bash
for f in secret*.txt; do
    echo "Удаление: $f"
    shred -v -n 3 -z -u "$f"
done
```

### 12. Проверка после удаления

```bash
shred -v -n 1 test_file
hexdump test_file
# Должны быть случайные байты
```

## Теория безопасного удаления

```
Обычное удаление (rm):
┌──────────────┐
│ Файл на диске │ ──> Удаляется запись в таблице файлов
│ Данные остаются!│     Данные НЕ удаляются
└──────────────┘

Удаление с shred:
┌──────────────┐
│ Файл на диске │ ──> Проход 1: случайные данные
│              │ ──> Проход 2: случайные данные
│              │ ──> Проход 3: случайные данные
│              │ ──> Проход N: нули (с -z)
│              │ ──> Удаление файла
└──────────────┘
```

### Стандарты перезаписи

| Стандарт | Количество проходов | Описание |
|----------|-------------------|----------|
| Gutmann | 35 | Максимальная безопасность |
| DoD 5220.22-M | 7 | Стандарт Минобороны США |
| По умолчанию | 3 | Достаточно для большинства случаев |

:::warning
`shred` работает эффективно только на традиционных HDD. На SSD, файловых системах с journaling (ext4, XFS) и при использовании RAID результат не гарантирован.
:::

## Ограничения shred

```bash
# shred НЕ работает эффективно на:
# - SSD (из-за wear leveling)
# - Файловых системах с journaling
# - Файлах в облаке
# - Зашифрованных файлах (лучше уничтожить ключ)
# - Файловых системах с copy-on-write (ZFS, Btrfs)
```

## Практические сценарии

### Удаление конфиденциальных документов

```bash
shred -n 7 -z -u secret_report.pdf
```

### Очистка временных файлов с паролями

```bash
shred -f -u /tmp/password.txt
```

### Безопасное удаление логов

```bash
find /var/log/myapp -name "*.log" -exec shred -u {} \;
```

### Удаление swap-файла

```bash
sudo swapoff /swapfile
sudo shred -n 1 -z /swapfile
sudo rm /swapfile
```

## Альтернативы

### secure-delete (srm)

```bash
sudo apt install secure-delete
srm secret.txt
# Более надёжный алгоритм
```

### wipe

```bash
sudo apt install wipe
wipe -rfi /path/to/dir/
```

### dd для дисков

```bash
sudo dd if=/dev/urandom of=/dev/sdX bs=1M status=progress
# Полная перезапись диска
```

## Советы

:::warning
На SSD shred не гарантирует полное удаление из-за технологии wear leveling. Для SSD используйте полное шифрование диска (LUKS) вместо shred.
:::

:::tip
Используйте `shred -n 3 -z -u` как стандартный набор опций — 3 прохода достаточны, нулевой проход маскирует факт удаления.
:::

:::warning
`shred` не работает с tmpfs, NFS и другими виртуальными файловыми системами. Проверяйте тип ФС с помощью `df -T`.
:::

:::tip
Для удаления чувствительных данных на SSD лучше использовать полное шифрование диска (LUKS, FileVault, BitLocker). При уничтожении достаточно удалить ключ шифрования.
