# pwd

**Уровень:** Начинающий

Выводит полный абсолютный путь текущего рабочего каталога (Print Working Directory). Встроенная команда оболочки.

## Синтаксис

```bash
pwd [-LP]
```

## Основные опции

| Опция | Описание |
|-------|----------|
| `-L` | Логический путь — использовать значение `$PWD`, следовать символическим ссылкам |
| `-P` | Физический путь — показать реальный путь на диске, разрешая все ссылки |

## Примеры

### 1. Простое использование

```bash
pwd
# /home/alex/projects
```

### 2. Логический путь (по умолчанию)

```bash
ln -s /var/log /tmp/logs
cd /tmp/logs
pwd -L
# /tmp/logs
```

### 3. Физический путь

```bash
cd /tmp/logs
pwd -P
# /var/log
```

### 4. Разница между -L и -P

```bash
mkdir -p /home/alex/real_dir
ln -s /home/alex/real_dir /home/alex/link_dir
cd /home/alex/link_dir

pwd -L
# /home/alex/link_dir (логический — через ссылку)

pwd -P
# /home/alex/real_dir (физический — реальный каталог)
```

### 5. Встроенная переменная $PWD

```bash
echo $PWD
# /home/alex/projects

# Эквивалентно pwd -L
```

### 6. Встроенная переменная $OLDPWD

```bash
cd /var/log
cd /etc
echo $OLDPWD
# /var/log
```

### 7. Сохранение текущего каталога в переменную

```bash
current_dir=$(pwd)
echo "Мы находимся в: $current_dir"
```

### 8. Использование в скриптах

```bash
#!/bin/bash
script_dir=$(cd "$(dirname "$0")" && pwd -P)
echo "Скрипт запущен из: $script_dir"
```

### 9. Проверка текущего каталога

```bash
if [[ $(pwd) == /home/alex ]]; then
    echo "Домашний каталог"
fi
```

### 10. Вывод без переноса строки

```bash
printf '%s' "$(pwd)" | xclip -selection clipboard
# Скопировать путь в буфер обмена
```

### 11. Путь к каталогу скрипта

```bash
#!/bin/bash
# Получить абсолютный путь к скрипту
SCRIPT_PATH="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd -P)"
echo "Скрипт: $SCRIPT_PATH"
```

### 12. Комбинация с другими командами

```bash
pwd | rev | cut -d'/' -f1 | rev
# Имя текущего каталога
```

## Логический vs физический путь

```
Допустим, структура:
/home/alex/
├── real_dir/
│   └── file.txt
└── link_dir -> /home/alex/real_dir/

cd /home/alex/link_dir

pwd -L покажет: /home/alex/link_dir
pwd -P покажет: /home/alex/real_dir
```

| Аспект | `-L` (логический) | `-P` (физический) |
|--------|-------------------|-------------------|
| Следует ссылкам | Нет | Да |
| Использует `$PWD` | Да | Нет |
| Поведение по умолчанию | Да (в bash) | Нет |
| Точность пути | Может содержать ссылки | Всегда реальный путь |

## Практические сценарии

### Определение директории скрипта

```bash
#!/bin/bash
# Вне зависимости от того, откуда запущен скрипт
SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
cd "$SCRIPT_DIR" || exit 1
echo "Рабочий каталог: $SCRIPT_DIR"
```

### Проверка, что мы не в корне

```bash
if [[ $(pwd -P) == "/" ]]; then
    echo "Опасно: мы в корневом каталоге!"
    exit 1
fi
```

### Отображение текущего пути для отладки

```bash
debug_info() {
    echo "PWD:       $(pwd -L)"
    echo "Real path: $(pwd -P)"
    echo "HOME:      $HOME"
    echo "OLDPWD:    $OLDPWD"
}
```

## Советы

:::tip
В скриптах всегда используйте `pwd -P`, чтобы получить реальный путь без символических ссылок — это предотвращает ошибки при работе с файлами.
:::

:::warning
`$PWD` может содержать путь через символические ссылки. Если нужен именно реальный путь, используйте `pwd -P` или `readlink -f`.
:::

:::tip
Для получения абсолютного пути файла используйте `realpath file` или `readlink -f file` вместо комбинации `cd` + `pwd`.
:::
