# w

Показывает, кто залогинен и что делает.

## Синтаксис

```bash
w [опции] [пользователь]
```

## Опции

| Опция | Описание |
|-------|----------|
| `-h` | Не показывать заголовок |
| `-s` | Краткий формат |
| `-f` | Не показывать поле FROM |
| `-u` | Игнорировать имя пользователя |
| `-o` | Старый формат (всё в одной строке) |
| `-i` | Показать IP вместо hostname |
| `--help` | Помощь |
| `--version` | Версия |

## Поля вывода (заголовок)

| Поле | Описание |
|------|----------|
| `HH:MM:SS` | Текущее время |
| `up days` | Время работы системы |
| `users` | Количество залогиненных |
| `load average` | Средняя нагрузка (1, 5, 15 мин) |

## Поля вывода (пользователи)

| Поле | Описание |
|------|----------|
| `USER` | Имя пользователя |
| `TTY` | Терминал |
| `FROM` | Откуда подключился |
| `LOGIN@` | Время входа |
| `IDLE` | Время простоя |
| `JCPU` | Время CPU всех процессов |
| `PCPU` | Время CPU текущего процесса |
| `WHAT` | Текущая команда |

## Примеры

### Полная информация

```bash
w
```

### Без заголовка

```bash
w -h
```

### Краткий формат

```bash
w -s
```

### Без поля FROM

```bash
w -f
```

### Конкретный пользователь

```bash
w alex
```

### С IP-адресами

```bash
w -i
```

### Старый формат

```bash
w -o
```

### Только текущая команда

```bash
w -h | awk '{print $1, $NF}'
```

### Проверка простоя

```bash
w -h | awk '$4 > "1:00" {print $1, "idle for", $4}'
```

### Подсчёт SSH-сессий

```bash
w -h | grep "pts/" | wc -l
```

### Мониторинг активности

```bash
watch -n 5 w
```

### Пользователи с длинным простоем

```bash
w -h | awk '{split($4,a,":"); if (a[1] > 0) print $1, $4}'
```

### Проверка нагрузки

```bash
w | head -1 | awk -F'load average:' '{print $2}'
```

## Практические сценарии

### Мониторинг пользователей

```bash
# Кто что делает
w

# Проверка пользователей с долгим простоем
w -h | awk '{if ($4+0 > 60) print $1, "idle", $4, "minutes"}'
```

### Проверка перед обслуживанием

```bash
active=$(w -h | wc -l)
if [ "$active" -gt 0 ]; then
    echo "Warning: $active users are active"
    w -h
fi
```

:::tip
Первая строка `w` содержит ту же информацию, что и `uptime`. Используйте для быстрой проверки нагрузки.
:::

:::warning
Поле `WHAT` показывает только текущую команду. Если пользователь в оболочке, будет показана оболочка, а не последняя команда.
:::

### Поиск пользователей с активными сессиями

```bash
w -h | awk '$5 == "0.00s" {print $1, "is active"}'
```

### Проверка SSH-подключений

```bash
w -h | grep "pts/" | awk '{print $1, $3}'
```

## См. также

- `who` — кто залогинен
- `uptime` — время работы и нагрузка
- `top` — мониторинг процессов
- `last` — история входов
