# passwd

**Уровень:** Начинающий

Управление паролями пользователей.

## Синтаксис

```bash
passwd [опции] [имя_пользователя]
```

## Опции

| Опция | Описание |
|-------|----------|
| `-l` | Заблокировать учётную запись |
| `-u` | Разблокировать учётную запись |
| `-e` | Заставить сменить пароль при следующем входе |
| `-S` | Показать статус пароля |
| `-d` | Удалить пароль (пустой пароль) |
| `-n дней` | Минимальный срок действия пароля |
| `-x дней` | Максимальный срок действия пароля |
| `-w дней` | Дней до предупреждения об истечении |
| `-i дней` | Дней до блокировки после истечения |
| `--stdin` | Прочитать пароль из stdin |
| `-k` | Изменить только истёкший пароль |
| `-f` | Принудительное изменение |

## Статус пароля (passwd -S)

| Поле | Описание |
|------|----------|
| Имя пользователя | Имя пользователя |
| Статус | L = заблокирован, P = установлен, NP = нет пароля |
| Дата изменения | Дата последнего изменения |
| Мин. дней | Минимальный срок |
| Макс. дней | Максимальный срок |
| Дней предупреждения | Дней до предупреждения |
| Дней неактивности | Дней до блокировки |

## Конфигурационные файлы

| Файл | Описание |
|------|----------|
| `/etc/passwd` | Информация о пользователях |
| `/etc/shadow` | Зашифрованные пароли |
| `/etc/login.defs` | Параметры паролей |

## Поля /etc/shadow

| Поле | Описание |
|------|----------|
| 1 | Имя пользователя |
| 2 | Зашифрованный пароль |
| 3 | Дата последнего изменения (дни с 1970-01-01) |
| 4 | Минимальный срок |
| 5 | Максимальный срок |
| 6 | Дней до предупреждения |
| 7 | Дней неактивности |
| 8 | Дата истечения |
| 9 | Зарезервировано |

## Примеры

### Смена собственного пароля

```bash
passwd
```

### Смена пароля другого пользователя (root)

```bash
passwd alex
```

### Блокировка учётной записи

```bash
passwd -l alex
```

### Разблокировка учётной записи

```bash
passwd -u alex
```

### Принудительная смена при следующем входе

```bash
passwd -e alex
```

### Показать статус

```bash
passwd -S alex
```

### Удалить пароль

```bash
passwd -d alex
```

### Установить минимальный срок

```bash
passwd -n 7 alex
```

### Установить максимальный срок

```bash
passwd -x 90 alex
```

### Установить предупреждение

```bash
passwd -w 14 alex
```

### Установить неактивность

```bash
passwd -i 30 alex
```

### Пароль из stdin

```bash
echo "newpassword" | passwd --stdin alex
```

### Показать статус всех пользователей

```bash
passwd -Sa
```

### Проверка блокировки

```bash
passwd -S alex | grep -q "L" && echo "Locked"
```

## Практические сценарии

### Политика паролей

```bash
# Минимум 7 дней между сменами
passwd -n 7 alex

# Максимум 90 дней
passwd -x 90 alex

# Предупреждение за 14 дней
passwd -w 14 alex

# Блокировка через 30 дней после истечения
passwd -i 30 alex
```

### Блокировка уволенного сотрудника

```bash
passwd -l alex
usermod -e 1 alex
```

### Принудительная смена пароля

```bash
passwd -e alex
# Пользователь сменит пароль при следующем входе
```

:::tip
Используйте `passwd -S username` для проверки статуса пароля. Это показывает, заблокирован ли пароль и когда он истекает.
:::

:::warning
Никогда не храните пароли в открытом виде. Используйте `passwd` для интерактивного ввода или генерируйте хеш через `openssl passwd -6`.
:::

### Генерация паролей

```bash
# Случайный пароль
openssl rand -base64 12

# Случайный пароль со спецсимволами
< /dev/urandom tr -dc 'A-Za-z0-9!@#$%^&*' | head -c 16; echo

# Установка сгенерированного пароля
echo "alex:$(openssl rand -base64 12)" | chpasswd
```

### Проверка истёкших паролей

```bash
# Найти пользователей с истёкшими паролями
passwd -Sa | awk '$2 == "P" && $3 < systime()/86400 {print $1}'
```
