# who

**Уровень:** Начинающий

Показывает, кто сейчас залогинен в системе.

## Синтаксис

```bash
who [опции] [файл]
```

## Опции

| Опция | Описание |
|-------|----------|
| `-a` | Вся информация |
| `-b` | Время последней перезагрузки |
| `-d` | Мёртвые процессы |
| `-H` | Показать заголовки |
| `-l` | Процессы входа |
| `-m` | Только текущий терминал |
| `-p` | Активные процессы |
| `-q` | Краткий вывод (только имена и количество) |
| `-r` | Текущий runlevel |
| `-s` | Краткий вывод (по умолчанию) |
| `-t` | Последнее изменение системных часов |
| `-T` | Статус терминала (+, -, ?) |
| `-u` | Пользователи и время простоя |

## Файлы

| Файл | Описание |
|------|----------|
| `/var/run/utmp` | Текущие сессии |
| `/var/log/wtmp` | История входов |

## Поля вывода

| Поле | Описание |
|------|----------|
| Имя пользователя | Имя пользователя |
| Терминал | Терминал (tty, pts) |
| Время | Время входа |
| Хост | Откуда подключился |

## Примеры

### Показать всех залогиненных

```bash
who
```

### С заголовками

```bash
who -H
```

### Вся информация

```bash
who -a
```

### Время перезагрузки

```bash
who -b
```

### Текущий runlevel

```bash
who -r
```

### Краткий вывод

```bash
who -q
```

### Текущий пользователь

```bash
who -m
```

### С IP-адресами

```bash
who --ips
```

### Статус терминалов

```bash
who -T
```

### С информацией о простое

```bash
who -u
```

### Подсчёт пользователей

```bash
who -q | tail -1
```

### Проверка подключения

```bash
if who | grep -q "alex"; then
    echo "alex is logged in"
fi
```

### Показать только имена

```bash
who | awk '{print $1}'
```

### Уникальные пользователи

```bash
who | awk '{print $1}' | sort -u
```

## Практические сценарии

### Проверка, залогинен ли пользователь

```bash
if who | grep -q "^alex "; then
    echo "alex is currently logged in"
else
    echo "alex is not logged in"
fi
```

### Мониторинг входов

```bash
watch -n 5 who
```

### Проверка перед обслуживанием

```bash
users_count=$(who -q | tail -1 | awk -F' ' '{print NF-1}')
if [ "$users_count" -gt 0 ]; then
    echo "Warning: $users_count users are logged in"
fi
```

:::tip
Используйте `who -a` для получения полной информации, включая время перезагрузки и runlevel.
:::

:::warning
Показывает только пользователей, вошедших через терминал. Пользователи сервисов и cron не отображаются.
:::

### Логирование входов

```bash
who >> /var/log/user_logins.log
```

### Проверка SSH-подключений

```bash
who | grep "pts/"
```
