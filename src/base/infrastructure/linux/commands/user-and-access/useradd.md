# useradd

**Уровень:** Средний

Создание нового пользователя в системе.

## Синтаксис

```bash
useradd [опции] имя_пользователя
```

## Опции

| Опция | Описание |
|-------|----------|
| `-m` | Создать домашний каталог |
| `-d путь` | Указать домашний каталог |
| `-s оболочка` | Указать оболочку (shell) |
| `-g группа` | Основная группа |
| `-G группы` | Дополнительные группы |
| `-u UID` | Указать UID |
| `-e дата` | Дата истечения (YYYY-MM-DD) |
| `-c комментарий` | Комментарий (GECOS) |
| `-r` | Создать системного пользователя |
| `-k скелет` | Каталог скелета |
| `-D` | Показать/изменить значения по умолчанию |
| `-b базовый каталог` | Базовый каталог для домашнего |
| `-N` | Не создавать группу пользователя |
| `-o` | Разрешить неуникальный UID |
| `-p пароль` | Зашифрованный пароль |
| `-f дней` | Дней до блокировки после истечения |

## Конфигурационные файлы

| Файл | Описание |
|------|----------|
| `/etc/default/useradd` | Значения по умолчанию |
| `/etc/login.defs` | Определения параметров входа |
| `/etc/skel/` | Шаблон домашнего каталога |
| `/etc/passwd` | Информация о пользователях |
| `/etc/shadow` | Зашифрованные пароли |
| `/etc/group` | Информация о группах |

## Примеры

### Создание пользователя с домашним каталогом

```bash
useradd -m alex
```

### Указать оболочку

```bash
useradd -m -s /bin/bash alex
```

### Указать домашний каталог

```bash
useradd -m -d /home/alex alex
```

### С дополнительными группами

```bash
useradd -m -G docker,sudo alex
```

### С определённым UID

```bash
useradd -m -u 1500 alex
```

### Системный пользователь

```bash
useradd -r -s /usr/sbin/nologin myservice
```

### С датой истечения

```bash
useradd -m -e 2025-12-31 alex
```

### С комментарием

```bash
useradd -m -c "Alex Petrov, IT Department" alex
```

### С указанием основной группы

```bash
useradd -m -g developers alex
```

### Без создания группы

```bash
useradd -m -N -g users alex
```

### С кастомным скелетом

```bash
useradd -m -k /etc/custom_skel alex
```

### Показать значения по умолчанию

```bash
useradd -D
```

### Изменить оболочку по умолчанию

```bash
useradd -D -s /bin/bash
```

### С паролем

```bash
useradd -m -p $(openssl passwd -6 "mypassword") alex
```

## Практические сценарии

### Полная настройка пользователя

```bash
# Создание пользователя
useradd -m -s /bin/bash -G sudo,docker -c "Alex Petrov" alex

# Установка пароля
passwd alex

# Проверка
id alex
ls -la /home/alex
```

### Создание сервисного пользователя

```bash
useradd -r -s /usr/sbin/nologin -d /var/lib/myservice myservice
```

### Пакетное создание пользователей

```bash
#!/bin/bash
while read username; do
    useradd -m -s /bin/bash "$username"
    echo "Created user: $username"
done < users.txt
```

:::tip
Всегда используйте `-m` для создания домашнего каталога. Без него пользователь не сможет войти в систему.
:::

:::warning
Не используйте `-p` с паролем в открытом виде в командной строке — он будет виден в истории и `ps`. Используйте `passwd` после создания пользователя.
:::
