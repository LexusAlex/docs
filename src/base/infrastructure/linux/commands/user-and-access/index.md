# Пользователи и группы

Управление учётными записями, группами, информацией о текущих пользователях системы.

## Команды

| Команда | Описание |
|---------|----------|
| [useradd](useradd.md) | Создание пользователя |
| [userdel](userdel.md) | Удаление пользователя |
| [usermod](usermod.md) | Изменение учётной записи |
| [passwd](passwd.md) | Управление паролями |
| [groupadd](groupadd.md) | Создание группы |
| [groupdel](groupdel.md) | Удаление группы |
| [groupmod](groupmod.md) | Изменение группы |
| [groups](groups.md) | Список групп пользователя |
| [id](id.md) | Информация о пользователе и группах |
| [who](who.md) | Кто сейчас в системе |
| [w](w.md) | Подробная информация о вошедших |
| [last](last.md) | История входов в систему |
| [su](su.md) | Смена пользователя |
| [sudo](sudo.md) | Выполнение с привилегиями root |

## Ключевые файлы

| Файл | Описание |
|------|----------|
| `/etc/passwd` | Учётные записи пользователей |
| `/etc/shadow` | Зашифрованные пароли |
| `/etc/group` | Группы |
| `/etc/sudoers` | Правила sudo |
