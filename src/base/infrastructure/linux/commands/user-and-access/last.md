# last

**Уровень:** Средний

Показывает историю входов в систему.

## Синтаксис

```bash
last [опции] [пользователь...] [tty...]
```

## Опции

| Опция | Описание |
|-------|----------|
| `-n количество` | Количество записей |
| `-a` | Показать hostname в последней колонке |
| `-i` | Показать IP вместо hostname |
| `-x` | Показать shutdown и runlevel |
| `-F` | Полные даты и время |
| `-f файл` | Использовать другой файл |
| `-d` | Не учитывать DNS |
| `-R` | Не показывать hostname |
| `-t YYYYMMDDHHMMSS` | Показать до указанного времени |
| `--help` | Помощь |

## Файлы

| Файл | Описание |
|------|----------|
| `/var/log/wtmp` | История входов |
| `/var/log/btmp` | Неудачные попытки входа |

## Поля вывода

| Поле | Описание |
|------|----------|
| Имя пользователя | Имя пользователя |
| Терминал | Терминал |
| Хост/IP | Откуда подключился |
| Время входа | Дата и время входа |
| Время выхода | Дата и время выхода (still logged in) |
| Продолжительность | Время сессии |

## Примеры

### Последние входы

```bash
last
```

### Конкретный пользователь

```bash
last alex
```

### Последние 10 записей

```bash
last -n 10
```

### Полные даты

```bash
last -F
```

### С IP-адресами

```bash
last -i
```

### Shutdown и reboot

```bash
last -x
```

### Неудачные попытки входа

```bash
lastb
```

### Неудачные попытки конкретного пользователя

```bash
lastb alex
```

### История SSH

```bash
last | grep "pts/"
```

### Проверка reboot

```bash
last reboot
```

### Проверка конкретного терминала

```bash
last tty1
```

### До указанного времени

```bash
last -t 20240115000000
```

### Без DNS-резолвинга

```bash
last -d
```

### Показать hostname в конце

```bash
last -a
```

## Практические сценарии

### Аудит безопасности

```bash
# Проверить неудачные попытки входа
lastb | head -20

# Проверить входы с необычных IP
last | awk '{print $3}' | sort | uniq -c | sort -rn
```

### Проверка активности пользователя

```bash
last alex | head -10
```

### Мониторинг SSH-входов

```bash
last -i | grep -v "0.0.0.0" | head -20
```

:::tip
Используйте `lastb` для проверки неудачных попыток входа. Это важно для обнаружения попыток взлома.
:::

:::warning
Файл `/var/log/wtmp` может расти со временем. Используйте `last -f /var/log/wtmp.1` для просмотра старых записей после ротации.
:::

### Проверка перезагрузок

```bash
last reboot | head -5
# Показывает историю перезагрузок
```

### Проверка времени работы

```bash
last -x | grep -E "shutdown|reboot" | head -10
```

### Очистка истории

```bash
# Очистить текущий wtmp
> /var/log/wtmp

# Очистить историю неудачных входов
> /var/log/btmp
```
