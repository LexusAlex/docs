# su

Переключение на другого пользователя.

## Синтаксис

```bash
su [опции] [пользователь]
```

## Опции

| Опция | Описание |
|-------|----------|
| `-` | Полный вход (login shell) |
| `-l` | Полный вход (аналог `-`) |
| `-c команда` | Выполнить команду и вернуться |
| `-s оболочка` | Использовать указанную оболочку |
| `-p` | Сохранить окружение |
| `-m` | Сохранить окружение (аналог `-p`) |
| `--help` | Помощь |
| `--version` | Версия |

## Различия su и su -

| Команда | Описание |
|---------|----------|
| `su username` | Переключение с сохранением окружения |
| `su - username` | Полный вход (новое окружение) |
| `su` | Переключение на root |
| `su -` | Полный вход как root |

## Примеры

### Переключение на root

```bash
su -
```

### Переключение на другого пользователя

```bash
su - alex
```

### Выполнение команды от имени другого пользователя

```bash
su - alex -c "whoami"
```

### Без полного входа

```bash
su alex
```

### С указанной оболочкой

```bash
su -s /bin/bash alex
```

### Выполнение команды от root

```bash
su -c "apt update"
```

### Сохранение окружения

```bash
su -p alex
```

### Проверка текущего пользователя

```bash
whoami
id
```

### Переключение на сервисного пользователя

```bash
su -s /bin/bash - www-data
```

### Выполнение скрипта от имени пользователя

```bash
su - alex -c "/path/to/script.sh"
```

### Переключение с логированием

```bash
echo "$(date): $(whoami) switched to alex" >> /var/log/su.log
su - alex
```

## Практические сценарии

### Проверка после переключения

```bash
su - alex
whoami
echo $HOME
echo $SHELL
```

### Выполнение нескольких команд

```bash
su - alex -c "
cd /home/alex
ls -la
pwd
"
```

### Безопасное переключение на root

```bash
# Вместо полного переключения
su -c "command_to_run_as_root"
```

:::tip
Используйте `su -` для полного входа с новым окружением. Это гарантирует правильные переменные окружения.
:::

:::warning
`su` требует пароль целевого пользователя. `sudo` более безопасен, так как использует пароль текущего пользователя и логирует действия.
:::

### Разница между su и su -

```bash
# Без полного входа
su alex
echo $HOME  # Может быть /root
pwd         # Текущий каталог не меняется

# С полным входом
su - alex
echo $HOME  # /home/alex
pwd         # /home/alex
```

### Проверка, кто выполнил su

```bash
# В /var/log/auth.log или /var/log/secure
grep "su:" /var/log/auth.log
```

## См. также

- `sudo` — выполнение команд от имени другого пользователя
- `whoami` — имя текущего пользователя
- `id` — информация о пользователе
- `/var/log/auth.log` — лог аутентификации
