# usermod

Изменение свойств существующего пользователя.

## Синтаксис

```bash
usermod [опции] имя_пользователя
```

## Опции

| Опция | Описание |
|-------|----------|
| `-aG группы` | Добавить в дополнительные группы |
| `-G группы` | Установить дополнительные группы |
| `-g группа` | Изменить основную группу |
| `-l имя` | Изменить имя пользователя |
| `-d путь` | Изменить домашний каталог |
| `-m` | Переместить содержимое домашнего каталога |
| `-s оболочка` | Изменить оболочку |
| `-L` | Заблокировать учётную запись |
| `-U` | Разблокировать учётную запись |
| `-e дата` | Дата истечения (YYYY-MM-DD) |
| `-f дней` | Дней до блокировки после истечения |
| `-c комментарий` | Изменить комментарий |
| `-u UID` | Изменить UID |
| `-o` | Разрешить неуникальный UID |
| `-Z контекст` | Контекст SELinux |
| `--lock` | Заблокировать пароль |
| `--unlock` | Разблокировать пароль |

## Примеры

### Добавление в группу

```bash
usermod -aG docker alex
```

### Добавление в несколько групп

```bash
usermod -aG docker,sudo,www-data alex
```

### Изменение оболочки

```bash
usermod -s /bin/zsh alex
```

### Изменение домашнего каталога

```bash
usermod -d /home/newdir alex
```

### Перемещение домашнего каталога

```bash
usermod -d /home/newdir -m alex
```

### Изменение имени пользователя

```bash
usermod -l newname alex
```

### Блокировка учётной записи

```bash
usermod -L alex
```

### Разблокировка учётной записи

```bash
usermod -U alex
```

### Изменение UID

```bash
usermod -u 1500 alex
```

### Установка даты истечения

```bash
usermod -e 2025-12-31 alex
```

### Изменение комментария

```bash
usermod -c "Alex Petrov, Senior Developer" alex
```

### Изменение основной группы

```bash
usermod -g developers alex
```

### Полная модификация

```bash
usermod -s /bin/bash -g developers -G docker,sudo -c "Alex P" alex
```

### Проверка изменений

```bash
id alex
grep alex /etc/passwd
```

## Практические сценарии

### Добавление пользователя в группу sudo

```bash
usermod -aG sudo alex
# Проверка
groups alex
```

### Смена оболочки на bash

```bash
usermod -s /bin/bash alex
grep alex /etc/passwd
```

### Безопасная смена имени пользователя

```bash
# 1. Заблокировать пользователя
usermod -L oldname

# 2. Изменить имя
usermod -l newname oldname

# 3. Изменить домашний каталог
usermod -d /home/newname -m oldname

# 4. Разблокировать
usermod -U newname
```

:::tip
При добавлении пользователя в группу всегда используйте `-aG` (append), а не `-G` (set), чтобы не удалить существующие группы.
:::

:::warning
При изменении имени пользователя нужно также переименовать домашний каталог и обновить права на файлы.
:::

### Блокировка уволенного сотрудника

```bash
# Блокировка
usermod -L -e 1 alex

# Проверка
passwd -S alex
# alex L 2024-01-15 0 99999 7 -1
```

### Изменение UID

```bash
# Найти текущий UID
id alex

# Изменить UID
usermod -u 1500 alex

# Обновить файлы
find / -user old_uid -exec chown alex {} \;
```

## См. также

- `passwd` — управление паролями
