# Планирование задач

Автоматический запуск команд и скриптов по расписанию.

## Темы

| Файл | Описание |
|------|----------|
| [crontab](crontab.md) | Cron-задачи (классический планировщик) |
| [systemd-timers](systemd-timers.md) | Таймеры systemd (современная альтернатива) |

## Сравнение

| Характеристика | cron | systemd timers |
|----------------|------|----------------|
| Синтаксис | 5 полей времени | Calendar/OnCalendar |
| Логи | syslog | journalctl |
| Зависимости | Нет | Есть (After=, Requires=) |
| Пропущенный запуск | Потерян | Можно настроить catch-up |
| Монотонные интервалы | Нет | OnBootSec, OnUnitActiveSec |

## Формат cron

```
*    *    *    *    *
│    │    │    │    │
│    │    │    │    └─ день недели (0-7, 0 и 7 = воскресенье)
│    │    │    └────── месяц (1-12)
│    │    └─────────── день месяца (1-31)
│    └──────────────── час (0-23)
└───────────────────── минута (0-59)
```

## Примеры cron

```bash
# Каждый день в 3:00
0 3 * * * /path/to/script.sh

# Каждые 5 минут
*/5 * * * * /path/to/check.sh

# Каждый понедельник в 9:00
0 9 * * 1 /path/to/report.sh

# Первое число каждого месяца
0 0 1 * * /path/to/monthly.sh
```
