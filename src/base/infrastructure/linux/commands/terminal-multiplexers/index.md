# Терминальные мультиплексоры

Терминальные мультиплексоры позволяют управлять несколькими сессиями терминала внутри одного окна. Они незаменимы при удалённой работе, запуске долгих задач и организации рабочего пространства.

## Зачем нужны мультиплексоры?

- **Сохранение сессий** — при разрыве SSH-соединения процессы продолжают работать
- **Несколько окон** — один терминал, множество вкладок и панелей
- **Фоновые задачи** — можно отключиться и вернуться позже
- **Совместная работа** — несколько пользователей могут подключиться к одной сессии

## Команды

| Команда | Описание |
|---------|----------|
| [tmux](tmux.md) | Современный терминальный мультиплексор с расширенными возможностями |
| [screen](screen.md) | Классический мультиплексор, предустановлен на многих системах |

## Сравнение tmux и screen

| Характеристика | tmux | screen |
|---------------|------|--------|
| Активная разработка | Да | Минимальная |
| Плагины | Да (TPM) | Нет |
| Скриптинг | Отличный | Ограниченный |
| Вертикальный сплит | Встроен | С версии 4.1 |
| Конфигурация | `~/.tmux.conf` | `~/.screenrc` |
| Горячие клавиши | `Ctrl+b` | `Ctrl+a` |
| Предустановка | Нет | Да |
| Serial console | Возможно | Лучше подходит |
| Множественные подключения | Встроен | `-x` |

## Когда что использовать?

- **tmux** — для повседневной работы, скриптинга, если нужен расширенный функционал
- **screen** — для serial-консолей, на серверах где tmux не установлен, для совместного доступа
