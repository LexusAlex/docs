# screen

**Уровень:** Средний

Terminal multiplexer — утилита для управления несколькими сессиями терминала. Старая и проверенная альтернатива tmux, предустановлена на большинстве Linux-систем.

## Синтаксис

```bash
screen [опции] [команда]
screen -S имя                  # создать именованную сессию
screen -ls                     # список сессий
screen -r имя                  # подключиться к сессии
screen -d -r имя               # отключить и подключить
```

## Основные опции

| Опция | Описание |
|-------|----------|
| `-S имя` | Задать имя сессии |
| `-ls`, `-list` | Показать список сессий |
| `-r [имя]` | Подключиться к отключённой сессии |
| `-R` | Подключиться к сессии или создать новую |
| `-d` | Отключить сессию перед подключением |
| `-D` | Отключить и подключить (даже если уже подключены) |
| `-x` | Подключиться к сессии (можно несколько раз) |
| `-X` | Выполнить команду в запущенной сессии |
| `-m` | Игнорировать `$STY` |
| `-A` | Подогнать размер под текущий терминал |
| `-p имя` | Переключиться на именованное окно |
| `-d -m` | Запустить сессию в фоне |
| `-h N` | Размер истории (строк) |
| `-L` | Включить логирование |
| `-c файл` | Использовать альтернативный конфиг |
| `-e xy` | Символы экранирования (по умолчанию `^^`) |
| `-T тип` | Задать тип терминала |
| `-V` | Показать версию |

## Управление сессиями

### Создание сессии

```bash
screen                        # новая сессия
screen -S work                # именованная сессия
screen -d -m -S work          # запустить в фоне
screen -S work -L -Logfile work.log  # с логированием
```

### Список сессий

```bash
screen -ls
# There are screens on:
#         12345.pts-0.server   (Attached)
#         12346.pts-0.server   (Detached)
# 2 Sockets in /run/screen/S-alex.
```

### Подключение к сессии

```bash
screen -r work                # подключиться к сессии work
screen -r 12345               # подключиться по ID
screen -R                     # подключиться к любой или создать
screen -x work                # подключиться (множественное подключение)
```

### Отключение от сессии

```
Ctrl+a d                      # отключиться от текущей сессии
```

```bash
screen -d work                # удалённо отключить сессию
```

### Завершение сессии

```bash
screen -X -S work quit        # завершить сессию
# Внутри screen:
exit                          # или Ctrl+d
```

## Конфигурация

Файл конфигурации: `~/.screenrc`

### Базовые настройки

```bash
# Отключить стартовое сообщение
startup_message off

# Размер истории
defscrollback 10000

# Автоматический detach при завершении
autodetach on

# Кодировка
defencoding UTF-8
encoding UTF-8 UTF-8

# Терминал
term screen-256color

# Статусбар
hardstatus alwayslastline
hardstatus string '%{= kG}[%{G}%H%{g}][%= %{= kw}%?%-Lw%?%{r}(%{W}%n*%f%t%?(%u)%?%{r})%{w}%?%+Lw%?%?%= %{g}][%{B}%Y-%m-%d %{W}%c%{g}]'

# Логирование
logfile /tmp/screenlog-%n.log

# Автоименование окон
shelltitle '$ |bash'

# Быстрые клавиши
bindkey -k k1 select 1
bindkey -k k2 select 2
bindkey -k k3 select 3
```

### Цвета

```bash
# Цвет статусбара
hardstatus alwayslastline '%{= kB}%-Lw%{= kB}%50>%n%f* %t%{= kB}%+Lw%<'

# Фон и текст
attrcolor b ".I"
defbce on
```

## Примеры

### 1. Рабочая сессия

```bash
screen -S work -d -m
screen -r work
# Ctrl+a c — создать окно редактора
# Ctrl+a c — создать окно терминала
# Ctrl+a c — создать окно для логов
```

### 2. Запуск долгих задач

```bash
screen -S backup -d -m
screen -r backup
# Выполнить задачу
# Ctrl+a d — отключиться
# Задача продолжается в фоне
```

### 3. Доступ к нескольким пользователям

```bash
# Пользователь 1
screen -S shared -x

# Пользователь 2 (на том же сервере)
screen -x shared
# Оба видят одно и то же
```

### 4. Логирование вывода

```bash
screen -S session -L -Logfile /tmp/session.log
# Весь вывод сохраняется в файл
```

### 5. Запуск скрипта в screen

```bash
screen -dmS mytask bash -c './long_script.sh; exec bash'
# Сессия завершится после выполнения скрипта
```

### 6. Serial console (COM-порт)

```bash
screen /dev/ttyUSB0 9600
# Подключение к serial-консоли оборудования
screen /dev/ttyS0 115200
```

### 7. Множественное подключение

```bash
# Терминал 1
screen -S demo -x

# Терминал 2 (демонстрация коллеге)
screen -x demo
# Оба терминала видят одно и то же
```

### 8. Список окон и переключение

```bash
# Внутри screen:
Ctrl+a "
# Показывает список всех окон с номерами
# Выберите стрелками и нажмите Enter

Ctrl+a 0   # перейти к окну 0
Ctrl+a 1   # перейти к окну 1
```

## Практические сценарии

### Удалённая работа через SSH

```bash
# Подключиться к серверу
ssh server

# Создать screen-сессию
screen -R work

# Работать...
# Если соединение разорвётся:
ssh server
screen -r work
# Всё на месте
```

### Serial-консоль для сетевого оборудования

```bash
# Подключить USB-COM адаптер
screen /dev/ttyUSB0 9600
# Управлять коммутатором/роутером

# Если нужно отключиться:
# Ctrl+a d
# Позже:
screen -r
```

### Пакетное выполнение задач

```bash
#!/bin/bash
for i in {1..5}; do
    screen -dmS "task_$i" bash -c "./process.sh $i; exec bash"
done
# Проверить статус
screen -ls
```

## screen vs tmux

| Характеристика | screen | tmux |
|---------------|--------|------|
| Активная разработка | Минимальная | Активная |
| Конфигурация | `~/.screenrc` | `~/.tmux.conf` |
| Горячие клавиши | `Ctrl+a` | `Ctrl+b` |
| Плагины | Нет | Да (TPM) |
| Скриптинг | Ограниченный | Отличный |
| Вертикальный сплит | С версии 4.1 | Встроен |
| Множественные attach | `-x` | Встроен |
| Сохранение сессий | Нет | tmux-resurrect |
| Предустановка | Да (на многих дистрибутивах) | Нет (нужно устанавливать) |

## Советы

:::tip
Для serial-консолей screen часто предпочтительнее tmux — он лучше работает с медленными и ненадёжными соединениями.
:::

:::warning
`Ctrl+a` используется и в screen, и в bash (переход в начало строки). В screen это перехватывается. Для bash-функции используйте `Ctrl+a a`.
:::

:::tip
Используйте `screen -x` для совместного доступа к сессии — удобно для pair programming или демонстраций.
:::

:::warning
При завершении screen через `Ctrl+a \` (quit) все окна завершаются без подтверждения.
:::

## Связки с другими командами

- **ssh** — screen сохраняет сессию при обрыве SSH-соединения
- **tmux** — более современная альтернатива с расширенными возможностями
- **nohup** — альтернатива для простых фоновых задач
- **serial consoles** — screen отлично подходит для подключения к COM-портам
- **script** — запись сессии терминала
