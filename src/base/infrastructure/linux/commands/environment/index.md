# Переменные окружения

Управление переменными окружения, файлы конфигурации оболочки, переменная PATH.

## Команды и темы

| Файл | Описание |
|------|----------|
| [export](export.md) | Установка и экспорт переменных |
| [env](env.md) | Просмотр переменных окружения |
| [printenv](printenv.md) | Вывод значения переменной |
| [path.md](path.md) | Переменная PATH и поиск команд |
| [bashrc.md](bashrc.md) | Файлы конфигурации оболочки |

## Область видимости

```bash
# Переменная только в текущем процессе
VAR="value"

# Экспорт в дочерние процессы
export VAR="value"

# Удаление переменной
unset VAR
```

## Файлы конфигурации bash

| Файл | Когда загружается |
|------|-------------------|
| `/etc/profile` | Для всех пользователей (login shell) |
| `~/.bash_profile` | Для пользователя (login shell) |
| `~/.bashrc` | Для пользователя (interactive non-login) |
| `~/.bash_logout` | При выходе из login shell |
| `/etc/environment` | Переменные для всех (systemd) |
