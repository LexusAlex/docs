# sort

**Уровень:** Начинающий

Команда `sort` сортирует строки текстовых файлов и вывода команд.

## Синтаксис

```bash
sort [опции] файл...
sort [опции] < файл
команда | sort [опции]
```

## Основные опции

| Опция | Описание |
|-------|----------|
| `-n` | Числовая сортировка |
| `-r` | Обратный порядок |
| `-k КЛЮЧ` | Сортировка по указанному ключу (полю) |
| `-t РАЗДЕЛИТЕЛЬ` | Указать разделитель полей |
| `-u` | Удалить дубликаты после сортировки |
| `-h` | Числовая сортировка с суффиксами (K, M, G) |
| `-M` | Сортировка по месяцам (Jan, Feb, ...) |
| `-R` | Случайный порядок |
| `-V` | Естественная сортировка версий (1.2 < 1.10) |
| `-f` | Игнорировать регистр |
| `-i` | Игнорировать непечатаемые символы |
| `-s` | Стабильная сортировка (сохраняет порядок равных) |
| `-o ФАЙЛ` | Записать результат в файл |
| `--parallel=N` | Количество потоков |
| `--unique` | То же, что `-u` |
| `--reverse` | То же, что `-r` |
| `--numeric-sort` | То же, что `-n` |

## Примеры

```bash
# Простая сортировка по алфавиту
sort names.txt

# Числовая сортировка
sort -n numbers.txt

# Обратный порядок
sort -r file.txt

# Числовая сортировка в обратном порядке
sort -rn numbers.txt

# Удалить дубликаты
sort -u file.txt

# Сортировка по второму полю (разделитель — пробел)
sort -k2 -t' ' data.txt

# Сортировка по третьему полю (числовая)
sort -k3 -n -t',' data.csv

# Сортировка по размеру файлов
du -sh * | sort -h

# Сортировка по месяцам
sort -M months.txt

# Случайный порядок
sort -R list.txt

# Сортировка версий
sort -V versions.txt

# Игнорировать регистр
sort -f mixed_case.txt

# Стабильная сортировка
sort -s -k1 file.txt

# Сохранить результат в файл
sort -o sorted.txt input.txt

# Сортировка по нескольким ключам
sort -k1,1 -k2,2n data.txt
# Сначала по первому полю (алфавитно),
# затем по второму (числовая)
```

## Практические сценарии

### Сортировка логов по дате
```bash
# Если дата в первом поле
sort -k1,1 -t' ' access.log

# Сортировка по времени (с учётом формата)
sort -k4,4 -t' ' access.log
```

### Топ-10 по значениям
```bash
# Топ-10 IP-адресов по количеству запросов
cut -d' ' -f1 access.log | sort | uniq -c | sort -rn | head -10

# Топ-10 самых больших файлов
du -sh * | sort -rh | head -10
```

### Удаление дубликатов
```bash
# Уникальные строки
sort -u file.txt

# Уникальные IP-адреса
sort -u ip_list.txt
```

### Сортировка CSV-данных
```bash
# По второму столбцу (числовая)
sort -t',' -k2,2n data.csv

# По третьему столбцу в обратном порядке
sort -t',' -k3,3r data.csv
```

### Случайная выборка
```bash
# Случайный порядок строк
sort -R data.txt | head -20
```

### Многоуровневая сортировка
```bash
# Сначала по фамилии, потом по имени
sort -k1,1 -k2,2 contacts.txt

# Сначала по дате, потом по времени
sort -k1,1 -k2,2 -t' ' logs.txt
```

## Советы

:::tip
Используйте `-u` для одновременной сортировки и удаления дубликатов вместо комбинации `sort | uniq`.
:::

:::warning
Без `-n` сортировка будет лексикографической: "10" будет перед "2". Для числовых данных всегда используйте `-n`.
:::

:::tip
Опция `-V` (версионная сортировка) полезна для списков вида 1.1, 1.2, 1.10, 2.0 — она сортирует правильно.
:::

:::tip
Используйте `-h` для сортировки значений с суффиксами размера: 1K, 2M, 3G. Работает с выводом `du -h`.
:::

:::warning
Сортировка больших файлов может потребовать много памяти. Используйте `--parallel` для ускорения на многопроцессорных системах.
:::

## Связки с другими командами

```bash
# Топ-10 самых больших директорий
du -sh * | sort -rh | head -10

# Топ-10 процессов по использованию CPU
ps aux --sort=-%cpu | head -10

# Топ IP-адресов по количеству запросов
cat access.log | awk '{print $1}' | sort | uniq -c | sort -rn | head

# Самые большие файлы в директории
ls -la | sort -k5 -rn | head -10

# Частота входов по датам
last | sort -k3,4 | uniq -c | sort -rn

# Самые большие лог-файлы по количеству строк
find . -name "*.log" -exec wc -l {} \; | sort -rn | head
```
