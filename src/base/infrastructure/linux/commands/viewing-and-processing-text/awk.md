# awk

**Уровень:** Средний

Команда `awk` — мощный язык программирования для обработки текста и извлечения данных.

## Синтаксис

```bash
awk 'шаблон { действие }' файл...
awk -F разделитель 'шаблон { действие }' файл
awk -f скрипт файл...
```

## Основные опции

| Опция | Описание |
|-------|----------|
| `-F РАЗДЕЛИТЕЛЬ` | Указать разделитель полей |
| `-f ФАЙЛ` | Читать программу из файла |
| `-v ПЕРЕМЕННАЯ=ЗНАЧЕНИЕ` | Установить переменную |
| `--posix` | Режим совместимости с POSIX |
| `--dump-variables` | Вывести все переменные в файл |
| `--lint` | Проверять синтаксис |

## Встроенные переменные

| Переменная | Описание |
|------------|----------|
| `NR` | Номер текущей записи (строки) |
| `NF` | Количество полей в текущей записи |
| `FS` | Разделитель полей (входной) |
| `OFS` | Разделитель полей (выходной) |
| `RS` | Разделитель записей |
| `ORS` | Разделитель записей (выходной) |
| `FILENAME` | Имя текущего файла |
| `FNR` | Номер записи в текущем файле |
| `$0` | Вся текущая строка |
| `$1, $2, ...` | Первое, второе и т.д. поле |

## Примеры

```bash
# Печать первого и третьего поля
awk '{print $1, $3}' file.txt

# С указанным разделителем
awk -F',' '{print $1, $2}' data.csv

# Печать строк, где первое поле больше 10
awk '$1 > 10 {print $0}' data.txt

# Печать номеров строк и содержимого
awk '{print NR, $0}' file.txt

# Последнее поле
awk '{print $NF}' file.txt

# Печать количества полей
awk '{print NF, $0}' file.txt

# Сумма значений в столбце
awk '{sum += $1} END {print sum}' numbers.txt

# Среднее значение
awk '{sum += $1; count++} END {print sum/count}' numbers.txt

# BEGIN и END блоки
awk 'BEGIN {print "Начало"} {print $0} END {print "Конец"}' file.txt

# Установить разделитель вывода
awk -F',' 'BEGIN {OFS="\t"} {print $1, $2}' data.csv

# Условные конструкции
awk '{if ($3 > 100) print $1, $3}' data.txt

# Циклы
awk '{for (i=1; i<=NF; i++) print $i}' file.txt

# Ассоциативные массивы
awk '{count[$1]++} END {for (word in count) print word, count[word]}' file.txt

# printf для форматированного вывода
awk '{printf "%-20s %10d\n", $1, $2}' data.txt

# Обработка нескольких файлов
awk 'FNR==1 {print "Файл:", FILENAME} {print}' file1.txt file2.txt

# Удаление дубликатов
awk '!seen[$0]++' file.txt
```

## Практические сценарии

### Анализ логов
```bash
# Подсчёт запросов по IP
awk '{print $1}' access.log | sort | uniq -c | sort -rn

# Топ-10 самых частых URL
awk '{print $7}' access.log | sort | uniq -c | sort -rn | head -10

# Средний размер ответа
awk '{sum += $10; count++} END {print sum/count}' access.log

# Запросы с кодом ошибки
awk '$9 >= 400 {print $0}' access.log
```

### Обработка CSV
```bash
# Сумма по столбцу
awk -F',' '{sum += $3} END {print sum}' data.csv

# Фильтрация по значению
awk -F',' '$2 == "active" {print $1}' users.csv

# Преобразование формата
awk -F',' '{print $1 "\t" $2 "\t" $3}' data.csv > data.tsv
```

### Форматирование вывода
```bash
# Красивая таблица
awk -F':' '{printf "%-20s %-30s\n", $1, $6}' /etc/passwd

# Нумерация строк
awk '{printf "%4d: %s\n", NR, $0}' file.txt
```

### Статистика
```bash
# Минимум и максимум
awk 'NR==1 {min=max=$1} {if ($1<min) min=$1; if ($1>max) max=$1} END {print min, max}' numbers.txt

# Количество уникальных значений
awk '{count[$1]++} END {print length(count)}' data.txt
```

### Преобразование данных
```bash
# Транспонировать матрицу (требует gawk)
awk '{for (i=1; i<=NF; i++) a[i][NR]=$i} END {for (i in a) {for (j in a[i]) printf "%s ", a[i][j]; print ""}}' matrix.txt

# Объединить строки
awk '{printf "%s ", $0} END {print ""}' multi_line.txt
```

## Советы

:::tip
Используйте `-F` для указания разделителя. Для табуляции: `-F'\t'`, для запятой: `-F','`.
:::

:::warning
Поля в `awk` нумеруются с 1, а не с 0. `$0` — вся строка.
:::

:::tip
Блоки `BEGIN` и `END` выполняются до и после обработки всех строк соответственно. Используйте их для инициализации и итогов.
:::

:::tip
Для сложных скриптов лучше использовать файл: `awk -f script.awk data.txt`.
:::

:::warning
`awk` использует собственные регулярные выражения, которые немного отличаются от `grep` или `sed`.
:::

## Связки с другими командами

```bash
# Общее потребление памяти всеми процессами (в МБ)
ps aux | awk '{sum+=$6} END {print sum/1024 " MB"}'

# Диски, заполненные более чем на 80%
df -h | awk 'NR>1 {gsub(/%/, "", $5); if ($5>80) print $6, $5"%"}'

# Топ-10 IP-адресов по количеству запросов
cat access.log | awk '{print $1}' | sort | uniq -c | sort -rn | head -10

# Процент использования оперативной памяти
free -m | awk '/Mem:/ {printf "Used: %.1f%%\n", $3/$2*100}'

# Частота входов по пользователям
last | awk '{print $1}' | sort | uniq -c | sort -rn

# Общий размер файлов в директории
ls -la | awk 'NR>1 {sum+=$5} END {print "Total:", sum/1024/1024, "MB"}'

# IP-адреса с неудачными попытками входа
cat /var/log/auth.log | awk '/Failed/{print $(NF-3)}' | sort | uniq -c | sort -rn

# Использование CPU по Docker-контейнерам
docker stats --no-stream | awk 'NR>1 {print $2, $3}'
```
