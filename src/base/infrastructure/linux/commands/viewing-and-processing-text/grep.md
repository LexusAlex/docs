# grep

`grep` - это поиск текстовых строк по шаблону.

## Поиск внутри файлов

````shell
grep -Rnwi / -e ""
````

## Ключи

- `-i` - игнорировать регистр
- `-R` - рекурсивный поиск в директориях + следовать символическим ссылкам
- `-n` - показать номера строк при совпадении
- `-w` - искать целые слова
