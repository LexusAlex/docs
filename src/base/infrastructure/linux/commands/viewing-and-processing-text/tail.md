# tail

Команда `tail` выводит конец файла — по умолчанию последние 10 строк. Поддерживает режим слежения за файлом.

## Синтаксис

```bash
tail [опции] файл...
tail -n количество файл
tail -f файл
```

## Основные опции

| Опция | Описание |
|-------|----------|
| `-n КОЛИЧЕСТВО` | Показать указанное количество строк с конца |
| `-c КОЛИЧЕСТВО` | Показать указанное количество байт с конца |
| `-f` | Следить за файлом (follow) — выводить новые строки |
| `-F` | Следить с повторным открытием (для ротации логов) |
| `--pid=PID` | Остановить слежение при завершении процесса |
| `-q` | Тихий режим — не показывать имена файлов |
| `-v` | Подробный режим — всегда показывать имена файлов |
| `-s СЕКУНДЫ` | Интервал обновления в режиме `-f` (по умолчанию 1) |
| `--retry` | Пробовать открыть файл, если он недоступен |

## Примеры

```bash
# Показать последние 10 строк (по умолчанию)
tail file.txt

# Показать последние 20 строк
tail -n 20 file.txt

# Показать последние 5 строк
tail -5 file.txt

# Показать последние 100 байт
tail -c 100 file.txt

# Следить за файлом в реальном времени
tail -f /var/log/syslog

# Следить с повторным открытием (для ротации логов)
tail -F /var/log/nginx/access.log

# Следить за несколькими файлами
tail -f file1.txt file2.txt

# Показать строки с 20-й с конца
tail -n +20 file.txt
# Показать начиная с 20-й строки с конца

# Остановить слежение при завершении процесса
tail -f --pid=1234 logfile.log

# Следить с интервалом 5 секунд
tail -f -s 5 logfile.log

# Просмотр конца вывода команды
dmesg | tail -20

# Последние 100 строк лога с именем файла
tail -v -n 100 /var/log/*.log

# Следить за файлом, который появится позже
tail -F /var/log/new_service.log
```

## Практические сценарии

### Мониторинг логов в реальном времени
```bash
# Следить за логами nginx
tail -f /var/log/nginx/access.log

# Фильтровать только ошибки
tail -f /var/log/nginx/error.log | grep "500"

# Следить за несколькими логами
tail -f /var/log/app/*.log
```

### Просмотр последних событий системы
```bash
# Последние системные сообщения
tail -n 50 /var/log/syslog

# Последние попытки входа
tail -n 20 /var/log/auth.log
```

### Работа с ротацией логов
```bash
# -F переживёт ротацию логов
tail -F /var/log/nginx/access.log
# Продолжит читать после ротации (rename + create)
```

### Отладка приложений
```bash
# Следить за выводом приложения
tail -f /tmp/app_debug.log | grep -E "(ERROR|WARN)"

# Остановить при завершении процесса
tail -f --pid=$! build.log
```

### Просмотр конца вывода команд
```bash
# Последние 5 запущенных процессов
ps aux | tail -6
```

## Советы

:::tip
Используйте `-F` вместо `-f` для логов, которые подвергаются ротации. Опция `-F` повторно откроет файл, если он был переименован или создан заново.
:::

:::warning
`tail -f` блокует терминал. Используйте `Ctrl+C` для остановки или запускайте в фоновом режиме с `&`.
:::

:::tip
Можно комбинировать: `tail -n +1 file | grep pattern` — вывести начиная с первой строки и отфильтровать.
:::

:::tip
Для мониторинга в реальном времени с подсветкой используйте: `tail -f log | ccze` или `tail -f log | colortail`.
:::
