# more

Команда `more` — это постраничный просмотрщик файлов, позволяющий просматривать содержимое по одной странице за раз.

## Синтаксис

```bash
more [опции] файл...
команда | more
```

## Основные опции

| Опция | Описание |
|-------|----------|
| `-d` | Показывать подсказки внизу экрана |
| `-f` | Считать логические строки, а не экранные |
| `-p` | Не прокручивать, а очищать экран перед каждой страницей |
| `-c` | Не прокручивать, а очищать и показывать сверху |
| `-s` | Сжимать несколько пустых строк в одну |
| `-n` | Количество строк на страницу |
| `+номер` | Начать показ с указанной строки |
| `+/паттерн` | Начать показ с найденного паттерна |

## Навигация

| Клавиша | Действие |
|---------|----------|
| `Space` | Следующая страница |
| `Enter` | Следующая строка |
| `b` | Предыдущая страница |
| `q` / `Q` | Выход |
| `/паттерн` | Искать вперёд |
| `n` | Следующее совпадение |
| `:n` | Следующий файл |
| `:p` | Предыдущий файл |
| `=` | Показать номер текущей строки |
| `:f` | Показать имя файла и номер строки |
| `!команда` | Выполнить команду оболочки |
| `h` | Показать справку |

## Примеры

```bash
# Просмотр файла
more /var/log/messages

# Просмотр с номерами строк и подсказками
more -d config.conf

# Просмотр вывода команды
ls -la /usr/bin | more

# Сжатие пустых строк
more -s log.txt

# Начать с определённой строки
more +50 script.sh

# Начать с паттерна
more +/"error" logfile.log

# Просмотр с 10 строками на страницу
more -10 short_file.txt

# Просмотр нескольких файлов
more file1.txt file2.txt file3.txt

# Просмотр с очисткой экрана
more -c document.txt

# Комбинирование с другими командами
dmesg | more
```

## Практические сценарии

### Быстрый просмотр логов
```bash
# Просмотр системных логов
more /var/log/syslog

# Используйте /pattern для поиска ошибок
# Нажмите n для перехода к следующему совпадению
```

### Просмотр длинного вывода команд
```bash
# Если вывод команды не помещается в экран
find / -name "*.conf" 2>/dev/null | more
```

### Просмотр нескольких файлов
```bash
# Просмотр набора файлов
more *.txt
# :n - следующий файл, :p - предыдущий
```

### Поиск в документации
```bash
# Просмотр с поиском
more +/"EXAMPLE" man_page.txt
```

## Сравнение с less

| Особенность | more | less |
|-------------|------|------|
| Прокрутка назад | Только на страницу | Полная |
| Поиск | Да | Да (расширенный) |
| Несколько файлов | Ограничено | Полная поддержка |
| Редактирование | Нет | Открытие в редакторе |
| Установка по умолчанию | Да (во многих системах) | Нет |

## Советы

:::tip
`more` доступен практически везде, даже в минимальных системах. Используйте его, когда `less` недоступен.
:::

:::warning
`more` не поддерживает прокрутку назад (кроме одной страницы через `b`). Для полноценной навигации используйте `less`.
:::

:::tip
Используйте опцию `-d` для получения подсказок — полезно для начинающих пользователей.
:::

:::warning
В некоторых системах `more` может вести себя иначе. Проверьте `man more` для вашей системы.
:::
