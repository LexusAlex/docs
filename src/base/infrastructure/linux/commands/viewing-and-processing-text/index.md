## Конвейеры

Эти команды часто используются в связке через pipe (`|`):

```bash
# Топ-10 IP по частоте в логах
cat access.log | awk '{print $1}' | sort | uniq -c | sort -rn | head -10

# Строки в файлах .py без комментариев
find . -type f -name "*.py" -exec grep -h -v "^#" -- {} + | wc -l

# Последние ошибки из лога
tail -100 /var/log/syslog | grep -i error | sort | uniq -c | sort -rn
```

## Сравнение команд обработки текста

| Задача | Лучшая команда | Альтернативы |
|--------|---------------|-------------|
| Найти строку в файле | `grep` | `sed -n '/pattern/p'`, `awk '/pattern/'` |
| Заменить текст в файле | `sed` | `awk gsub()`, `tr` (символы) |
| Выбрать столбец | `awk '{print $N}'` | `cut -d: -fN` |
| Отфильтровать строки | `grep -v pattern` | `awk '!/pattern/'` |
| Отсортировать строки | `sort` | — |
| Удалить дубликаты | `sort \| uniq` | `sort -u` |
| Подсчитать строки | `wc -l` | `grep -c ""` |
| Преобразовать JSON | `jq` | `python -m json.tool` |
| Сравнить файлы | `diff` | `comm`, `cmp` |
| Форматировать в таблицу | `column -t` | `awk printf` |

### Когда что использовать

- **grep** — поиск строк по шаблону. Быстрый, простой, для фильтрации.
- **sed** — замена, удаление, вставка строк. Потоковый редактор.
- **awk** — извлечение и преобразование данных. Столбцы, условия, вычисления.
- **cut** — простой выбор столбцов по разделителю.
- **tr** — замена/удаление отдельных символов.
- **sort/uniq** — сортировка и дедупликация.
- **wc** — подсчёт строк, слов, символов.
- **jq** — работа с JSON.
