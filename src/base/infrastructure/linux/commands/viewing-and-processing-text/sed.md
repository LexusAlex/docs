# sed

**Уровень:** Средний

Команда `sed` (stream editor) — потоковый редактор для выполнения преобразований текста.

## Синтаксис

```bash
sed [опции] 'команда' файл...
sed [опции] -e 'команда1' -e 'команда2' файл
sed [опции] -f скрипт файл
```

## Основные опции

| Опция | Описание |
|-------|----------|
| `-i` | Изменить файл на месте (in-place) |
| `-e ВЫРАЖЕНИЕ` | Добавить выражение (можно несколько) |
| `-f ФАЙЛ` | Читать команды из файла |
| `-n` | Подавить автоматический вывод |
| `-E` | Использовать расширенные регулярные выражения |
| `--in-place` | То же, что `-i` |
| `--regexp-extended` | То же, что `-E` |
| `--quiet` | То же, что `-n` |
| `--silent` | То же, что `-n` |

## Основные команды

| Команда | Описание |
|---------|----------|
| `s/pattern/replacement/flags` | Замена |
| `d` | Удалить строку |
| `p` | Напечатать строку |
| `i\текст` | Вставить текст перед строкой |
| `a\текст` | Добавить текст после строки |
| `c\текст` | Заменить строку текстом |
| `y/abc/xyz/` | Транслитерация символов |
| `q` | Выйти |
| `r файл` | Вставить содержимое файла |
| `w файл` | Записать строку в файл |

## Флаги замены

| Флаг | Описание |
|------|----------|
| `g` | Заменить все вхождения в строке |
| `N` | Заменить N-е вхождение |
| `p` | Напечатать строку после замены |
| `w файл` | Записать строку в файл после замены |
| `i` | Игнорировать регистр |
| `e` | Выполнить команду оболочки |

## Адресы

```
N          — строка N
$          — последняя строка
/pattern/  — строки, совпадающие с паттерном
N,M        — строки с N по M
N,+K       — строка N и следующие K строк
N~S         — каждая S-я строка, начиная с N
```

## Примеры

```bash
# Замена первого вхождения в строке
sed 's/old/new/' file.txt

# Замена всех вхождений в строке
sed 's/old/new/g' file.txt

# Замена с игнорированием регистра
sed 's/old/new/gi' file.txt

# Изменить файл на месте
sed -i 's/old/new/g' file.txt

# Создать резервную копию при изменении
sed -i.bak 's/old/new/g' file.txt

# Удалить строки
sed '/pattern/d' file.txt

# Удалить строку по номеру
sed '5d' file.txt

# Удалить строки с 5 по 10
sed '5,10d' file.txt

# Напечатать только совпадающие строки
sed -n '/pattern/p' file.txt

# Вставить строку перед совпадением
sed '/pattern/i\Новая строка' file.txt

# Добавить строку после совпадения
sed '/pattern/a\Новая строка' file.txt

# Заменить строку целиком
sed '/pattern/c\Новая строка' file.txt

# Несколько команд
sed -e 's/foo/bar/g' -e 's/baz/qux/g' file.txt

# Использовать расширенные regex
sed -E 's/[0-9]+/NUMBER/g' file.txt

# Обратные ссылки
sed 's/\(hello\) \(world\)/\2 \1/' file.txt

# Удалить пустые строки
sed '/^$/d' file.txt

# Удалить комментарии
sed '/^#/d' file.txt

# Добавить строку в начало файла
sed -i '1i\# Header' file.txt

# Замена в диапазоне строк
sed '5,10s/old/new/g' file.txt
```

## Практические сценарии

### Замена в конфигурационных файлах
```bash
# Заменить значение параметра
sed -i 's/^#Port 22/Port 2222/' /etc/ssh/sshd_config

# Закомментировать строку
sed -i 's/^option/# option/' config.conf

# Раскомментировать строку
sed -i 's/^# option/option/' config.conf
```

### Очистка данных
```bash
# Удалить пустые строки
sed '/^$/d' file.txt

# Удалить trailing пробелы
sed 's/[[:space:]]*$//' file.txt

# Удалить leading пробелы
sed 's/^[[:space:]]*//' file.txt

# Удалить комментарии и пустые строки
sed -e '/^#/d' -e '/^$/d' config.conf
```

### Обработка логов
```bash
# Извлечь определённые поля
sed 's/.*\[\(.*\)\].*/\1/' access.log

# Заменить формат даты
sed 's|\([0-9]\{2\}\)/\([0-9]\{2\}\)/\([0-9]\{4\}\)|\3-\2-\1|g' dates.txt
```

### Массовая замена
```bash
# Замена во всех файлах
find . -name "*.txt" -exec sed -i 's/old/new/g' {} +

# Замена в файлах с резервной копией
find . -name "*.conf" -exec sed -i.bak 's/old/new/g' {} +
```

### Трансформация форматов
```bash
# CSV в TSV
sed 's/,/\t/g' data.csv > data.tsv

# Добавить кавычки вокруг полей
sed 's/[^,]*/"&"/g' data.csv
```

## Советы

:::tip
Используйте `-i.bak` вместо `-i` для создания резервных копий при in-place редактировании.
:::

:::warning
Будьте осторожны с `sed -i` — изменения необратимы. Всегда делайте резервные копии или тестируйте без `-i` сначала.
:::

:::tip
Для сложных замен используйте расширенные regex с `-E`. Это позволяет использовать `+`, `?`, `()` без экранирования.
:::

:::tip
Для многострочных замен используйте `N` команду: `sed '/pattern/{N;s/\n/ /}' file.txt`.
:::

:::warning
Разделитель в команде `s` может быть любым символом. Удобно использовать `|` или `#` для путей: `sed 's|/old/path|/new/path|g'`.
:::

## Связки с другими командами

```bash
# Удалить комментарии и пустые строки из конфига
cat config.yml | sed '/^#/d; /^$/d'

# Заменить слово и преобразовать в верхний регистр
echo "Hello World" | sed 's/World/Linux/g' | tr '[:lower:]' '[:upper:]'

# Пропустить первые 5 строк и показать следующие 20
cat file.txt | sed '1,5d' | head -20

# Уникальные файлы с TODO-комментариями
grep -r "TODO" --include="*.py" | sed 's/:.*$//' | sort -u

# Извлечь все server-блоки из конфига nginx
cat /etc/nginx/nginx.conf | sed -n '/server {/,/}/p'

# Извлечь IP-адреса из вывода ip addr
ip addr | sed -n '/inet /p' | awk '{print $2}'

# Преобразовать CSV в читаемую таблицу
cat file.csv | sed 's/,/|/g' | column -t -s '|'

# Показать события от ошибки до разрешения
journalctl | sed -n '/error/I,/resolved/Ip'
```
