# tr

**Уровень:** Средний

Команда `tr` (translate) транслирует или удаляет символы из стандартного ввода.

## Синтаксис

```bash
tr [опции] СИМВОЛЫ1 СИМВОЛЫ2
команда | tr [опции] СИМВОЛЫ1 СИМВОЛЫ2
tr -d СИМВОЛЫ
tr -s СИМВОЛЫ
```

## Основные опции

| Опция | Описание |
|-------|----------|
| `-d` | Удалить указанные символы |
| `-s` | Сжать повторяющиеся символы в один |
| `-c` | Дополнение (все символы КРОМЕ указанных) |
| `-t` | Обрезать первый набор по длине второго |
| `--delete` | То же, что `-d` |
| `--squeeze-repeats` | То же, что `-s` |
| `--complement` | То же, что `-c` |

## Классы символов

| Класс | Описание |
|-------|----------|
| `[:upper:]` | Прописные буквы (A-Z) |
| `[:lower:]` | Строчные буквы (a-z) |
| `[:alpha:]` | Все буквы |
| `[:digit:]` | Цифры (0-9) |
| `[:alnum:]` | Буквы и цифры |
| `[:space:]` | Пробельные символы |
| `[:blank:]` | Пробел и табуляция |
| `[:punct:]` | Знаки пунктуации |
| `[:print:]` | Печатаемые символы |
| `[:graph:]` | Видимые символы |
| `[:xdigit:]` | Hex-цифры (0-9, a-f, A-F) |

## Специальные символы

| Символ | Описание |
|--------|----------|
| `\n` | Новая строка |
| `\t` | Табуляция |
| `\r` | Возврат каретки |
| `\\` | Обратный слэш |
| `\NNN` | Символ в восьмеричной системе |

## Примеры

```bash
# Перевести в верхний регистр
echo "hello" | tr 'a-z' 'A-Z'

# Перевести в нижний регистр
echo "HELLO" | tr 'A-Z' 'a-z'

# Использование классов символов
echo "Hello World" | tr '[:lower:]' '[:upper:]'

# Замена символов
echo "hello world" | tr ' ' '_'

# Удалить символы
echo "hello 123 world" | tr -d '0-9'

# Сжать пробелы
echo "hello     world" | tr -s ' '

# Удалить и сжать
echo "aabbccdd" | tr -s 'a-z'

# Замена нескольких символов
echo "hello" | tr 'elo' 'ELO'

# Дополнение (все кроме указанных)
echo "hello123" | tr -cd '0-9'

# Удалить всё кроме букв и пробелов
echo "hello! world@ 123" | tr -cd '[:alpha:] '

# Сжать повторяющиеся пробелы
echo "many     spaces" | tr -s ' '

# Удалить пустые строки
cat file.txt | tr -s '\n'

# Перевести DOS в UNIX формат
cat file.txt | tr -d '\r' > file_unix.txt

# Перевести UNIX в DOS формат
cat file.txt | sed 's/$/\r/' > file_dos.txt

# Замена разделителей
echo "one:two:three" | tr ':' '\t'

# Удалить непечатаемые символы
cat binary_file | tr -cd '[:print:]\n'
```

## Практические сценарии

### Конвертация регистра
```bash
# Перевести файл в нижний регистр
cat file.txt | tr '[:upper:]' '[:lower:]' > lower.txt

# Перевести файл в верхний регистр
cat file.txt | tr '[:lower:]' '[:upper:]' > upper.txt
```

### Очистка данных
```bash
# Удалить всё кроме букв и цифр
cat data.txt | tr -cd '[:alnum:]\n' > clean.txt

# Удалить знаки пунктуации
cat text.txt | tr -d '[:punct:]' > no_punct.txt
```

### Форматирование вывода
```bash
# Замена разделителей
cat data.csv | tr ',' '\t' > data.tsv

# Замена табуляций на пробелы
cat Makefile | tr '\t' ' ' > spaces.txt
```

### Работа с форматами строк
```bash
# Удалить \r из Windows-файлов
cat file.txt | tr -d '\r' > file_unix.txt

# Добавить \r для Windows
cat file.txt | sed 's/$/\r/' > file_win.txt
```

### Генерация данных
```bash
# Случайная строка
cat /dev/urandom | tr -dc 'a-zA-Z0-9' | head -c 32

# Случайный пароль
cat /dev/urandom | tr -dc '[:graph:]' | head -c 16
```

## Советы

:::tip
`tr` работает только со стандартным вводом. Для работы с файлом используйте перенаправление: `tr ... < file` или `cat file | tr ...`.
:::

:::warning
`tr` не принимает файл как аргумент — только stdin. Используйте `< file` или пайп.
:::

:::tip
Используйте классы символов (`[:upper:]`, `[:lower:]`) вместо явного перечисления для большей переносимости.
:::

:::warning
При замене символов второй набор не может быть длиннее первого. Если первый набор длиннее, используйте `-t` для обрезки.
:::
