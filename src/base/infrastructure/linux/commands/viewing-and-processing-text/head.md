# head

Команда `head` выводит начало файла — по умолчанию первые 10 строк.

## Синтаксис

```bash
head [опции] файл...
head -n количество файл
head -c количество файл
```

## Основные опции

| Опция | Описание |
|-------|----------|
| `-n КОЛИЧЕСТВО` | Показать указанное количество строк (по умолчанию 10) |
| `-c КОЛИЧЕСТВО` | Показать указанное количество байт |
| `-q` | Тихий режим — не показывать имена файлов |
| `-v` | Подробный режим — всегда показывать имена файлов |
| `--lines=N` | То же, что `-n N` |
| `--bytes=N` | То же, что `-c N` |

## Примеры

```bash
# Показать первые 10 строк (по умолчанию)
head file.txt

# Показать первые 20 строк
head -n 20 file.txt

# Показать первые 5 строк
head -5 file.txt

# Показать первые 100 байт
head -c 100 file.txt

# Показать первые 1 КБ
head -c 1K file.txt

# Показать первые 1 МБ
head -c 1M largefile.bin

# Просмотр начала нескольких файлов
head -n 5 file1.txt file2.txt file3.txt

# Тихий режим (без имён файлов)
head -q -n 3 *.txt

# Подробный режим (с именами файлов)
head -v -n 3 file1.txt file2.txt

# Просмотр начала вывода команды
ps aux | head -20

# Просмотр первых строк CSV-файла
head -n 5 data.csv

# Просмотр структуры JSON
curl -s https://api.example.com | head -c 500

# Показать все строки кроме последних N
head -n -5 file.txt
# Показать все строки кроме последних 5
```

## Практические сценарии

### Просмотр заголовков CSV
```bash
# Быстрый просмотр структуры CSV
head -n 1 data.csv
# Показывает только заголовки

# Просмотр первых нескольких записей
head -n 10 data.csv
```

### Проверка логов
```bash
# Просмотр начала лог-файла
head -n 50 /var/log/nginx/access.log

# Просмотр первых ошибок
head -n 20 error.log
```

### Работа с выводом команд
```bash
# Первые 5 процессов по использованию памяти
ps aux --sort=-%mem | head -6
# 6, потому что первая строка — заголовок

# Первые 10 файлов по размеру
du -sh * | sort -rh | head -10
```

### Извлечение бинарных данных
```bash
# Извлечь первые 512 байт (один сектор)
head -c 512 disk_image.bin > boot_sector.bin
```

### Просмотр README
```bash
# Быстрый просмотр начала документации
head -n 30 README.md
```

## Советы

:::tip
Можно использовать отрицательные значения с `-n`: `head -n -5 file.txt` покажет все строки кроме последних пяти.
:::

:::warning
Опция `-c` считает байты, а не символы. Для многобайтовых символов (UTF-8) результат может отличаться от ожидаемого.
:::

:::tip
При работе с несколькими файлами используйте `-q` чтобы убрать заголовки с именами файлов, или `-v` чтобы добавить их.
:::

:::tip
Для вывода команды с `head` используйте пайп: `command | head -n 20`. Это полезно для ограничения длинного вывода.
:::
