# less

**Уровень:** Начинающий

Команда `less` — это постраничный просмотрщик файлов с поддержкой прокрутки, поиска и навигации в обоих направлениях.

## Синтаксис

```bash
less [опции] файл...
команда | less
less < файл
```

## Основные опции

| Опция | Описание |
|-------|----------|
| `-N` | Показать номера строк |
| `-S` | Не переносить длинные строки |
| `-F` | Выйти, если файл помещается на один экран |
| `-X` | Не очищать экран при выходе |
| `-i` | Игнорировать регистр при поиске |
| `-R` | Показать ANSI-цвета |
| `-g` | Подсветить только текущее совпадение при поиске |
| `-s` | Сжимать несколько пустых строк в одну |
| `-p строка` | Начать показ с указанной строки/паттерна |
| `-m` | Подробный индикатор позиции |

## Навигация

| Клавиша | Действие |
|---------|----------|
| `Space` / `f` | Следующая страница |
| `b` | Предыдущая страница |
| `g` | Переход к началу файла |
| `G` | Переход к концу файла |
| `j` / `Enter` | Следующая строка |
| `k` | Предыдущая строка |
| `q` | Выход |
| `d` | Полстраницы вниз |
| `u` | Полстраницы вверх |

## Поиск

| Клавиша | Действие |
|---------|----------|
| `/паттерн` | Искать вперёд |
| `?паттерн` | Искать назад |
| `n` | Следующее совпадение |
| `N` | Предыдущее совпадение |
| `&паттерн` | Показать только строки с совпадением |

## Закладки

| Клавиша | Действие |
|---------|----------|
| `m` + буква | Установить закладку |
| `'` + буква | Перейти к закладке |

## Примеры

```bash
# Просмотр файла
less /var/log/syslog

# Просмотр с номерами строк
less -N script.py

# Просмотр без переноса длинных строк
less -S wide_table.csv

# Автовыход для коротких файлов
less -F short_file.txt

# Сохранение ANSI-цветов (вывод git diff)
git diff | less -R

# Поиск с игнорированием регистра
less -i README.md
# Затем введите /search_term

# Просмотр нескольких файлов
less file1.txt file2.txt file3.txt
# Используйте :n для следующего файла, :p для предыдущего

# Начать просмотр с определённой строки
less -N +100 script.py

# Начать с паттерна
less -p "error" /var/log/syslog

# Сжатие пустых строк
less -s log.txt

# Просмотр вывода команды
ps aux | less

# Поиск в less
# Введите /pattern для поиска вперёд
# Используйте n/N для навигации между совпадениями

# Использование закладок
# Нажмите ma (установить закладку 'a')
# Позже нажмите 'a (перейти к закладке 'a')
```

## Практические сценарии

### Просмотр логов в реальном времени
```bash
# В less можно следить за файлом (аналог tail -f)
less +F /var/log/nginx/access.log
# Ctrl+C для остановки, затем q для выхода
```

### Изучение вывода git
```bash
git log --oneline --graph --all | less -R
# Просмотр дерева коммиттов с цветами
```

### Навигация по большим файлам
```bash
# Открыть файл и сразу перейти к концу
less +G largefile.log
# Или к началу: less +g file
```

### Поиск в документации
```bash
man bash | less -p "SHELL GRAMMAR"
# Сразу открыть man на нужной секции
```

### Просмотр JSON
```bash
curl -s https://api.example.com/data | python3 -m json.tool | less
```

## Советы

:::tip
Внутри `less` нажмите `h` для просмотра справки по всем командам навигации.
:::

:::warning
`less` очищает экран при выходе по умолчанию. Если нужно сохранить вывод на экране, используйте опцию `-X` или настройте переменную `LESS` экспортом `LESS='-X'`.
:::

:::tip
Для ANSI-цветов (например, вывод `git diff --color`) всегда используйте `less -R`, иначе цветовые коды будут отображаться как мусор.
