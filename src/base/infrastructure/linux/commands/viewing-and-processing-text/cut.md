# cut

**Уровень:** Начинающий

Команда `cut` вырезает секции из каждой строки файла — поля, символы или байты.

## Синтаксис

```bash
cut ОПЦИЯ файл...
cut -d разделитель -f номера файл
cut -c номера файл
cut -b номера файл
```

## Основные опции

| Опция | Описание |
|-------|----------|
| `-d РАЗДЕЛИТЕЛЬ` | Указать разделитель полей (по умолчанию табуляция) |
| `-f НОМЕРА` | Выбрать поля (номера через запятую или диапазоны) |
| `-c НОМЕРА` | Выбрать символы по позиции |
| `-b НОМЕРА` | Выбрать байты по позиции |
| `--complement` | Инвертировать выбор (всё кроме указанных) |
| `--output-delimiter=СТРОКА` | Заменить разделитель в выводе |
| `-s` | Не выводить строки без разделителя |
| `--only-delimited` | То же, что `-s` |

## Формат номеров

```
N     — конкретный номер
N-M   — диапазон от N до M
N-    — от N до конца
-M    — от начала до M
N,M,P — конкретные номера через запятую
```

## Примеры

```bash
# Вырезать первый символ каждой строки
cut -c1 file.txt

# Вырезать символы 1-5
cut -c1-5 file.txt

# Вырезать символы с 10-й до конца
cut -c10- file.txt

# Вырезать первый и третий символы
cut -c1,3 file.txt

# Вырезать первое поле (разделитель — табуляция)
cut -f1 file.tsv

# Вырезать первое и третье поле
cut -f1,3 file.csv

# Вырезать поля с 2-го по 4-й
cut -f2-4 data.csv

# Использовать запятую как разделитель
cut -d',' -f1 data.csv

# Использовать двоеточие как разделитель
cut -d':' -f1,3 /etc/passwd

# Вырезать всё кроме первого поля
cut -d',' --complement -f1 data.csv

# Заменить разделитель в выводе
cut -d':' -f1,7 --output-delimiter=' -> ' /etc/passwd

# Не выводить строки без разделителя
cut -d',' -f1 -s mixed_file.txt

# Вырезать байты
cut -b1-10 binary_file.dat

# Комбинация с другими командами
ps aux | cut -d' ' -f1,11-
```

## Практические сценарии

### Парсинг /etc/passwd
```bash
# Имена пользователей
cut -d':' -f1 /etc/passwd

# Домашние директории
cut -d':' -f6 /etc/passwd

# Пользователи с оболочками
cut -d':' -f1,7 /etc/passwd | grep -v nologin
```

### Обработка CSV-файлов
```bash
# Первый столбец CSV
cut -d',' -f1 data.csv

# Первый и третий столбцы
cut -d',' -f1,3 data.csv

# Все столбцы кроме второго
cut -d',' --complement -f2 data.csv
```

### Анализ логов
```bash
# IP-адреса из access.log
cut -d' ' -f1 /var/log/nginx/access.log

# Уникальные IP
cut -d' ' -f1 access.log | sort -u

# URL-адреса
cut -d'"' -f2 access.log | cut -d' ' -f2
```

### Работа с переменными окружения
```bash
# Путь из PATH
echo $PATH | cut -d':' -f1

# Все директории из PATH
echo $PATH | tr ':' '\n' | cut -d':' -f1
```

### Извлечение данных из вывода команд
```bash
# Имена процессов
ps aux | cut -c66-

# Пользователи процессов
ps aux | cut -d' ' -f1 | sort -u
```

## Советы

:::tip
Используйте `--complement` для инвертирования выбора — это удобно, когда нужно удалить один столбец из многих.
:::

:::warning
`cut` не поддерживает несколько символов в качестве разделителя. Для сложных случаев используйте `awk` или `sed`.
:::

:::tip
Для CSV с кавычками (где запятая может быть внутри значения) `cut` не подходит. Используйте `csvtool`, `mlr` или `python`.
:::

:::tip
Опция `--output-delimiter` позволяет преобразовать разделитель: `cut -d',' -f1-3 --output-delimiter='|' data.csv`.
:::

## Связки с другими командами

```bash
# Имена пользователей и их оболочки
cat /etc/passwd | cut -d: -f1,7 | sort

# Процент использования дисков
df -h | cut -d'%' -f1 | awk '{print $5, $6}'

# IP-адреса с CIDR-notation из вывода ip addr
ip addr | grep inet | cut -d' ' -f6

# Топ IP-адресов по количеству запросов
cat access.log | cut -d' ' -f1 | sort | uniq -c | sort -rn

# Частота входов по пользователям
last | cut -d' ' -f1 | sort | uniq -c | sort -rn
```
