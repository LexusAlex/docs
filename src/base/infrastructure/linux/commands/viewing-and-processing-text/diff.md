# diff

**Уровень:** Начинающий

Команда `diff` сравнивает файлы построчно и показывает различия между ними.

## Синтаксис

```bash
diff [опции] файл1 файл2
diff [опции] директория1 директория2
```

## Основные опции

| Опция | Описание |
|-------|----------|
| `-u` | Объединённый формат (unified) |
| `-c` | Контекстный формат |
| `-y` | Сравнение рядом (side-by-side) |
| `--width=N` | Ширина для side-by-side формата |
| `-q` | Показать только, отличаются ли файлы |
| `-s` | Показать, если файлы идентичны |
| `-i` | Игнорировать регистр |
| `-w` | Игнорировать пробелы |
| `-B` | Игнорировать пустые строки |
| `-r` | Рекурсивное сравнение директорий |
| `--brief` | То же, что `-q` |
| `--color` | Цветной вывод |
| `-N` | Считать отсутствующие файлы пустыми |
| `--new-file` | То же, что `-N` |
| `-p` | Показать имя функции |
| `--unified=N` | Количество контекстных строк |

## Символы в выводе

| Символ | Значение |
|--------|----------|
| `<` | Строка только в первом файле |
| `>` | Строка только во втором файле |
| `---` | Разделитель между файлами |
| `@@` | Диапазон строк в unified формате |

## Примеры

```bash
# Простое сравнение
diff file1.txt file2.txt

# Объединённый формат (для патчей)
diff -u old.txt new.txt

# Контекстный формат
diff -c old.txt new.txt

# Сравнение рядом
diff -y file1.txt file2.txt

# Сравнение с шириной 120 символов
diff -y --width=120 file1.txt file2.txt

# Только узнать, отличаются ли файлы
diff -q file1.txt file2.txt

# Показать идентичные файлы
diff -s file1.txt file2.txt

# Игнорировать пробелы
diff -w file1.txt file2.txt

# Игнорировать регистр
diff -i file1.txt file2.txt

# Рекурсивное сравнение директорий
diff -r dir1/ dir2/

# Сравнение с цветом
diff --color old.txt new.txt

# Создать патч-файл
diff -u old.txt new.txt > changes.patch

# Применить патч
patch old.txt < changes.patch

# Сравнение с контекстом
diff -U3 old.txt new.txt
# 3 контекстные строки (по умолчанию)

# Игнорировать пустые строки
diff -B file1.txt file2.txt

# Показать имя функции в diff
diff -p old.c new.c
```

## Практические сценарии

### Создание и применение патчей
```bash
# Создать патч
diff -u original.conf modified.conf > config.patch

# Применить патч
patch original.conf < config.patch

# Отменить патч
patch -R original.conf < config.patch
```

### Сравнение конфигураций
```bash
# Сравнить два конфига
diff -u /etc/nginx/nginx.conf.bak /etc/nginx/nginx.conf

# Рекурсивно сравнить директории конфигов
diff -r /etc/nginx/sites-available/ /etc/nginx/sites-enabled/
```

### Проверка изменений в Git
```bash
# Изменения в текущем репозитории
git diff

# Сравнение веток
git diff main..feature

# Использование diff напрямую
diff -u <(git show HEAD:file.txt) file.txt
```

### Сравнение вывода команд
```bash
# Сравнить вывод двух команд
diff <(command1) <(command2)

# Пример
diff <(ps aux | sort) <(ps aux | head -20 | sort)
```

### Автоматическое сравнение
```bash
# Проверка изменений в крон
diff -q /backup/config /etc/config || echo "Конфиг изменился!"

# Мониторинг изменений
while true; do
  diff -q old.txt new.txt || echo "Файл изменился!"
  cp new.txt old.txt
  sleep 60
done
```

## Советы

:::tip
Используйте `-u` (unified format) для создания патчей — это стандартный формат, понимаемый командой `patch`.
:::

:::warning
`diff` возвращает код выхода 0 если файлы идентичны, 1 если различаются, и 2 при ошибках. Используйте это в скриптах.
:::

:::tip
Для цветного вывода используйте `diff --color` или настройте алиас: `alias diff='diff --color'`.
:::

:::warning
При рекурсивном сравнении (`-r`) `diff` не игнорирует файлы, указанные в `.gitignore`. Используйте `git diff` для репозиториев.
:::

:::tip
Для сравнения вывода команд используйте процесс-замыкания: `diff <(cmd1) <(cmd2)`.
