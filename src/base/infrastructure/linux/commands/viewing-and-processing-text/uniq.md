# uniq

**Уровень:** Начинающий

Команда `uniq` фильтрует или выводит повторяющиеся строки из отсортированного файла.

## Синтаксис

```bash
uniq [опции] [входной [выходной]]
sort файл | uniq [опции]
```

## Основные опции

| Опция | Описание |
|-------|----------|
| `-c` | Подсчитать количество повторений |
| `-d` | Показать только дубликаты |
| `-u` | Показать только уникальные строки |
| `-i` | Игнорировать регистр при сравнении |
| `-f N` | Пропустить первых N полей при сравнении |
| `-s N` | Пропустить первых N символов при сравнении |
| `-w N` | Сравнивать только первых N символов |
| `--count` | То же, что `-c` |
| `--repeated` | То же, что `-d` |
| `--unique` | То же, что `-u` |
| `--group` | Группировать одинаковые строки |

## Примеры

```bash
# Удалить повторяющиеся строки (файл ДОЛЖЕН быть отсортирован!)
uniq sorted.txt

# Подсчитать количество повторений
sort file.txt | uniq -c

# Показать только дубликаты
sort file.txt | uniq -d

# Показать только уникальные строки
sort file.txt | uniq -u

# Подсчитать с сортировкой по количеству
sort file.txt | uniq -c | sort -rn

# Игнорировать регистр
sort file.txt | uniq -ci

# Пропустить первое поле при сравнении
uniq -f1 data.txt

# Пропустить первые 5 символов
uniq -s5 file.txt

# Сравнивать только первые 10 символов
uniq -w10 file.txt

# Группировать одинаковые строки
sort file.txt | uniq --group

# Уникальные IP-адреса
sort access.log | uniq -u

# Самые частые значения
sort data.txt | uniq -c | sort -rn | head -10

# Уникальные пользователи
cut -d' ' -f1 access.log | sort | uniq

# Комбинация с другими командами
ps aux | awk '{print $1}' | sort | uniq -c | sort -rn
```

## Практические сценарии

### Анализ частотности
```bash
# Топ-10 самых частых IP-адресов
cut -d' ' -f1 access.log | sort | uniq -c | sort -rn | head -10

# Самые запрашиваемые URL
cut -d'"' -f2 access.log | cut -d' ' -f2 | sort | uniq -c | sort -rn | head -10
```

### Удаление дубликатов из списков
```bash
# Уникальные email-адреса
sort emails.txt | uniq > unique_emails.txt

# Уникальные пользователи
cat users.txt | sort | uniq > unique_users.txt
```

### Поиск ошибок
```bash
# Уникальные сообщения об ошибках
grep "ERROR" app.log | sort | uniq -c | sort -rn

# Повторяющиеся ошибки
grep "ERROR" app.log | sort | uniq -d
```

### Анализ данных
```bash
# Уникальные значения в столбце
cut -d',' -f3 data.csv | sort | uniq

# Количество уникальных значений
cut -d',' -f3 data.csv | sort | uniq | wc -l
```

### Проверка данных
```bash
# Найти дубликаты в списке
sort list.txt | uniq -d

# Проверить наличие дубликатов
sort list.txt | uniq -d | wc -l
# Если > 0, есть дубликаты
```

## Советы

:::warning
`uniq` работает ТОЛЬКО с отсортированными файлами! Всегда используйте `sort` перед `uniq` для корректной работы.
:::

:::tip
Для удаления дубликатов без сортировки (сохраняя порядок) используйте: `awk '!seen[$0]++' file.txt`.
:::

:::tip
Комбинация `sort | uniq -c | sort -rn` — классический паттерн для анализа частотности в Linux.
:::

:::warning
Опция `-f` пропусляет поля (разделённые пробелами), а не символы. Для пропуска символов используйте `-s`.
:::

:::tip
Для подсчёта уникальных значений без вывода: `sort file.txt | uniq | wc -l`.

## Связки с другими командами

```bash
# Топ-20 IP-адресов по количеству запросов
cat access.log | awk '{print $1}' | sort | uniq -c | sort -rn | head -20

# Топ сервисов по количеству сообщений в журнале
journalctl | awk '{print $5}' | sort | uniq -c | sort -rn | head

# Частота входов по пользователям
last | awk '{print $1}' | sort | uniq -c | sort -rn

# Источники сообщений ядра
dmesg | awk '{print $4}' | sed 's/\[.*\]//' | sort | uniq -c | sort -rn

# IP-адреса с неудачными попытками входа
cat /var/log/auth.log | grep "Failed" | awk '{print $(NF-3)}' | sort | uniq -c | sort -rn
```
