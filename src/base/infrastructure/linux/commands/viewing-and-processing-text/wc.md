# wc

**Уровень:** Начинающий

Команда `wc` (word count) подсчитывает количество строк, слов, байтов и символов в файлах.

## Синтаксис

```bash
wc [опции] файл...
команда | wc [опции]
```

## Основные опции

| Опция | Описание |
|-------|----------|
| `-l` | Подсчитать только строки |
| `-w` | Подсчитать только слова |
| `-c` | Подсчитать только байты |
| `-m` | Подсчитать только символы (учитывает многобайтовые кодировки) |
| `-L` | Показать длину самой длинной строки |
| `--files0-from=ФАЙЛ` | Читать имена файлов из указанного файла |

## Примеры

```bash
# Полная статистика файла
wc file.txt
# Вывод: строки слова байты файл.txt

# Подсчёт строк
wc -l file.txt

# Подсчёт слов
wc -w file.txt

# Подсчёт байтов
wc -c file.txt

# Подсчёт символов (для UTF-8)
wc -m file.txt

# Длина самой длинной строки
wc -L file.txt

# Статистика по нескольким файлам
wc *.txt

# Подсчёт строк в выводе команды
ps aux | wc -l

# Подсчёт файлов в директории
ls -1 | wc -l

# Подсчёт слов в документе
wc -w README.md

# Подсчёт символов в строке
echo -n "Привет мир" | wc -m

# Подсчёт строк кода (без пустых)
grep -c '.' script.py
# Или:
cat script.py | grep -v '^$' | wc -l

# Подсчёт уникальных значений
sort file.txt | uniq | wc -l

# Тихий режим (только итог для нескольких файлов)
wc -l *.log | tail -1
```

## Практические сценарии

### Подсчёт строк коды
```bash
# Количество строк во всех Python-файлах
find . -name "*.py" -exec wc -l {} + | tail -1

# Подсчёт строк по типам файлов
find . -type f -name "*.js" -exec wc -l -- {} + | tail -n 1
find . -type f -name "*.ts" -exec wc -l -- {} + | tail -n 1
```

### Мониторинг логов
```bash
# Количество строк в логе
wc -l /var/log/nginx/access.log

# Проверка роста лога
watch -n 5 'wc -l /var/log/app.log'
```

### Анализ данных
```bash
# Количество записей в CSV (минус заголовок)
tail -n +2 data.csv | wc -l

# Количество уникальных пользователей
cut -d: -f1 access.log | sort -u | wc -l
```

### Проверка размера вывода
```bash
# Сколько процессов запущено
ps aux | wc -l

# Сколько файлов в архиве
tar -tf archive.tar.gz | wc -l
```

### Проверка длины строк
```bash
# Найти строки длиннее 80 символов
awk 'length > 80' file.txt | wc -l

# Показать длину самой длинной строки
wc -L file.txt
```

## Советы

:::tip
Используйте `-m` вместо `-c` для подсчёта символов в UTF-8 файлах. Опция `-c` считает байты, а `-m` — реальные символы.
:::

:::warning
При подсчёте строк с помощью `wc -l` учитывается количество символов новой строки (`\n`). Последняя строка без `\n` не будет посчитана.
:::

:::tip
Для подсчёта только итогового значения при обработке нескольких файлов: `wc -l *.txt | tail -1`.
:::

:::tip
Комбинация `sort | uniq -c | sort -rn` часто используется вместе с `wc` для анализа частотности.
:::

## Связки с другими командами

```bash
# Python-файлы, отсортированные по количеству строк
find . -type f -name "*.py" -exec wc -l -- {} + | sort -rn | head

# Общее количество строк в системном логе
cat /var/log/syslog | wc -l

# Количество файлов в директории (включая . и ..)
ls -la | wc -l

# Количество запущенных процессов
ps aux | wc -l

# Количество системных пользователей
cat /etc/passwd | wc -l

# Количество import-строк во всех Python-файлах
grep -r "import" --include="*.py" | wc -l
```
