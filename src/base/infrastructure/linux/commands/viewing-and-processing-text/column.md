# column

**Уровень:** Средний

Команда `column` форматирует текст в виде таблицы с колонками.

## Синтаксис

```bash
column [опции] файл...
команда | column [опции]
```

## Основные опции

| Опция | Описание |
|-------|----------|
| `-t` | Создать таблицу (автоопределение колонок) |
| `-s РАЗДЕЛИТЕЛЬ` | Указать разделитель колонок |
| `-o РАЗДЕЛИТЕЛЬ` | Указать разделитель вывода |
| `-c ШИРИНА` | Максимальная ширина строки |
| `-x` | Заполнить столбцы перед строками |
| `-J` | Вывести в формате JSON |
| `-N СПИСОК` | Имена колонок через запятую |
| `-H СПИСОК` | Скрыть указанные колонки |
| `--json` | JSON-формат вывода |

## Примеры

```bash
# Простое форматирование в таблицу
mount | column -t

# С указанным разделителем
cat /etc/passwd | column -t -s ':'

# CSV в таблицу
cat data.csv | column -t -s ','

# Форматирование вывода команды
df -h | column -t

# Указать имена колонок вручную
column -t -N "Имя,Возраст,Город" data.csv

# Указать разделитель вывода
column -t -s ',' -o '|' data.csv

# Ограничить ширину строки
column -t -c 80 wide_data.txt

# Заполнение по столбцам
column -t -x data.txt

# JSON-вывод (требует -N для имён колонок)
column -t -N "Имя,Возраст,Город" --json data.csv

# Форматирование вывода ps
ps aux | column -t

# Форматирование вывода ls
ls -l | column -t

# Скрыть колонки
column -t -H "2,4" data.csv

# Форматирование CSV с заголовками
echo -e "Name,Age,City\nAlice,30,Moscow\nBob,25,SPB" | column -t -s ','

# Форматирование вывода с разделителем
echo -e "key1\tvalue1\nkey2\tvalue2" | column -t
```

## Практические сценарии

### Форматирование вывода команд
```bash
# Красивый вывод df
df -h | column -t

# Красивый вывод mount
mount | column -t

# Красивый вывод /etc/fstab
column -t /etc/fstab
```

### Обработка CSV-файлов
```bash
# Просмотр CSV как таблицы
column -t -s ',' data.csv

# С заголовками
column -t -s ',' -n data.csv

# Экспорт в другой разделитель
column -t -s ',' -o '|' data.csv > data.txt
```

### Анализ данных
```bash
# Форматирование вывода ps
ps aux | head -20 | column -t

# Форматирование вывода free
free -h | column -t

# Форматирование вывода ip addr
ip addr | column -t
```

### Создание отчётов
```bash
# Красивый вывод в файл
column -t -s ',' data.csv > report.txt

# JSON-отчёт
column -t -s ',' --json data.csv > report.json
```

### Работа с логами
```bash
# Форматирование структурированных логов
cat app.log | column -t -s '|' | less
```

## Советы

:::tip
Используйте `-t` для автоматического определения колонок на основе разделителей. Это самый часто используемый режим работы.
:::

:::warning
`column` может некорректно обрабатывать данные с кавычками (например, CSV с запятыми внутри значений). Для сложных CSV используйте `csvtool` или `python`.
:::

:::tip
Для просмотра CSV с заголовками используйте `-n` — первая строка будет интерпретироваться как заголовки колонок.
:::

:::warning
На некоторых системах (старые версии util-linux) опция `-n` может отсутствовать. Проверьте `man column` для вашей системы.
:::

:::tip
Комбинация `column -t -s ','` — быстрый способ просмотреть CSV-файл в терминале в виде таблицы.
:::
