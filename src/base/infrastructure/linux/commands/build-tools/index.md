# Инструменты сборки

Утилиты для автоматизации сборки, тестирования и развёртывания проектов.

## Команды

| Команда | Описание |
|---------|----------|
| [make](make.md) | Классическая утилита автоматизации сборки через Makefile |

## Зачем нужны инструменты сборки?

- **Автоматизация** — повторяемые команды в одном вызове
- **Зависимости** — правильный порядок выполнения задач
- **Инкрементальность** — пересборка только изменённых файлов
- **Портируемость** — одинаковая сборка на разных машинах

## Когда использовать make

- Сборка C/C++ проектов
- Запуск тестов и линтеров
- Деплой приложений
- Управление Docker-образами
- Любая задача с зависимостями между шагами
