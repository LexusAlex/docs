# ssh-keygen

Утилита для генерации, управления и конвертации SSH-ключей.

## Синтаксис

```bash
ssh-keygen [опции]
```

## Опции

| Опция | Описание |
|-------|----------|
| `-t тип` | Тип ключа (ed25519, rsa, ecdsa) |
| `-b биты` | Длина ключа в битах |
| `-C комментарий` | Комментарий к ключу |
| `-f файл` | Имя выходного файла |
| `-N пароль` | Парольная фраза (пустая = без пароля) |
| `-q` | Тихий режим |
| `-l` | Показать отпечаток ключа |
| `-f файл -l` | Отпечаток конкретного ключа |
| `-R хост` | Удалить ключ хоста из known_hosts |
| `-p` | Изменить парольную фразу |
| `-e` | Экспорт ключа в формат RFC4716 |
| `-i` | Импорт ключа из формата RFC4716 |
| `-y` | Вычислить публичный ключ из приватного |
| `-F хост` | Найти хост в known_hosts |
| `-H` | Хешировать known_hosts |

## Сравнение типов ключей

| Тип | Длина | Безопасность | Скорость | Рекомендация |
|-----|-------|-------------|----------|--------------|
| ed25519 | 256 бит | Высокая | Быстрый | **Рекомендуется** |
| rsa | 4096 бит | Хорошая | Средний | Совместимость |
| ecdsa | 256/384/521 бит | Высокая | Быстрый | Альтернатива |

## Примеры

### Генерация ключа Ed25519 (рекомендуется)

```bash
ssh-keygen -t ed25519 -C "user@hostname"
```

### Генерация RSA-ключа (4096 бит)

```bash
ssh-keygen -t rsa -b 4096 -C "user@hostname"
```

### Генерация ECDSA-ключа

```bash
ssh-keygen -t ecdsa -b 521 -C "user@hostname"
```

### Указание имени файла

```bash
ssh-keygen -t ed25519 -f ~/.ssh/my_key -C "my server key"
```

### Генерация без парольной фразы (для автоматизации)

```bash
ssh-keygen -t ed25519 -f ~/.ssh/automation_key -N "" -C "ansible"
```

### Показ отпечатков ключей

```bash
ssh-keygen -l -f ~/.ssh/id_ed25519
```

### Показ отпечатков в формате SHA256

```bash
ssh-keygen -l -E sha256 -f ~/.ssh/id_ed25519
```

### Показ отпечатков всех ключей

```bash
ssh-keygen -l -f ~/.ssh/id_ed25519.pub
ssh-keygen -l -f ~/.ssh/id_rsa.pub
```

### Изменение парольной фразы

```bash
ssh-keygen -p -f ~/.ssh/id_ed25519
```

### Удаление ключа хоста из known_hosts

```bash
ssh-keygen -R 192.168.1.100
```

### Удаление по имени хоста

```bash
ssh-keygen -R server.example.com
```

### Экспорт публичного ключа

```bash
ssh-keygen -e -f ~/.ssh/id_ed25519.pub
```

### Восстановление публичного ключа из приватного

```bash
ssh-keygen -y -f ~/.ssh/id_ed25519
```

### Генерация ключа для конкретного алгоритма RSA

```bash
ssh-keygen -t rsa -b 4096 -m PEM -f ~/.ssh/legacy_key
```

### Хеширование known_hosts

```bash
ssh-keygen -H -f ~/.ssh/known_hosts
```

## Практические сценарии

### Настройка SSH-доступа к серверу

```bash
# 1. Генерация ключа
ssh-keygen -t ed25519 -C "admin@myserver"

# 2. Копирование на сервер
ssh-copy-id -i ~/.ssh/id_ed25519.pub user@server

# 3. Проверка подключения
ssh user@server
```

### Создание ключа для Ansible

```bash
ssh-keygen -t ed25519 -f ~/.ssh/ansible_key -N "" -C "ansible@control"
```

### Создание ключа для Git (GitHub/GitLab)

```bash
ssh-keygen -t ed25519 -C "user@example.com"
cat ~/.ssh/id_ed25519.pub
```

### Ротация ключей

```bash
# Генерация нового ключа
ssh-keygen -t ed25519 -f ~/.ssh/id_ed25519_new -C "new key"

# Копирование на серверы
for host in server1 server2 server3; do
    ssh-copy-id -i ~/.ssh/id_ed25519_new.pub user@$host
done

# Замена старого ключа
mv ~/.ssh/id_ed25519 ~/.ssh/id_ed25519.old
mv ~/.ssh/id_ed25519_new ~/.ssh/id_ed25519
```

### Проверка ключа после генерации

```bash
ssh-keygen -l -f ~/.ssh/id_ed25519
# Должно вывести что-то вроде:
# 256 SHA256:... user@hostname (ED25519)
```

## Структура ключей

```
~/.ssh/
├── id_ed25519          # Приватный ключ (никогда не передавать!)
├── id_ed25519.pub      # Публичный ключ (можно передавать)
├── id_rsa              # Приватный ключ RSA
├── id_rsa.pub          # Публичный ключ RSA
├── known_hosts         # Известные хосты
└── authorized_keys     # Авторизованные ключи на сервере
```

:::warning Внимание
Никогда не передавайте приватный ключ (`id_ed25519`, `id_rsa`) третьим лицам. Публичный ключ (`.pub`) можно свободно распространять.
:::

:::tip Совет
Используйте Ed25519 для новых ключей — он быстрее RSA и обеспечивает лучшую безопасность при меньшем размере ключа.
:::

:::tip Совет
Для автоматизации (CI/CD, Ansible, скрипты) создавайте ключи без парольной фразы: `ssh-keygen -t ed25519 -f key -N ""`.
:::

:::warning Внимание
Если вы потеряли приватный ключ, немедленно удалите соответствующий публичный ключ из `authorized_keys` на всех серверах.
:::
