# SSH

Secure Shell — протокол безопасного удалённого доступа к серверам. Управление ключами, копирование файлов, настройка соединений.

## Команды

| Команда | Описание |
|---------|----------|
| [ssh](ssh.md) | Подключение к удалённому серверу |
| [ssh-keygen](ssh-keygen.md) | Генерация пары ключей |
| [ssh-copy-id](ssh-copy-id.md) | Копирование публичного ключа на сервер |
| [ssh-agent](ssh-agent.md) | Агент для управления ключами |
| [scp](scp.md) | Копирование файлов по SSH |
| [rsync](rsync.md) | Синхронизация файлов по SSH |

## Конфигурация

### Файлы

| Файл | Описание |
|------|----------|
| `~/.ssh/config` | Конфигурация клиента |
| `~/.ssh/id_rsa` | Приватный ключ |
| `~/.ssh/id_rsa.pub` | Публичный ключ |
| `~/.ssh/known_hosts` | Известные хосты |
| `~/.ssh/authorized_keys` | Разрешённые ключи (на сервере) |
| `/etc/ssh/sshd_config` | Конфигурация сервера |

### Пример `~/.ssh/config`

```
Host myserver
    HostName 192.168.1.100
    User admin
    Port 2222
    IdentityFile ~/.ssh/id_rsa_work
```

```bash
# Подключение через алиас
ssh myserver
```
