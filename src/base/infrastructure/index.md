# Инфраструктура

Администрирование серверов, контейнеризация, автоматизация развёртывания и настройка веб-серверов.

## Разделы

### [Linux](/base/infrastructure/linux/)

Команды, управление пользователями и правами, работа с файлами и процессами.

### [Docker](/base/infrastructure/docker/)

Контейнеризация приложений. Docker Compose для оркестрации сервисов.

### [Ansible](/base/infrastructure/ansible/)

Автоматизация настройки и развёртывания серверов.

### [Серверы](/base/infrastructure/server/)

Веб-серверы: Nginx и Apache. Конфигурация, версии, оптимизация.
