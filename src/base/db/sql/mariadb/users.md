# Управление пользователями в `mariaDb`

::: info
Проверено на версии `11.8`
:::

## Название аккаунта

Каждый пользователь определяется уникальной комбинацией имени пользователя и имени хоста, например `'user'@'localhost'`, где

- `user` - пользователь
- `localhost` - хост с которого пользователь может подключаться к `mariaDb`

### Некоторые особенности

- Если имя хоста не указано, то предполагается, что оно равно `%`, то есть со всех хостов.
- Имена хостов могут использовать подстановочные знаки `%` и `_`как в инструкции `LIKE`.
- Имена хостов могут совпадать как с `ip` адресами так и с доменными именами.
- Для локальных подключений с самой машины используется хост `localhost`.
- Можно использовать `ip` адрес совместно с маской для указания диапазона адресов, например `'247.150.130.0/255.255.255.0'`
- Использование `255.255.255.255` эквивалентно от использования маски вообще.
- Учетные записи для `%` не во всех случаях дают подключение со всех хостов, иногда `localhost` будет иметь приоритет
- Начиная с версии `10.6` длина имени может достигать 255 символов.

Если найдено несколько учетных записей, критерии выбора будут такими:

- Точное имя хоста будет в приоритете с именами, где есть подстановочный знак `%`.
- Имена хостов с сетевой маской будут в приоритете.
- Не пустые имена пользователей имеют приоритет над пустыми.

## Информация о пользователе

Заходим в базу данных

````shell
mariadb -u root -p
````

Проверим какие учетные записи у нас есть

````sql
SELECT User, Host FROM mysql.user;
-- | root | localhost |
````

Сменим ему пароль

````sql
ALTER USER 'root'@'localhost' IDENTIFIED BY 'NewVeryStr0ngP@ss';
````

## Создать пользователя

Создадим пользователя с максимальным набором привилегий, но заходить разрешим только с определенного `ip`

````sql
CREATE USER 'root'@'192.168.88.252' IDENTIFIED BY 'superpass'; 
GRANT ALL PRIVILEGES ON *.* TO 'root'@'192.168.88.252';
FLUSH PRIVILEGES;
````

::: info
Важное допущение для удаленного подключения к базе данных нужно в файле `/etc/mysql/mariadb.conf.d/50-server.cnf` настроить директиву `bind-address = 0.0.0.0`.

Могут быть только два варианта `127.0.0.1` и `0.0.0.0`.

Плюс к этому нужно разрешить в фаерволе если используется порт `3306` `sudo ufw allow 3306`.
:::

Создадим еще пользователя, но не будем указывать ему привилегии, он будет просто обычный пользователь, которому ничего не доступно

````sql
CREATE USER 'test'@'192.168.88.252' IDENTIFIED BY 'the_secure_password';
````

## Информация о созданном пользователе


````sql
SHOW CREATE USER 'test'@'192.168.88.252';
-- # CREATE USER `test`@`192.168.88.252` IDENTIFIED BY PASSWORD '*645E9013421D5D65B18728AC535BF6A4015F4DA7'            
````

## Переименовать пользователя

Команда `RENAME USER` переименовывает уже существующего пользователя базы данных.

````sql
RENAME USER 'test'@'192.168.88.252' TO 'test2'@'192.168.88.252';
````

## Сменить пароль пользователя

````sql
ALTER USER 'test2'@'192.168.88.252' IDENTIFIED BY 'the_secure_password2';
````

Так же есть еще один способ изменить пароль 

````sql
SET PASSWORD FOR 'test2'@'192.168.88.252' = PASSWORD('the_secure_password3');
````

## Текущий пользователь и подключение

````sql
SELECT CURRENT_USER();
-- #root@192.168.88.252
SELECT USER(), CURRENT_USER(), DATABASE();
-- #root@192.168.88.252	root@192.168.88.252	
````

## Удалить пользователя

Инструкция `DROP USER` удаляет учетную запись и привилегии пользователя.

````sql
DROP USER 'test2'@'192.168.88.252';
````

## Summary

Краткий обзор

````sql
-- Просмотр всех пользователей
SELECT User, Host FROM mysql.user;
-- Создать пользователя
CREATE USER 'test2'@'192.168.88.252' IDENTIFIED BY 'superpass2';
GRANT ALL PRIVILEGES ON *.* TO 'root'@'192.168.88.252';
FLUSH PRIVILEGES;
-- Переименовать пользователя
RENAME USER 'test'@'192.168.88.252' TO 'test2'@'192.168.88.252';
-- Сменить пароль
ALTER USER 'test2'@'192.168.88.252' IDENTIFIED BY 'test3';
-- Удалить пользователя
DROP USER 'test2'@'192.168.88.252';      
````

## Безопасность

- Никогда не используйте `root` для приложений. Всегда создавайте отдельных пользователей. 
- Принцип наименьших привилегий: Давайте пользователю только те права, которые ему абсолютно необходимы для работы. 
- Ограничивайте хост. По умолчанию используйте `localhost`. Если удаленный доступ необходим, указывайте конкретный `ip`, а не `%`. 
- Используйте сложные пароли. 
- Регулярно проверяйте список пользователей: `SELECT user, host FROM mysql.user;` и удаляйте ненужные учетные записи.
