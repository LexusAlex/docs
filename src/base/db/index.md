# Базы данных

Хранение, управление и обработка структурированных данных. Реляционные СУБД, SQL-запросы, администрирование.

## Разделы

### [SQL](/base/db/sql/)

Язык структурированных запросов и реляционные базы данных:

- **[MySQL](/base/db/sql/mysql/)** — популярная开源 СУБД
- **[MariaDB](/base/db/sql/mariadb/)** — форк MySQL с расширенными возможностями
- **[Percona](/base/db/sql/percona/)** — оптимизированный MySQL для высоких нагрузок
- **[PostgreSQL](/base/db/sql/postgresql/)** — объектно-реляционная СУБД
