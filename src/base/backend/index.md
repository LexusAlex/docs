# Backend (Сервер)

Серверная сторона веб-приложений. Обрабатывает бизнес-логику, работает с базами данных, предоставляет API для клиента.

## Разделы

### [PHP](/base/backend/php/)

Основной язык серверной разработки. Фреймворки и инструменты экосистемы.

#### [Yii3](/base/backend/php/frameworks/yii3/)

Современный PHP-фреймворк с Dependency Injection, архитектурой на пакетах и строгой типизацией.
