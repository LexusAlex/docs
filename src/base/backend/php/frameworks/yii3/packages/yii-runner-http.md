# yii-runner-http

Пакет помогает запустить и настроить приложение.

Ключи конструктора:

- `$rootPath` — абсолютный путь к корню проекта.
- `$debug` — включен ли режим отладки.
- `$checkEvents` — проверяется ли конфигурация событий.
- `$environment` — имя среды.
- `$bootstrapGroup` — название группы настройки начальной загрузки.
- `$eventsGroup` — название группы настройки событий.
- `$diGroup` — название группы настройки определений контейнеров.
- `$diProvidersGroup` — название группы настройки поставщиков контейнеров.
- `$diDelegatesGroup` — название группы настройки делегатов контейнеров.
- `$diTagsGroup` — название группы конфигураций тегов контейнера.
- `$paramsGroup` — название группы конфигурационных параметров.
- `$nestedParamsGroups` — названия групп конфигураций, которые входят в группу конфигурационных параметров. Это необходимо для параметров рекурсивного слияния.
- `$nestedEventsGroups` — имена групп конфигурации, которые входят в группу конфигурации событий. Это необходимо для конфигураций событий обратного и рекурсивного слияния.
- `$configModifiers` — модификаторы конфигурации.
- `$configDirectory` — относительный путь от `$rootPath` до хранилища конфигурации.
- `$vendorDirectory` — относительный путь от `$rootPath` до каталога поставщика.
- `$configMergePlanFile` — относительный путь от `$configDirectory` к плану объединения.
- `$logger` — средство регистрации ошибок во время сборки контейнера.
- `$bufferSize` — размер буфера в байтах для отправки содержимого текста сообщения (по умолчанию 8 Мб).
- `$temporaryErrorHandler` — временный обработчик ошибок, необходимый для обработки создания экземпляров конфигурации и контейнера.
- `$emitter` — отправитель для отправки ответа.
- `$useRemoveBodyByStatusMiddleware` — нужно ли удалять текст ответа для определенных кодов состояния ответа.
- `$useContentLengthMiddleware` — нужно ли управлять заголовком Content-Length для ответа.
- `$useHeadRequestMiddleware` — нужно ли удалять текст ответа для запросов HEAD.
