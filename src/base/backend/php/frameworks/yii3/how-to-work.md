# Как это работает

Доп возможности:

- Несколько входных скриптов - обычно, скрипты доступны конечному пользователю и обрабатывают все приложние целиком
- Сервисы - объекты без состояния зарегистрированные в контейнере
- `middleware` - это код, которые вызывается до или после обработки запроса

## Что делает Application Runner

- Автозагрузки `composer`
- Получаем конфигурацию
- Используем конфигурацию для инициализации контейнера `DI`
- Получаем запрос
- Передаем приложению запрос и получаем от него ответ
- Объект `Response` трансформируется в фактический ответ `http` и отправляется в браузер пользователю
- Можно создать web или консольное приложение

## Приложение

- Запуск приложения. Получаем контейнер внедрения зависимостей. Запуск события `ApplicationStartup`
- Обработка запросов, передавая запросы в `middleware dispatcher` для выполнения `middleware stack`, это может быть выполнено один или несколько раз. `Response` преобразуется в `http` ответ м помощью `emitter`, событие `AfterEmit`.
- Остановка приложение. событие `ApplicationShutdown`.

## Middleware

`middleware` выполняется между запросом и ответом.

Каждое `middleware` может передать запрос следующему `middleware`

Полезные определения [https://yiisoft.github.io/docs/ru/guide/structure/domain.html](https://yiisoft.github.io/docs/ru/guide/structure/domain.html)

В конструктор `HttpApplicationRunner` передаются параметры которые, настраивают приложение.

- Запуск метода `runInternal`
  - Временная метка начало работы приложения
  - Регистрация временного обработчика ошибок, чтобы перехватывать ошибки во время сборки контейнера
  - Создание контейнера
  - Создание конфига сначала объекта на основании `merge-plan` файла
  - Регистрация основного обработчика ошибок
  - Обработка секций `boostap` и `events`
  - Достаем из контейнера `Application` специфичное для `http`
  - Начинается работа с `http` Достаем фабрику `RequestFactory`. Создаем запрос. Создаем временную метку старта приложения.
  - Стартуем приложение
  - Определяем ответ
  - Запуск `emit` с запросом ответом
  - Завершение приложения
