# VCS

Системы контроля версий (Version Control Systems) — инструменты для отслеживания изменений в коде и совместной работы.

## Разделы

### [Git](/base/tools/vcs/git/)

Распределённая система контроля версий. Стандарт де-факто в современной разработке. Создана Линусом Торвальдсом в 2005 году.

**Основные преимущества:**

- Распределённая архитектура — каждый разработчик имеет полную копию истории
- Быстрое ветвление и слияние
- Криптографическая целостность данных
- Поддержка нелинейной разработки

### GitLab

[GitLab](/base/tools/platform/gitlab/) — платформа для совместной разработки с интегрированным Git-хостингом, CI/CD и инструментами code review.
