# git add

**Уровень:** Начинающий
**Версия Git:** 0.99

Добавляет изменения из рабочей директории в индекс (staging area). Подготавливает файлы для следующего коммита.

## Синтаксис

```bash
git add <путь>
git add [опции] <путь...>
```

## Основные опции

| Опция | Описание |
|-------|----------|
| `.` | Все изменения в текущей директории |
| `-A` / `--all` | Все изменения во всём репозитории |
| `-u` / `--update` | Только отслеживаемые файлы (без новых) |
| `-p` / `--patch` | Интерактивный выбор частей файлов |
| `-n` / `--dry-run` | Показать, что будет добавлено (без изменений) |
| `-i` / `--interactive` | Интерактивный режим |
| `-e` / `--edit` | Редактировать diff перед добавлением |
| `--intent-to-add` | Зарегистрировать файл как отслеживаемый (без содержимого) |
| `--refresh` | Обновить индекс (без добавления файлов) |
| `--ignore-errors` | Продолжить при ошибках |
| `--ignore-missing` | Игнорировать отсутствующие файлы |
| `--renormalize` | Повторно применить фильтры ко всем файлам |

## Примеры

### 1. Добавление одного файла

```bash
git add README.md
# Добавляет README.md в индекс
```

### 2. Добавление нескольких файлов

```bash
git add file1.txt file2.txt file3.txt
```

### 3. Добавление всех изменений в текущей директории

```bash
git add .
# Добавляет все новые и изменённые файлы
```

### 4. Добавление всех изменений в репозитории

```bash
git add -A
# Добавляет всё: новые, изменённые, удалённые
```

### 5. Добавление только отслеживаемых файлов

```bash
git add -u
# Добавляет изменения в уже отслеживаемых файлах
# Новые файлы не добавляются
```

### 6. Интерактивный выбор частей (patch)

```bash
git add -p
# Показывает каждый блок изменений
# y — добавить, n — пропустить, s — разбить
```

### 7. Интерактивный выбор файлов

```bash
git add -i
# Меню: status, update, revert, add, patch, diff, quit
```

### 8. Добавление по маске (glob)

```bash
git add "*.js"
# Все .js файлы (включая поддиректории)
```

### 9. Добавление директории

```bash
git add src/
# Все файлы в src/ рекурсивно
```

### 10. Добавление с исключениями

```bash
git add --all -- ':!node_modules' ':!*.log'
# Всё, кроме node_modules и .log файлов
```

### 11. Dry-run (предпросмотр)

```bash
git add -n .
# Показывает, что БЫЛО бы добавлено
```

### 12. Добавление удалённых файлов

```bash
git add -u
# Индексирует удаление файлов
```

### 13. Intent-to-add (регистрация без содержимого)

```bash
git add --intent-to-add new-file.txt
# Файл появляется в status как "new file"
# Но содержимое не проиндексировано
```

### 14. Редактирование перед добавлением

```bash
git add -e file.js
# Открывает diff в редакторе
# Можно выбрать, какие части добавить
```

### 15. Добавление конкретной строки

```bash
git add -p file.js
# Выбирает блоки: y/n/s/e/q
# s — разбить блок на меньшие
```

## Зоны Git

```
Рабочая директория  →  Индекс (staging)  →  Репозиторий
    (working dir)        (index/stage)         (HEAD)
         │                    │                   │
         └── git add ────────┘                   │
                         └── git commit ─────────┘
```

## Практические сценарии

### Частичный коммит (часть файла)

```bash
git add -p file.js
# Выбрать только нужные блоки
git commit -m "Fix: only the important part"
```

### Добавление всех изменений кроме одного файла

```bash
git add --all -- ':!config/local.js'
```

### Добавление файлов с пробелами в именах

```bash
git add "file with spaces.txt"
```

### Подготовка удалений

```bash
# Удалить файл
rm old-file.txt

# Индексировать удаление
git add old-file.txt
# или
git add -u
```

## Связки с другими командами

```bash
# Добавить всё и закоммитить
git add . && git commit -m "Update"

# Добавить и посмотреть что будет закоммичено
git add -u && git status

# Добавить и показать staged diff
git add -p && git diff --cached

# Добавить и поправить последний коммит
git add . && git commit --amend
```

## Советы

:::tip
Используйте `git add -p` для точного контроля — можно закоммитить только часть изменений.
:::

:::warning
`git add .` добавляет ВСЁ, включая файлы, которые вы забыли добавить в `.gitignore`. Проверяйте `git status` перед коммитом.
:::

:::tip
Для удалённых файлов используйте `git add -u` — это индексирует удаления без необходимости указывать каждый файл.
:::
