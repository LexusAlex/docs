# git status

**Уровень:** Начинающий
**Версия Git:** 0.99

Показывает состояние рабочей директории и индекса. Отображает изменённые, новые и удалённые файлы.

## Синтаксис

```bash
git status
git status [опции]
```

## Основные опции

| Опция | Описание |
|-------|----------|
| `-s` / `--short` | Короткий формат |
| `-b` / `--branch` | Показать информацию о ветке |
| `--porcelain` | Стабильный формат для скриптов |
| `--ignored` | Показать игнорируемые файлы |
| `-u[<режим>]` / `--untracked-files[=<режим>]` | Показать неотслеживаемые файлы (`no`, `normal`, `all`) |
| `--no-renames` | Не показывать переименования |
| `-z` | Разделитель NUL (для скриптов) |
| `--column[=<опции>]` | Вывод в колонках |
| `--verbose` | Подробный вывод |
| `--ignore-submodules[=<режим>]` | Игнорировать подмодули (`none`, `untracked`, `dirty`, `all`) |
| `--show-stash` | Показать stash |

## Примеры

### 1. Полный статус

```bash
git status
# Подробная информация о всех изменениях
```

### 2. Короткий формат

```bash
git status -s
# M  file1.js     # Изменён в индексе
#  M file2.js     # Изменён в рабочей директории
# ?? new-file.js  # Неотслеживаемый
#  D deleted.js   # Удалён
```

### 3. Короткий формат с веткой

```bash
git status -sb
# ## main...origin/main [ahead 2]
# M  file1.js
```

### 4. Формат для скриптов (porcelain)

```bash
git status --porcelain
# Стабильный формат, не меняется между версиями
```

### 5. Показать игнорируемые файлы

```bash
git status --ignored
# Показывает файлы из .gitignore
```

### 6. Без неотслеживаемых файлов

```bash
git status -uno
# Только отслеживаемые файлы
```

### 7. Только изменённые файлы

```bash
git status -u no
# Не показывает новые файлы
```

### 8. С разделителем NUL (для скриптов)

```bash
git status -z
# Имена разделены NUL (обработка пробелов)
```

### 9. Показать stash

```bash
git status --show-stash
# Показывает количество stash-записей
```

### 10. Игнорирование подмодулей

```bash
git status --ignore-submodules=dirty
# Не показывать грязные подмодули
```

### 11. Проверка конкретного файла

```bash
git status -- file.js
# Статус только указанного файла
```

## Символы в коротком формате

| Символ | Позиция | Значение |
|--------|---------|----------|
| `M` | Первая | Изменён в индексе (staged) |
| `M` | Вторая | Изменён в рабочей директории |
| `A` | Первая | Добавлен в индекс |
| `D` | — | Удалён |
| `R` | — | Переименован |
| `C` | — | Скопирован |
| `U` | — | Не слит (unmerged) |
| `?` | — | Неотслеживаемый |
| `!` | — | Игнорируемый |

### Примеры символов

```
M  file.js      # Изменён и staged
 M file.js      # Изменён, но не staged
MM file.js      # Изменён в обеих зонах
A  file.js      # Новый файл, staged
AM file.js      # Новый файл, staged + изменения
?? file.js      # Неотслеживаемый
```

## Практические сценарии

### Быстрая проверка перед коммитом

```bash
git status -sb
# Что изменилось и на каком коммите мы
```

### Проверка перед push

```bash
git status
# "Your branch is ahead of 'origin/main' by 2 commits"
```

### Поиск неотслеживаемых файлов

```bash
git status -u
# Все новые файлы, которые не в .gitignore
```

### Проверка после merge (конфликты)

```bash
git status
# Показывает "Unmerged paths"
```

## Связки с другими командами

```bash
# Показать что будет закоммичено
git status && git diff --cached

# Короткий статус + количество изменений
git status -s | wc -l

# Проверить перед push
git status -sb && git log --oneline -5

# Проверить stash
git status --show-stash && git stash list
```

## Советы

:::tip
Используйте `git status -sb` для быстрой проверки — показывает ветку и изменения в компактном формате.
:::

:::info Подмодули
`git status` показывает изменённое состояние submodule, если оно не скрыто настройкой или `--ignore-submodules`. `git submodule status --recursive` дополнительно показывает записанные commit ID и состояние вложенных submodule.
:::

:::tip
В скриптах используйте `git status --porcelain` — формат стабилен между версиями Git.
:::
