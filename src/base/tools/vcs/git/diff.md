# git-diff

**Уровень:** Средний
**Версия Git:** 0.99

Показывает различия между коммитами, ветками, рабочей директорией и индексом. Основной инструмент для анализа изменений.

## Синтаксис

```bash
git diff [<options>] [<commit>] [--] [<path>...]
git diff [<options>] --cached [<commit>] [--] [<path>...]
git diff [<options>] <commit> <commit> [--] [<path>...]
```

## Основные опции

| Опция | Описание |
|-------|----------|
| `--staged` | Сравнивает индекс с HEAD (что будет закоммичено) |
| `--cached` | Синоним `--staged` |
| `--stat` | Показывает только статистику изменений |
| `--name-only` | Показывает только имена изменённых файлов |
| `--name-status` | Показывает имена файлов и тип изменения (A/M/D) |
| `--word-diff` | Показывает различия на уровне слов |
| `--color-words` | Цветовые различия на уровне слов |
| `--no-index` | Сравнивает два файла вне репозитория |
| `--ignore-space-change` | Игнорирует изменения пробелов |
| `--ignore-all-space` | Игнорирует все пробелы |
| `--unified=<n>` | Количество контекстных строк |
| `--shortstat` | Краткая статистика (файлы, вставки, удаления) |

## Примеры

1. Изменения в рабочей директории (не проиндексированные):
```bash
git diff
```

2. Что будет закоммичено (индекс vs HEAD):
```bash
git diff --staged
```

3. Разница между двумя коммитами:
```bash
git diff abc1234 def5678
```

4. Разница между ветками:
```bash
git diff main..feature
```

5. Изменения конкретного файла:
```bash
git diff -- src/app.js
```

6. Только статистика изменений:
```bash
git diff --stat
```

7. Только имена изменённых файлов:
```bash
git diff --name-only
```

8. Имена файлов с типом изменения:
```bash
git diff --name-status
```

9. Различия на уровне слов:
```bash
git diff --word-diff
```

10. Цветовые различия на уровне слов:
```bash
git diff --color-words
```

11. Сравнение двух файлов вне репозитория:
```bash
git diff --no-index file1.txt file2.txt
```

12. Игнорирование изменений пробелов:
```bash
git diff --ignore-space-change
```

13. Игнорирование всех пробелов:
```bash
git diff --ignore-all-space
```

14. Краткая статистика:
```bash
git diff --shortstat
```

15. Разница с определённым количеством контекстных строк:
```bash
git diff --unified=5
```

16. Изменения в индексе для конкретного файла:
```bash
git diff --staged -- README.md
```

17. Сравнение текущей ветки с main:
```bash
git diff main
```

18. Что изменилось между тегами:
```bash
git diff v1.0.0..v2.0.0
```

19. Разница с удалённой веткой:
```bash
git diff origin/main..main
```

20. Изменения за определённый коммит:
```bash
git diff abc1234^..abc1234
```

## Практические сценарии

**Проверка перед коммитом:**
```bash
# Посмотреть, что будет закоммичено
git diff --staged --stat
# Детальный просмотр изменений
git diff --staged
```

**Сравнение ветки перед слиянием:**
```bash
# Что изменится после merge
git diff main..feature-branch --stat
```

**Ревью изменений в CI/CD:**
```bash
# Получить список изменённых файлов между коммитами
git diff --name-only HEAD~1..HEAD
```

## Связки с другими командами

```bash
# Пайп в less для удобного просмотра
git diff --stat | less

# Копирование списка изменённых файлов
git diff --name-only HEAD~1 | pbcopy

# Подсчёт изменённых строк
git diff --shortstat HEAD~5

# Проверка стиля кода только на изменённых файлах
git diff --name-only --cached | xargs eslint
```

## Советы

:::tip
Используйте `git diff --staged` перед каждым коммитом, чтобы убедиться в правильности индексированных изменений.
:::

:::warning
`git diff` без аргументов показывает только не проиндексированные изменения. Используйте `--staged` для просмотра индексированных.
:::
