# git clean

**Уровень:** Средний
**Минимальная версия Git:** 1.5

`git clean` удаляет неотслеживаемые файлы из рабочего дерева. Команда не удаляет изменения отслеживаемых файлов — для них используется `git restore` или, в более широком сценарии, `git reset --hard`.

## Синтаксис

```bash
git clean [<options>] [--] [<pathspec>...]
```

При стандартной настройке `clean.requireForce=true` требуется `-f`, `-n` или `-i`.

## Основные опции

| Опция | Описание |
|---|---|
| `-n`, `--dry-run` | Только показать кандидатов на удаление |
| `-i`, `--interactive` | Интерактивно выбрать, что удалить |
| `-f`, `--force` | Выполнить удаление |
| `-d` | Включить неотслеживаемые каталоги |
| `-x` | Включить также игнорируемые файлы |
| `-X` | Удалить только игнорируемые файлы |
| `-e <pattern>` | Дополнительно исключить шаблон |
| `-q`, `--quiet` | Не перечислять успешно удалённые файлы |

## Безопасный шаблон

Всегда запускайте preview с теми же флагами, что и реальное удаление:

```bash
git clean -nd
git clean -fd
```

Если между командами состояние изменилось, повторите preview.

### Удалить только игнорируемые артефакты сборки

```bash
git clean -ndX
git clean -fdX
```

`-X` удобен для очистки файлов, уже описанных в `.gitignore`.

### Удалить все неотслеживаемые и игнорируемые файлы

```bash
git clean -ndx
git clean -fdx
```

::: danger Флаг `-x`
Команда может удалить `.env`, локальные ключи, базы данных, IDE-настройки и другие ценные файлы, если они игнорируются. Используйте её только в воспроизводимом рабочем дереве после проверки списка.
:::

### Очистить конкретный каталог

```bash
git clean -nd -- build/
git clean -fd -- build/
```

### Сохранить исключение

```bash
git clean -ndX -e '!important-cache/'
git clean -fdX -e '!important-cache/'
```

Проверьте поведение шаблона в preview: правила исключений используют синтаксис `.gitignore`.

### Интерактивная очистка

```bash
git clean -id
```

Интерактивный режим позволяет фильтровать кандидатов и подтверждать выбранные пути.

## Полностью привести disposable checkout к HEAD

Только если все локальные данные можно удалить:

```bash
git status --short
git clean -ndx
git reset --hard HEAD
git clean -fdx
```

`reset --hard` удаляет изменения отслеживаемых файлов, а `clean -fdx` — неотслеживаемые и игнорируемые. Для обычной разработки лучше восстанавливать только нужные пути.

## Вложенные репозитории

Git не удаляет неотслеживаемый каталог, внутри которого находится другой Git-репозиторий, при одном `-f`. Второй `-f` разрешает это явно:

```bash
git clean -ndff path/to/nested-repo/
git clean -dff path/to/nested-repo/
```

Используйте `-ff` только после проверки, что вложенный репозиторий действительно не нужен.
