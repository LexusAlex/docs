# git-clean

**Уровень:** Средний
**Версия Git:** 1.5.0

Удаляет неотслеживаемые файлы из рабочего дерева. Используется для очистки рабочей директории от временных файлов, артефактов сборки и других неотслеживаемых объектов.

## Синтаксис

```bash
git clean [опции]
```

## Основные опции

| Опция | Описание |
|---|---|
| `-f` | Принудительное удаление (обязательно) |
| `-fd` | Удалить неотслеживаемые файлы и каталоги |
| `-fdx` | Удалить неотслеживаемые и игнорируемые файлы |
| `-n` | Сухой запуск (показать без выполнения) |
| `--dry-run` | Сухой запуск (синоним -n) |
| `-d` | Удалить неотслеживаемые каталоги |
| `-x` | Не учитывать правила .gitignore |
| `-X` | Удалить только игнорируемые файлы |
| `-i` | Интерактивный режим |
| `-e <шаблон>` | Исключить файлы по шаблону |
| `--quiet` | Тихий режим |

## Примеры

1. Сухой запуск (показать что будет удалено):
```bash
git clean -n
```

2. Удаление неотслеживаемых файлов:
```bash
git clean -f
```

3. Удаление неотслеживаемых файлов и каталогов:
```bash
git clean -fd
```

4. Удаление неотслеживаемых и игнорируемых файлов:
```bash
git clean -fdx
```

5. Удаление только игнорируемых файлов:
```bash
git clean -fX
```

6. Интерактивный режим очистки:
```bash
git clean -i
```

7. Удаление с исключением шаблона:
```bash
git clean -fd -e "*.log"
```

8. Сухой запуск для всех неотслеживаемых файлов:
```bash
git clean -n -d
```

9. Удаление неотслеживаемых файлов в тихом режиме:
```bash
git clean -fq
```

10. Удаление с исключением нескольких шаблонов:
```bash
git clean -fd -e "*.log" -e "*.tmp"
```

11. Показать что будет удалено (включая каталоги):
```bash
git clean -n -d
```

12. Удаление файлов в конкретном каталоге:
```bash
git clean -f src/
```

13. Удаление игнорируемых файлов в тихом режиме:
```bash
git clean -fXq
```

14. Удаление всех неотслеживаемых файлов (осторожно!):
```bash
git clean -fdx
```

15. Удаление с подтверждением каждого файла:
```bash
git clean -i -d
```

## Практические сценарии

**Очистка после сборки:**
Удаление артефактов сборки, временных файлов и кэша после завершения работы.

```bash
git clean -fd -e "node_modules/"
npm run build
# ... работа ...
git clean -fd
```

**Подготовка к деплою:**
Полная очистка рабочей директории перед развёртыванием для обеспечения чистоты сборки.

```bash
git clean -fdx
git checkout -- .
npm ci
npm run build
```

**Восстановление чистого состояния:**
Возврат репозитория в состояние, идентичное клонированному.

```bash
git clean -fdx
git checkout -- .
git reset HEAD
```

## Связки с другими командами

```bash
# Полная очистка репозитория
git clean -fdx && git checkout -- . && git reset HEAD

# Очистка перед переключением ветки
git clean -fd && git checkout other-branch

# Очистка с проверкой
git clean -n && git clean -f

# Очистка и обновление зависимостей
git clean -fd && npm ci
```

## Советы

:::tip
Всегда используйте `git clean -n` (сухой запуск) перед фактическим удалением, чтобы увидеть, какие файлы будут удалены.
:::

:::warning
Команда `git clean -fdx` удаляет файлы безвозвратно. Убедитесь, что вы не удалите важные несохранённые файлы.
:::
