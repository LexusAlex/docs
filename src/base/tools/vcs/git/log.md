# git-log

**Уровень:** Начинающий
**Версия Git:** 0.99

Показывает историю коммитов репозитория. Позволяет просматривать, фильтровать и форматировать журнал изменений.

## Синтаксис

```bash
git log [<options>] [<revision-range>] [[--] <path>...]
```

## Основные опции

| Опция | Описание |
|-------|----------|
| `--oneline` | Выводит каждый коммит в одну строку |
| `--graph` | Отображает граф ветвлений и слияний |
| `--all` | Включает все refs: локальные и remote-tracking ветки, теги и другие |
| `--author=<pattern>` | Фильтр по автору |
| `--since=<date>` | Коммиты после указанной даты |
| `--until=<date>` | Коммиты до указанной даты |
| `--grep=<pattern>` | Поиск по сообщению коммита |
| `--stat` | Показывает статистику изменений файлов |
| `--patch` | Показывает diff каждого коммита |
| `--format=<format>` | Пользовательский формат вывода |
| `--date=<format>` | Формат отображения даты |
| `--no-merges` | Исключает коммиты слияний |
| `--merges` | Показывает только коммиты слияний |
| `-n <number>` | Ограничивает количество коммитов |
| `--follow` | Следит за переименованиями файла |
| `-- <path>` | Фильтр по пути файла |
| `-S <string>` | Поиск коммитов, изменивших количество вхождений строки |
| `-G <pattern>` | Поиск коммитов, где diff совпадает с регулярным выражением |

## Примеры

1. Базовый просмотр истории:
```bash
git log
```

2. Краткий формат — один коммит на строку:
```bash
git log --oneline
```

3. Визуализация ветвлений:
```bash
git log --oneline --graph --all
```

4. Последние 10 коммитов:
```bash
git log -n 10
```

5. Фильтр по автору:
```bash
git log --author="Иван"
```

6. Коммиты за последнюю неделю:
```bash
git log --since="1 week ago"
```

7. Коммиты за конкретный период:
```bash
git log --since="2024-01-01" --until="2024-06-01"
```

8. Поиск по сообщению коммита:
```bash
git log --grep="fix"
```

9. Статистика изменений файлов:
```bash
git log --stat
```

10. Полный diff каждого коммита:
```bash
git log --patch
```

11. Пользовательский формат:
```bash
git log --format="%h - %an, %ar : %s"
```

12. Формат с датой:
```bash
git log --format="%h %ad %s" --date=short
```

13. Только коммиты слияний:
```bash
git log --merges
```

14. Без коммитов слияний:
```bash
git log --no-merges
```

15. История конкретного файла с отслеживанием переименований:
```bash
git log --follow -- src/main.py
```

16. Коммиты, изменившие строку:
```bash
git log -S "function_name"
```

17. Коммиты по регулярному выражению в diff:
```bash
git log -G "TODO.*fix"
```

18. Коммиты конкретного файла:
```bash
git log -- README.md
```

19. История ветки:
```bash
git log feature-branch --oneline
```

20. Сравнение двух веток:
```bash
git log --oneline main..feature
# Коммиты, достижимые из feature, но не из main
git log --left-right --oneline main...feature
# Уникальные коммиты обеих сторон
```

## Практические сценарии

**Поиск ответственного за баг:**
```bash
# Найти коммит, который сломал тесты
git log --oneline --all -- tests/test_auth.py
# Посмотреть изменения в конкретном коммите
git show abc1234
```

**Подготовка релизных заметок:**
```bash
# Все коммиты с последнего тега
git log $(git describe --tags --abbrev=0)..HEAD --oneline --no-merges
```

**Анализ активности разработчика:**
```bash
# Коммиты конкретного разработчика за месяц
git log --author="Alex" --since="1 month ago" --stat
```

## Связки с другими командами

```bash
# Просмотр изменений в файле + blame
git log --oneline -- src/app.js | head -5

# Поиск и показ коммита
git log --oneline --grep="refactor"
# После выбора хеша
git show <commit>

# Экспорт лога в файл
git log --oneline --all > commit_history.txt

# Подсчёт коммитов по авторам
git shortlog -sn --all
```

## Советы

:::tip
Используйте алиасы для часто используемых команд: `git config --global alias.lg "log --oneline --graph --all --decorate"`
:::

:::warning
При использовании `--follow` отслеживание переименований работает только с одним файлом.
:::
