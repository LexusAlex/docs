# git-gc

**Уровень:** Продвинутый
**Версия Git:** 1.5.0

Выполняет сборку мусора (garbage collection) и оптимизацию репозитория Git. Удаляет ненужные файлы, оптимизирует хранилище и выполняет профилактическое обслуживание.

## Синтаксис

```bash
git gc [опции]
```

## Основные опции

| Опция | Описание |
|---|---|
| `--aggressive` | Более агрессивная оптимизация (дольше, но эффективнее) |
| `--auto` | Запуск только при необходимости |
| `--no-prune` | Не удалять неиспользуемые объекты |
| `--prune=<дата>` | Удалить объекты старше указанной даты |
| `--force` | Принудительный запуск |
| `--quiet` | Тихий режим |
| `--depth=<n>` | Глубина для delta-компрессии |
| `--window=<n>` | Размер окна для delta-компрессии |
| `--max-pack-size=<n>` | Максимальный размер пакета |

## Примеры

1. Базовая сборка мусора:
```bash
git gc
```

2. Агрессивная оптимизация:
```bash
git gc --aggressive
```

3. Автоматическая сборка (при необходимости):
```bash
git gc --auto
```

4. Сборка без удаления неиспользуемых объектов:
```bash
git gc --no-prune
```

5. Сборка с удалением объектов старше 2 недель:
```bash
git gc --prune=2.weeks.ago
```

6. Принудительная сборка:
```bash
git gc --force
```

7. Сборка в тихом режиме:
```bash
git gc --quiet
```

8. Сборка с настройкой глубины:
```bash
git gc --depth=50
```

9. Сборка с размером окна:
```bash
git gc --window=250
```

10. Сборка с ограничением размера пакета:
```bash
git gc --max-pack-size=2g
```

11. Проверка перед сборкой:
```bash
git fsck
git gc
```

12. Агрессивная сборка с удалением старых объектов:
```bash
git gc --aggressive --prune=1.month.ago
```

13. Сборка с увеличенным окном:
```bash
git gc --aggressive --window=500
```

14. Автоматическая сборка с выводом:
```bash
git gc --auto --verbose
```

15. Полная оптимизация репозитория:
```bash
git gc --aggressive --depth=100 --window=500
```

## Практические сценарии

**Регулярное обслуживание репозитория:**
Запуск периодической оптимизации для поддержания производительности.

```bash
# Ежемесячная оптимизация
git gc --aggressive --prune=1.month.ago
```

**Очистка после массовых операций:**
Оптимизация репозитория после больших слияний, ребейзов или удаления веток.

```bash
git gc --auto
git remote prune origin
```

**Восстановление после проблем:**
Проверка целостности и оптимизация после сбоев или некорректных операций.

```bash
git fsck --full
git gc --force --prune=now
```

## Связки с другими командами

```bash
# Проверка целостности перед gc
git fsck && git gc

# Удаление старых веток и сборка мусора
git remote prune origin && git gc --auto

# Полная оптимизация
git reflog expire --expire=now --all && git gc --prune=now --aggressive

# Проверка размера репозитория
git count-objects -vH && git gc
```

## Советы

:::tip
Используйте `git gc --auto` — Git сам определит, когда нужна оптимизация, и выполнит её в фоновом режиме.
:::

:::warning
Агрессивная сборка (`--aggressive`) может занять значительное время в больших репозиториях. Выполняйте её в нерабочее время.
:::
