# Инструменты

Инструменты разработчика для контроля версий, совместной работы и отладки.

## Разделы

### [VCS](/base/tools/vcs/)

Системы контроля версий. Git — распределённое хранение истории изменений.

### [Платформы](/base/tools/platform/)

Платформы для совместной разработки: GitLab, GitHub. CI/CD, code review.

### [Браузеры](/base/tools/browsers/)

Теория и архитектура браузеров: как работает рендеринг, парсинг, сетевые операции. Расширения и инструменты разработчика.
