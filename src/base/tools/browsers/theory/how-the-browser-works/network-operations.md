# Сетевые операции

Сетевая подсистема браузера запрашивает необходимые ресурсы когда мы кликаем по ссылке или вводим `url`.

Контроль всего, что работает все конкретной вкладки, то есть пользовательский интерфейс, управляется **процессом браузера**.

## Запрос на навигацию

### Разбор url

Браузер анализирует введенный адрес.

### Поиск DNS

Цель получить `ip` адрес хоста, если он отсутствует в хеше браузера.

### Установка соединения

Если активного соединения нет, браузер открывает новое

### Отправка HTTP-запроса

Когда соединение установлено, отправляется запрос на ресурс, например протоколы `HTTP/2` или `HTTP/3` позволяют передать несколько ресурсов по одному соединению.

### Ответ

Браузер читает поток данных и пытается его обработать

### Перенаправление

Бывает такое, что ответ был перенаправлен на новый адрес.

Только после получения итогового ответа браузер переходи к его обработке.
