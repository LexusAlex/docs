#  Слабое зацепление (Low Coupling) и Высокая связанность (High Cohesion)

## Зацепление Coupling

Это степень зависимости одного модуля от другого. То есть насколько много один модуль знает о внутренностях другого

Сильное зацеление. Классы одного модуля исльно свзяаны с классами другого модуля. Это делает код хрупким.

Слабое зацепление. Классы минимально зависят друг от друга. Они взаимодействуют через контракты, интерфейсы не вникая во внутренню реализацию друг друга.

В идеале каждый класс должен азниматься только своим делом.

## Связанность Cohesion

Элементы одного модуля логически связаны и выполняют одну задачу.

Низкая связанность - Класс или функция делает много разных, не связанных между собой вещей. Такой код сложно понять и поддерживать.

Высокая связанность - Все методы и свойства класса служат одной, четко определенной цели. Класс делает "что-то одно" и делает это хорошо. 

## Итог

Зацепление - зависимость между модулями должна быть слабой, то есть минимальные зависимости между компонентами.

Связанность - логическая связь внутри модуля должна быть высокой, макмимальная фокусировка модуля на одной задаче.

Нужно чтобы Зацепление было слабым `Low Coupling`, а связанность кода была высокой `High Cohesion`.
