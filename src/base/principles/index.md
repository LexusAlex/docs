- Управление данными и состоянием
  - Состояние - это то что изменяется во времени - это данные (state ->code-> ui ->event-> state) . Состояние может меняться по websocket или timer
    - То есть определяем состояние, функция которая отображает состояние на экране
    - Нужна возможность реагировать на изменение состояния
  - Компонент - единица функциональности, прячущая внутри себя (инкапсулирующая) свой вид, логику и оформление

- Паттерны работы с данными
  - Пагинация
- Организация кода
  - Package-by-type - организация по типам всех классов, разбросано по всему проекту
  - Package-by-layer - организация по уровням, слоям Application, Domain, Infrastructure, опять все разбросано в разных местах
  - Package-by-feature - огранизация по фичам. Папка название фичи, все лежит рядышком
