# Заголовки

Используйте классическую модель с одним `<h1>` и строгой, непрерывной иерархией заголовков. 
А семантические элементы `<section>`, `<article>` и другие используйте для логической группировки контента, 
а не для сброса уровня заголовка.

## Как работать с заголовками

- Только один заголовок `h1` на страницу. Он должен быть уникален в пределах всего сайта.
- Строгая иерархия без пропусков. Никогда не перескакивайте через уровень.
- Используйте `<section>` и `<article>` для семантики, а не для иерархии. Они должны быть в пределах общей семантики.
- Заголовки описывают контент. Каждый заголовок должен кратко и точно отражать содержание секции, которой он принадлежит. Пользователь должен понимать, о чём пойдёт речь, лишь прочитав заголовки.
- Заголовок - это смысловой элемент, а не оформительский.

## Пример правильной структуры

````html
<!doctype html>
<html lang="en">
<head>
<meta charset="UTF-8">
<meta name="viewport" content="width=device-width, user-scalable=no, initial-scale=1.0, maximum-scale=1.0, minimum-scale=1.0">
<meta http-equiv="X-UA-Compatible" content="ie=edge">
<title>Document</title>
</head>
<body>
<h1>Главная страница</h1>
<section>
  <h2>Новости</h2>
  <article>
    <h3>Событие 1</h3>
    <article>
      <h4>Событие 1.1</h4>
    </article>
  </article>
  <article>
    <h3>Событие 2</h3>
  </article>
</section>
<aside>
  <h2>Реклама</h2>
</aside>
</body>
</html>
````
