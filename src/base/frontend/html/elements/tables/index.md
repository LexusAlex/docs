# Таблицы

Табличные данные, группы строк и ячейки.

- [`table`](./table) — Таблица данных в двух измерениях.
- [`caption`](./caption) — Заголовок или подпись таблицы.
- [`colgroup`](./colgroup) — Группа одного или нескольких столбцов таблицы.
- [`col`](./col) — Столбец внутри colgroup.
- [`tbody`](./tbody) — Группа основных строк таблицы.
- [`thead`](./thead) — Группа строк заголовка таблицы.
- [`tfoot`](./tfoot) — Группа итоговых строк таблицы.
- [`tr`](./tr) — Строка таблицы.
- [`td`](./td) — Ячейка данных таблицы.
- [`th`](./th) — Заголовочная ячейка таблицы.
