# Формы

Ввод, выбор, отправка и отображение результатов.

- [`form`](./form) — Набор элементов управления для отправки данных.
- [`label`](./label) — Подпись элемента управления формы.
- [`input`](./input) — Типизированный элемент управления вводом.
- [`button`](./button) — Кнопка, отправляющая форму или выполняющая команду.
- [`select`](./select) — Элемент выбора из списка вариантов.
- [`datalist`](./datalist) — Набор предложенных вариантов для связанного input.
- [`optgroup`](./optgroup) — Именованная группа option внутри select.
- [`option`](./option) — Вариант выбора в select, datalist или optgroup.
- [`textarea`](./textarea) — Многострочное поле ввода обычного текста.
- [`output`](./output) — Результат вычисления или пользовательского действия.
- [`progress`](./progress) — Ход выполнения задачи.
- [`meter`](./meter) — Скалярное значение в известном диапазоне.
- [`fieldset`](./fieldset) — Тематическая группа элементов управления формы.
- [`legend`](./legend) — Подпись родительского fieldset.
- [`selectedcontent`](./selectedcontent) — Отображает копию содержимого выбранного option в настраиваемом select.
