# Метаданные документа

Название, базовый URL, стили и машиночитаемые сведения.

- [`head`](./head) — Контейнер метаданных документа, не отображаемых как основное содержимое страницы.
- [`title`](./title) — Название документа для вкладки, истории и результатов поиска.
- [`base`](./base) — Задаёт базовый URL и базовую цель для относительных ссылок документа.
- [`link`](./link) — Связывает документ с внешним ресурсом, чаще всего таблицей стилей или значком.
- [`meta`](./meta) — Передаёт метаданные, которые нельзя выразить через title, base, link или style.
- [`style`](./style) — Содержит встроенные CSS-правила документа.
