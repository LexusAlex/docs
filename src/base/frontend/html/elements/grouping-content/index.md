# Группировка содержимого

Абзацы, списки, цитаты и универсальные контейнеры.

- [`p`](./p) — Абзац текста.
- [`hr`](./hr) — Тематический разрыв между абзацами или разделами.
- [`pre`](./pre) — Блок предварительно форматированного текста, где пробелы и переносы значимы.
- [`blockquote`](./blockquote) — Раздел, процитированный из другого источника.
- [`ol`](./ol) — Упорядоченный список, для которого порядок элементов имеет значение.
- [`ul`](./ul) — Неупорядоченный список.
- [`menu`](./menu) — Список команд или элементов интерфейса, представленный как список.
- [`li`](./li) — Элемент списка ol, ul или menu.
- [`dl`](./dl) — Список групп «имя — значение».
- [`dt`](./dt) — Имя или термин внутри dl.
- [`dd`](./dd) — Значение или описание внутри dl.
- [`figure`](./figure) — Самостоятельный материал, на который можно ссылаться как на единое целое.
- [`figcaption`](./figcaption) — Подпись для ближайшего родительского figure.
- [`main`](./main) — Доминирующее содержимое документа.
- [`search`](./search) — Контейнер средств поиска или фильтрации.
- [`div`](./div) — Универсальный контейнер потокового содержимого без собственной семантики.
