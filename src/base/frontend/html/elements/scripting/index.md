# Сценарии и компоненты

Скрипты, шаблоны, Shadow DOM и программная графика.

- [`script`](./script) — Сценарий или блок данных для обработки программой.
- [`noscript`](./noscript) — Резервное содержимое, когда выполнение скриптов отключено или недоступно.
- [`template`](./template) — Неактивный фрагмент разметки для последующего клонирования или Declarative Shadow DOM.
- [`slot`](./slot) — Точка вставки содержимого в теневом дереве.
- [`canvas`](./canvas) — Скриптуемый растровый холст с резервным содержимым.
