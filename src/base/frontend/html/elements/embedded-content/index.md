# Встраиваемое содержимое

Изображения, медиа, дочерние документы и внешние ресурсы.

- [`picture`](./picture) — Набор альтернативных источников изображения с обязательным img.
- [`source`](./source) — Альтернативный источник для picture, audio или video.
- [`img`](./img) — Изображение с текстовой альтернативой.
- [`iframe`](./iframe) — Встраивает дочерний контекст навигации.
- [`embed`](./embed) — Встраивает внешний ресурс или приложение.
- [`object`](./object) — Встраивает внешний ресурс с возможным резервным содержимым.
- [`video`](./video) — Видеопроигрыватель и связанный медиаресурс.
- [`audio`](./audio) — Аудиопроигрыватель и связанный медиаресурс.
- [`track`](./track) — Временная текстовая дорожка для audio или video.
- [`map`](./map) — Карта изображения, связывающая img с интерактивными областями area.
- [`area`](./area) — Ссылка или неактивная область внутри карты изображения.
