# Секции и структура

Семантическая структура, области страницы и заголовки.

- [`body`](./body) — Содержит отображаемое содержимое HTML-документа.
- [`article`](./article) — Самостоятельная композиция, пригодная для независимого распространения или повторного использования.
- [`section`](./section) — Тематический раздел документа, обычно с собственным заголовком.
- [`nav`](./nav) — Раздел с основными навигационными ссылками.
- [`aside`](./aside) — Содержимое, косвенно связанное с окружающим материалом.
- [`h1`](./h1) — Заголовок первого уровня.
- [`h2`](./h2) — Заголовок второго уровня.
- [`h3`](./h3) — Заголовок третьего уровня.
- [`h4`](./h4) — Заголовок четвёртого уровня.
- [`h5`](./h5) — Заголовок пятого уровня.
- [`h6`](./h6) — Заголовок шестого уровня.
- [`hgroup`](./hgroup) — Группирует заголовок с подзаголовком или альтернативным названием.
- [`header`](./header) — Вводное содержимое или навигационные средства ближайшего раздела.
- [`footer`](./footer) — Справочная информация и завершение ближайшего раздела.
- [`address`](./address) — Контактная информация для страницы или ближайшего article.
