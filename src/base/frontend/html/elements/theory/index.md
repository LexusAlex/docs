# Теория HTML-элементов

HTML описывает смысл и допустимые связи элементов, а CSS — их визуальное представление и участие в раскладке.

- [Блочные и строчные элементы](./block-and-inline) — почему это термины CSS, а не современная классификация HTML.
- [Элементы по категориям содержимого](../by-category) — актуальный индекс категорий WHATWG.
- [Учебные сценарии](../learning-path) — примеры связей родителей, дочерних элементов и атрибутов.
