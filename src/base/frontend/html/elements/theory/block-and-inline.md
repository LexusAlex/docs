# Блочные и строчные элементы

## Модель содержимого

Каждый `html` элемент имеет модель которая, описывает ожидаемое содержимое.

**Модель содержимого** - это некий набор правил, которые определяют, какие другие элементы или типы данных могут находиться внутри данного элемента.

**Содержимое элемента** - это его дочерние узлы в `DOM` дереве.

Пробелы между элементами при этом разрешены, они представляют собой текстовый узел.

В итоге `html` документ должен быть структурирован в соответствии с правилами установленными в спецификации, и что определенные типы узлов не влияют на семантическое значение документов.

В старых спецификациях `HTML 4` было грубое разделение элементов "Блочный элемент может содержать строчные и блочные, а строчный элемент только строчные"

Современный стандарт `HTML 5` ввел уже понятие категорий содержимого. 
Один и тот же элемент может принадлежать сразу к нескольким категориям, их делят по их _логической роли_

## Блок и строка

**Блок** - это по сути самая крупная структурная единица страницы. Это прямоугольник, который занимает все доступное пространство по горизонтали.

**Инлайновый** или **строчный элемент** располагается в строке и при переносе строки разрывается на несколько прямоугольников.

## Бокс

В `css 2` появилось еще одно понятие `box`. Это прямоугольная область которую генерирует браузер для отображения элемента.

Теперь самое главное как же связан бокс и элемент.

- Один элемент один бокс. Например, элемент `div` генерирует один бокс
- Один элемент может порождать несколько боксов. Это происходит когда в одном блочном элементе содержится строчный контент `<p>Это длинный текст</p>`. Здесь `p` это блочный бокс, а внутри него несколько строчных боксов по одному на каждую строку текста.
- Бокс без элементов. Бокс может быть сам по себе без своего элемента, например `Это длинный текст`. Браузер обернет текст `Это длинный текст` в анонимный бокс.

::: info
У нас нет блочных и строчных элементов.
:::

## Итог

- Оказывается что у нас нет блочных и строчных элементов, так как модель содержимого у всех элементов разная исходя из их логического предназначения.
- Визуальная составляющая элемента относится исключительно к `CSS`. То есть `CSS` может изменить внешний вид элемента, но на модель содержимого повлиять не может.
- Модель содержимого элемента важна при построении `DOM`, а далее в игру уже вступает css со своим оформлением.

::: info
`НTML` описывает что (элемент), а `CSS` описывает как (элемент выглядит).
:::

::: tip
Важно то для чего элемент предназначен (`НTML`), а не как он выглядит (`CSS`).
:::
