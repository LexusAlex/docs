# HTML-атрибуты

Каталог основан на индексе WHATWG: **32 глобальные темы**, **113 специальных атрибутов** и **89 атрибутов-обработчиков событий**. Одно имя с разной семантикой описывается на одной странице с таблицей вариантов.

::: info Актуальность
Страница сверена 2026-07-22 с текущим индексом WHATWG HTML Living Standard. Наличие в стандарте не заменяет проверку поддержки браузерами для проекта.
:::


## Разделы

- [Глобальные атрибуты](./global/) — применимы ко всем HTML-элементам, хотя эффект зависит от контекста.
- [Специальные атрибуты](./element-specific/) — определены для конкретных элементов.
- [Атрибуты событий](./events/) — встроенные обработчики; в приложениях обычно предпочтительнее addEventListener.
- [Индекс атрибутов по элементам](./by-element) — обратная связь от элемента к допустимым атрибутам.
- [Устаревшие элементы и атрибуты](../obsolete) — одно общее приложение.
