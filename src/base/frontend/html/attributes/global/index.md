# Глобальные атрибуты

Применимы ко всем HTML-элементам, но эффект некоторых атрибутов зависит от элемента и контекста.

- [`accesskey`](./accesskey) — Объявляет клавишу быстрого доступа к элементу.
- [`autocapitalize`](./autocapitalize) — Подсказывает, как автоматически менять регистр вводимого текста.
- [`autocorrect`](./autocorrect) — Подсказывает, следует ли автоматически исправлять вводимый текст.
- [`autofocus`](./autofocus) — Просит сфокусировать элемент при загрузке или открытии диалога/popover.
- [`class`](./class) — Задаёт список классов элемента.
- [`contenteditable`](./contenteditable) — Определяет, можно ли редактировать содержимое элемента.
- [`data-*`](./data-star) — Хранит пользовательские данные, доступные через dataset.
- [`dir`](./dir) — Задаёт направление текста элемента.
- [`draggable`](./draggable) — Указывает, можно ли перетаскивать элемент.
- [`enterkeyhint`](./enterkeyhint) — Подсказывает подпись клавиши Enter на виртуальной клавиатуре.
- [`headingoffset`](./headingoffset) — Смещает вычисляемые уровни вложенных заголовков.
- [`headingreset`](./headingreset) — Сбрасывает вычисляемое смещение уровней заголовков.
- [`hidden`](./hidden) — Скрывает нерелевантное содержимое или включает состояние until-found.
- [`id`](./id) — Задаёт уникальный в документе идентификатор без ASCII-пробелов.
- [`inert`](./inert) — Делает поддерево неинтерактивным для фокуса и пользовательского ввода.
- [`inputmode`](./inputmode) — Подсказывает подходящую виртуальную клавиатуру.
- [`is`](./is) — Указывает имя настроенного встроенного элемента.
- [`itemid`](./itemid) — Задаёт глобальный идентификатор microdata-элемента.
- [`itemprop`](./itemprop) — Задаёт свойства microdata-элемента.
- [`itemref`](./itemref) — Добавляет по id внешние свойства к microdata-элементу.
- [`itemscope`](./itemscope) — Создаёт новый microdata-элемент.
- [`itemtype`](./itemtype) — Задаёт типы microdata-элемента как абсолютные URL.
- [`lang`](./lang) — Задаёт язык содержимого элемента.
- [`nonce`](./nonce) — Передаёт криптографический nonce для Content Security Policy.
- [`popover`](./popover) — Превращает элемент в popover и задаёт режим его поведения.
- [`slot`](./slot) — Назначает элемент именованному slot в теневом дереве.
- [`spellcheck`](./spellcheck) — Подсказывает, следует ли проверять орфографию редактируемого текста.
- [`style`](./style) — Задаёт встроенные CSS-декларации элемента.
- [`tabindex`](./tabindex) — Управляет фокусируемостью и порядком последовательной навигации.
- [`title`](./title) — Передаёт консультативную информацию; смысл зависит от элемента.
- [`translate`](./translate) — Указывает, следует ли переводить текст и переводимые атрибуты элемента.
- [`writingsuggestions`](./writingsuggestions) — Разрешает или запрещает предложения текста от пользовательского агента.
