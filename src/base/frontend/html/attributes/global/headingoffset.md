# `headingoffset`

Смещает вычисляемые уровни вложенных заголовков.

::: info Актуальность
Страница сверена 2026-07-22 с текущим индексом WHATWG HTML Living Standard. Наличие в стандарте не заменяет проверку поддержки браузерами для проекта.

::: warning Проверяйте поддержку

## Применимость и значение

| Элементы | Значение в индексе WHATWG | Формат значения | Определение |
|---|---|---|---|
| Все HTML-элементы | Offsets heading levels for descendants | Valid non-negative integer between 0 and 8 | [WHATWG](https://html.spec.whatwg.org/multipage/sections.html#attr-headingoffset) |

Английские формулировки в таблице сохранены из официального индекса, чтобы не потерять нормативные различия одноимённых атрибутов.

## Примеры использования

### Для всех HTML-элементов

Точная формулировка WHATWG: `Offsets heading levels for descendants`. Формат из индекса: `Valid non-negative integer between 0 and 8`.

```html
<section headingoffset="2">Содержимое section</section>
```

### Смещение вложенных заголовков

```html
<article headingoffset="1">
  <h1>Вычисляется как заголовок второго уровня</h1>
  <section headingoffset="1"><h1>Ещё на уровень глубже</h1></section>
</article>
```

Если атрибут отсутствует, действует состояние по умолчанию конкретного элемента. Пустая строка и отсутствие атрибута не взаимозаменяемы, кроме случаев, явно определённых спецификацией.
