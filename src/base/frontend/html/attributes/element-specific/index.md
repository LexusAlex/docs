# Специальные атрибуты

Определены только для перечисленных элементов; одинаковое имя может иметь несколько вариантов семантики.

- [`abbr`](./abbr) — Задаёт краткую альтернативную подпись заголовочной ячейки таблицы.
- [`accept`](./accept) — Подсказывает допустимые типы файлов для загрузки.
- [`accept-charset`](./accept-charset) — Задаёт кодировку отправки формы; в актуальном HTML допустим UTF-8.
- [`action`](./action) — Задаёт URL обработчика отправки формы.
- [`allow`](./allow) — Определяет Permissions Policy для содержимого iframe.
- [`allowfullscreen`](./allowfullscreen) — Разрешает содержимому iframe переходить в полноэкранный режим.
- [`alpha`](./alpha) — Указывает, что компонент выбора цвета поддерживает альфа-канал.
- [`alt`](./alt) — Задаёт текстовую альтернативу изображению или области карты.
- [`as`](./as) — Уточняет тип ресурса для предварительной загрузки.
- [`async`](./async) — Разрешает выполнять внешний классический скрипт независимо от разбора документа.
- [`autocomplete`](./autocomplete) — Управляет автозаполнением формы или элемента управления.
- [`autoplay`](./autoplay) — Просит начать воспроизведение медиа автоматически.
- [`blocking`](./blocking) — Указывает операции, которые могут блокировать отображение документа.
- [`charset`](./charset) — Указывает кодировку документа или внешнего ресурса.
- [`checked`](./checked) — Задаёт начальное выбранное состояние checkbox или radio.
- [`cite`](./cite) — Ссылается на источник цитаты или описание правки.
- [`closedby`](./closedby) — Ограничивает способы, которыми пользователь может закрыть dialog.
- [`color`](./color) — Задаёт цвет подсветки для link rel=mask-icon.
- [`colorspace`](./colorspace) — Выбирает цветовое пространство элемента input type=color.
- [`cols`](./cols) — Задаёт ожидаемую ширину textarea в символах.
- [`colspan`](./colspan) — Задаёт число столбцов, занимаемых ячейкой.
- [`command`](./command) — Задаёт команду, которую button передаёт целевому элементу.
- [`commandfor`](./commandfor) — Указывает элемент, которым управляет кнопка.
- [`content`](./content) — Хранит значение метаданных meta.
- [`controls`](./controls) — Запрашивает встроенные средства управления пользовательского агента.
- [`coords`](./coords) — Задаёт координаты области карты изображения.
- [`crossorigin`](./crossorigin) — Настраивает CORS-режим загрузки ресурса.
- [`data`](./data) — Задаёт URL ресурса object.
- [`datetime`](./datetime) — Задаёт машиночитаемую дату или время для time, ins и del.
- [`decoding`](./decoding) — Подсказывает способ декодирования изображения.
- [`default`](./default) — Делает текстовую дорожку track предпочтительной по умолчанию.
- [`defer`](./defer) — Откладывает выполнение классического внешнего скрипта до завершения разбора документа.
- [`dirname`](./dirname) — Добавляет направление текста поля к отправляемым данным формы.
- [`disabled`](./disabled) — Отключает элемент управления или связанную группу.
- [`download`](./download) — Предлагает скачать целевой ресурс и при необходимости задаёт имя файла.
- [`enctype`](./enctype) — Задаёт формат данных при отправке формы методом POST.
- [`fetchpriority`](./fetchpriority) — Подсказывает относительный приоритет загрузки ресурса.
- [`for`](./for) — Связывает label или output с другими элементами по id.
- [`form`](./form) — Связывает элемент управления с form по id вне обычного вложения.
- [`formaction`](./formaction) — Переопределяет URL отправки формы для кнопки отправки.
- [`formenctype`](./formenctype) — Переопределяет формат отправки формы для кнопки отправки.
- [`formmethod`](./formmethod) — Переопределяет HTTP-метод отправки формы для кнопки отправки.
- [`formnovalidate`](./formnovalidate) — Отключает проверку формы для конкретной кнопки отправки.
- [`formtarget`](./formtarget) — Переопределяет контекст навигации результата отправки формы.
- [`headers`](./headers) — Связывает ячейку таблицы с заголовочными ячейками по id.
- [`height`](./height) — Задаёт высоту в CSS-пикселях для поддерживающих элементов.
- [`high`](./high) — Задаёт нижнюю границу высокого диапазона meter.
- [`href`](./href) — Задаёт адрес гиперссылки или внешнего ресурса.
- [`hreflang`](./hreflang) — Подсказывает язык связанного ресурса.
- [`http-equiv`](./http-equiv) — Объявляет pragma-директиву meta.
- [`imagesizes`](./imagesizes) — Задаёт размеры адаптивного изображения, предзагружаемого через link.
- [`imagesrcset`](./imagesrcset) — Задаёт кандидаты адаптивного изображения для link rel=preload.
- [`integrity`](./integrity) — Передаёт криптографические метаданные Subresource Integrity.
- [`ismap`](./ismap) — Включает серверную карту изображения для img внутри ссылки.
- [`kind`](./kind) — Задаёт назначение временной дорожки track.
- [`label`](./label) — Задаёт пользовательскую подпись track, option или optgroup.
- [`list`](./list) — Связывает input с datalist по id.
- [`loading`](./loading) — Подсказывает, загружать ресурс сразу или лениво.
- [`loop`](./loop) — Повторяет audio или video после окончания.
- [`low`](./low) — Задаёт верхнюю границу низкого диапазона meter.
- [`max`](./max) — Задаёт максимальное допустимое значение.
- [`maxlength`](./maxlength) — Ограничивает максимальную длину пользовательского ввода.
- [`media`](./media) — Задаёт условие, при котором ресурс или source применим.
- [`method`](./method) — Задаёт способ отправки формы.
- [`min`](./min) — Задаёт минимальное допустимое значение.
- [`minlength`](./minlength) — Ограничивает минимальную длину пользовательского ввода.
- [`multiple`](./multiple) — Разрешает выбрать или ввести несколько значений.
- [`muted`](./muted) — Задаёт начальное беззвучное состояние медиа.
- [`name`](./name) — Задаёт имя элемента для отправки, навигации или поиска.
- [`nomodule`](./nomodule) — Не выполняет скрипт в средах с поддержкой JavaScript-модулей.
- [`novalidate`](./novalidate) — Отключает встроенную проверку при отправке формы.
- [`open`](./open) — Задаёт открытое состояние details или dialog.
- [`optimum`](./optimum) — Задаёт оптимальное значение meter.
- [`pattern`](./pattern) — Задаёт регулярное выражение для проверки значения поля.
- [`ping`](./ping) — Перечисляет URL, уведомляемые при переходе по ссылке.
- [`placeholder`](./placeholder) — Показывает краткую подсказку в пустом поле ввода.
- [`playsinline`](./playsinline) — Подсказывает воспроизводить видео внутри страницы.
- [`popovertarget`](./popovertarget) — Связывает кнопку с popover по id.
- [`popovertargetaction`](./popovertargetaction) — Задаёт действие кнопки над целевым popover.
- [`poster`](./poster) — Задаёт изображение-заставку video.
- [`preload`](./preload) — Подсказывает объём предварительной загрузки медиа.
- [`readonly`](./readonly) — Запрещает изменение значения пользователем, сохраняя участие в форме.
- [`referrerpolicy`](./referrerpolicy) — Задаёт политику передачи Referer при загрузке или переходе.
- [`rel`](./rel) — Задаёт тип связи текущего документа с целевым ресурсом.
- [`required`](./required) — Требует непустое допустимое значение перед отправкой формы.
- [`reversed`](./reversed) — Разворачивает нумерацию упорядоченного списка.
- [`rows`](./rows) — Задаёт ожидаемую высоту textarea в строках.
- [`rowspan`](./rowspan) — Задаёт число строк, занимаемых ячейкой.
- [`sandbox`](./sandbox) — Накладывает ограничения на содержимое iframe с помощью токенов.
- [`scope`](./scope) — Указывает набор ячеек, к которому относится заголовок th.
- [`selected`](./selected) — Задаёт начально выбранный option.
- [`shadowrootclonable`](./shadowrootclonable) — Разрешает клонировать декларативный Shadow Root.
- [`shadowrootcustomelementregistry`](./shadowrootcustomelementregistry) — Просит создать отдельный реестр пользовательских элементов для Shadow Root.
- [`shadowrootdelegatesfocus`](./shadowrootdelegatesfocus) — Включает делегирование фокуса в Shadow Root.
- [`shadowrootmode`](./shadowrootmode) — Создаёт декларативный Shadow Root в режиме open или closed.
- [`shadowrootserializable`](./shadowrootserializable) — Разрешает сериализацию Shadow Root.
- [`shadowrootslotassignment`](./shadowrootslotassignment) — Выбирает именованное или ручное распределение по slot.
- [`shape`](./shape) — Задаёт форму области карты изображения.
- [`size`](./size) — Задаёт видимое число вариантов select или ширину поля ввода.
- [`sizes`](./sizes) — Задаёт размеры адаптивного изображения или медиазапросы для icon.
- [`span`](./span) — Задаёт число столбцов в col или colgroup.
- [`src`](./src) — Задаёт URL встраиваемого ресурса.
- [`srcdoc`](./srcdoc) — Передаёт HTML-документ непосредственно в iframe.
- [`srclang`](./srclang) — Задаёт язык текстовой дорожки track.
- [`srcset`](./srcset) — Задаёт набор кандидатов изображения и их дескрипторы.
- [`start`](./start) — Задаёт начальное число упорядоченного списка.
- [`step`](./step) — Задаёт допустимый шаг числового или временного значения.
- [`target`](./target) — Задаёт контекст навигации для ссылки, base или формы.
- [`type`](./type) — Выбирает вид элемента, ресурса, кнопки, поля или списка.
- [`usemap`](./usemap) — Связывает img или object с map по имени.
- [`value`](./value) — Задаёт начальное либо машиночитаемое значение; смысл зависит от элемента.
- [`width`](./width) — Задаёт ширину в CSS-пикселях для поддерживающих элементов.
- [`wrap`](./wrap) — Задаёт перенос строк и сериализацию значения textarea.
