# Комбинаторы

Комбинаторы определяют.relationship между селекторами. Они указывают, как элементы связаны друг с другом в дереве DOM.

- [Потомок](descendant.md) — пробел (`A B`)
- [Прямой потомок](child.md) — greater-than (`A > B`)
- [Смежный sibling](adjacent-sibling.md) — плюс (`A + B`)
- [Общий sibling](general-sibling.md) — тильда (`A ~ B`)
