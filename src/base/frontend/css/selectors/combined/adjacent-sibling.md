# Комбинатор смежного sibling ( adjacent sibling combinator )

Комбинатор смежного sibling обозначается символом `+` между двумя селекторами. Он выбирает элемент, который идёт непосредственно после другого и имеет общего родителя.

## Синтаксис

```css
A + B {
  /* стили */
}
```

Элемент `B` выбирается только если он следует сразу за `A` (без других элементов между ними).

## Примеры

### Абзац сразу после заголовка

```css
h2 + p {
  font-size: 1.125rem;
  color: #555;
}
```

```html
<h2>Заголовок</h2>
<p>Первый абзац — будет стилизован</p>
<p>Второй абзац — не будет</p>
```

### Отступы между секциями

```css
section + section {
  margin-top: 2rem;
}
```

### Форма: метка перед полем

```css
label + input {
  margin-top: 0.25rem;
}

input + input {
  margin-left: 0.5rem;
}
```

### Навигация: разделитель между ссылками

```css
a + a::before {
  content: " | ";
  color: #999;
}
```

## Специфичность

Комбинатор смежного sibling **не добавляет** специфичность.

```css
/* Специфичность = 0-0-1 */
p { color: black; }

/* Специфичность = 0-1-0 (только .lead) */
.lead + p { font-size: 1.125rem; }
```

::: tip
Комбинатор смежного sibling полезен для стилизации элементов, которые логически связаны своей последовательностью, например: заголовок → абзац, метка → поле ввода.
:::
