# Комбинатор потомка ( descendant combinator )

Комбинатор потомка — это пробел между двумя селекторами. Он выбирает все элементы, являющиеся потомками (на любом уровне вложенности) указанного родителя.

## Синтаксис

```css
A B {
  /* стили */
}
```

## Примеры

### Все абзацы внутри `article`

```html
<article>
  <p>Привет</p>
  <section>
    <p>Вложенное</p>
  </section>
</article>
```

```css
article p {
  line-height: 1.6;
}
```

Оба абзаца (прямой потомок и вложенный через `section`) получат стили.

### Вложенность на любой глубине

```css
/* Все элементы внутри .sidebar — на любой глубине */
.sidebar a {
  color: inherit;
}

/* Все изображения внутри .card */
.card img {
  max-width: 100%;
}
```

### Комбинация с другими селекторами

```css
/* Все input[type="text"] внутри формы */
form input[type="text"] {
  border: 1px solid #ccc;
}

/* Все пункты меню внутри nav */
nav ul li a {
  display: block;
  padding: 0.5rem 1rem;
}
```

## Специфичность

Комбинатор потомка **не добавляет** специфичность. Специфичность определяется только селекторами по обе стороны от пробела.

```css
/* Специфичность = 0-0-1 (только p) */
p { color: black; }

/* Специфичность = 0-1-0 (только .text) */
.text p { color: blue; }
```

## Разница с прямым потомком

```css
/* Прямой потомок: только вложенные напрямую */
nav > ul { list-style: none; }

/* Любой потомок: все уровни вложенности */
nav ul { list-style: none; }
```

::: tip
Комбинатор потомка полезен для стилизации по контексту, но избегайте излишней вложенности — это снижает производительность селекторов.
:::
