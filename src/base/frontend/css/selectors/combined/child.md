# Комбинатор прямого потомка ( child combinator )

Комбинатор прямого потомка обозначается символом `>` между двумя селекторами. Он выбирает только те элементы, которые являются прямыми потомками (дочерними элементами) указанного родителя.

## Синтаксис

```css
A > B {
  /* стили */
}
```

## Примеры

### Прямые дочерние элементы

```html
<nav>
  <ul>
    <li><a href="#">Ссылка</a></li>
  </ul>
</nav>
```

```css
/* Только прямые <ul> внутри <nav> */
nav > ul {
  list-style: none;
  display: flex;
  gap: 1rem;
}

/* Только прямые <li> внутри <ul> */
ul > li {
  margin-right: 1rem;
}
```

### Разница с потомком

```css
/* Вложенный <a> внутри <li> внутри <ul> */
ul > li > a {
  color: inherit;
  text-decoration: none;
}

/* Только прямой <li> внутри <ul> */
ul > li {
  padding: 0.5rem 0;
}
```

### Стилизация контейнера

```css
/* Все прямые div внутри .grid получают определённую ширину */
.grid > div {
  flex: 1;
}

/* Только прямые потомки — не затрагивает вложенные */
.card > p:last-child {
  margin-bottom: 0;
}
```

## Специфичность

Комбинатор прямого потомка, как и комбинатор потомка, **не добавляет** специфичность.

```css
/* Специфичность = 0-0-1 */
p { color: black; }

/* Специфичность = 0-1-0 (только .content) */
.content > p { color: blue; }
```

## Когда использовать

Используйте `>` когда важно ограничить выборку только прямыми детьми, а не всей вложенностью. Это полезно для:
- Контейнеров раскладки (flex, grid)
- Навигационных списков
- Карточек с вложенной структурой

::: tip
Комбинатор прямого потомка делает селектор более точным и предсказуемым. Предпочитайте его комбинатору потомка там, где это возможно.
:::
