# Универсальный селектор

Универсальный селектор `*` соответствует **всем элементам** в DOM-дереве независимо от типа.

## Синтаксис

```css
* {
  color: red;
}
```

## Применение

Чаще всего используется для сброса стилей по умолчанию:

```css
* {
  margin: 0;
  padding: 0;
  box-sizing: border-box;
}
```

## Специфичность

Универсальный селектор имеет специфичность `0-0-0` — такую же, как у селекторов по тегу. Он не добавляет веса к правилу.

## Комбинирование

Можно комбинировать с другими селекторами:

```css
/* Все элементы внутри .container */
.container * {
  font-size: 14px;
}

/* Все элементы с атрибутом data-active */
*[data-active] {
  opacity: 1;
}
```

::: tip
Используйте `*` осторожно — применение ко всем элементам страницы может повлиять на производительность. Лучше ограничивать контекстом.
:::
