# Универсальный селектор *

Универсальный селектор `*` используется для выбора **всех** элементов на странице. 
Он применяет стили глобально, но требует осторожного использования из-за особенностей специфичности и производительности.

То есть селектор соотвествует абсолютно любому тегу на странице, кроме псевдоэлементов `::before` и `::after`.
