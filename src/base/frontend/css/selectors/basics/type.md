# Селектор типа элемента

Селектор типа элемента (type selector) выбирает все элементы с указанным именем тега без префикса `.` или `#`.

## Синтаксис

```css
div {
  color: blue;
}
```

Все элементы `<div>` получат синий цвет текста.

## Примеры

### Стилизация конкретного тега

```css
p {
  line-height: 1.6;
}

h1, h2, h3 {
  font-weight: 700;
}

a {
  text-decoration: none;
}
```

### В комбинации с другими селекторами

```css
/* Все абзацы внутри article */
article p {
  max-width: 65ch;
}

/* Прямой потомок — только первый уровень */
nav > ul {
  list-style: none;
}
```

## Специфичность

Специфичность селектора типа — `0-0-1`. Он уступает селекторам класса (`0-1-0`) и ID (`1-0-0`).

```css
/* Специфичность 0-0-1 */
p {
  color: black;
}

/* Специфичность 0-1-0 — победит */
.text {
  color: red;
}
```

::: tip
Используйте селекторы типа для стилизации по семантике, а не по внешнему виду. Селекторы по классу более гибки и переиспользуемы.
:::
