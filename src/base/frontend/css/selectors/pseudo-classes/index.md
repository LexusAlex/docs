# Псевдоклассы

Псевдоклассы — это ключевые слова, добавляемые к селектору, которые определяют специфическое состояние элемента. Они обозначаются двоеточием `:` перед именем (за исключением `:has()`, `:is()`, `:where()` — они используют двоеточие, но являются функциональными).

- [Состояние](state.md) — :hover, :active, :focus, :visited, :link
- [Структурные](structural.md) — :root, :first-child, :nth-child(), :not(), :is(), :where(), :has()
- [Поля ввода](input.md) — :checked, :disabled, :valid, :invalid, :required
