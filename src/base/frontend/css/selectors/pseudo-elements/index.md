# Псевдоэлементы

Псевдоэлементы позволяют стилизовать определённые части элемента или вставлять декоративное содержимое с помощью CSS. Они обозначаются двойным двоеточием `::`.

- [Текстовые](text.md) — ::first-line, ::first-letter, ::selection, ::placeholder, ::marker
- [Генерируемое содержимое](generated.md) — ::before, ::after
- [Дерево](tree.md) — ::details-content
