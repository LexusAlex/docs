# Методологии

Методологии организации CSS-кода определяют правила именования классов, структуру стилей и подходы к архитектуре проекта. Главная цель — сделать код предсказуемым, переиспользуемым и удобным для командной работы.

## Зачем нужны методологии

Без методологии CSS-код быстро превращается в хаос:
- конфликты имён классов
- дублирование стилей
- сложность переиспользования
- трудности при масштабировании

Методология решает эти проблемы, предоставляя единые правила для всех разработчиков.

## Основные подходы

| Подход | Особенность |
|--------|-------------|
| [БЭМ](bem.md) | Блок-Элемент-Модификатор, русскоязычная методология |
| OOCSS | Объектно-ориентированный CSS |
| SMACSS | Scalable and Modular Architecture for CSS |
| ITCSS | Inverted Triangle CSS — по слоям от общего к частному |

## Когда выбирать методологию

- **Маленький проект** (1–3 страницы) — методология не обязательна, но БЭМ не помешает
- **Средний проект** (SPA, лендинг) — БЭМ или SMACSS
- **Крупный проект** (e-commerce, дизайн-система) — БЭМ + ITCSS
