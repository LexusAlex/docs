# table-layout

Свойство `table-layout` определяет алгоритм расчёта ширины ячеек и столбцов таблицы.

## Значения

| Значение | Описание |
|----------|----------|
| `auto` | Ширина столбцов определяется содержимым (по умолчанию) |
| `fixed` | Ширина столбцов определяется шириной таблицы и первых ячеек |

## table-layout: auto

При значении `auto` браузер вычисляет ширину каждого столбца на основе содержимого ячеек. Это занимает больше времени, но обеспечивает точное отображение контента.

```css
table {
  table-layout: auto;
  width: 100%;
}
```

Результат — столбцы будут иметь разную ширину в зависимости от самого длинного содержимого в каждом столбце.

## table-layout: fixed

При значении `fixed` ширина столбцов определяется шириной таблицы и шириной ячеек в первой строке. Остальные строки не влияют на расчёт ширины.

```css
table {
  table-layout: fixed;
  width: 800px;
}

/* Задаём ширины столбцов через colgroup */
/* <colgroup>
     <col style="width: 200px;">
     <col style="width: 300px;">
     <col>
   </colgroup>
*/
```

:::tip
Значение `fixed` значительно быстрее `auto`, так как не требует анализа содержимого всех ячеек. Используйте его для таблиц с фиксированной структурой.
:::

## Производительность

| Критерий | auto | fixed |
|----------|------|-------|
| Скорость расчёта | Медленнее | Быстрее |
| Точность ширины | Точная | Приблизительная |
| Рекомендуется для | Малых таблиц | Больших таблиц |

```css
/* Быстрая таблица с фиксированными столбцами */
.large-table {
  table-layout: fixed;
  width: 100%;
  border-collapse: collapse;
}
```

## Задание ширины столбцов

При `fixed` ширину столбцов можно задать через:

1. `colgroup` / `col` — предпочтительный способ
2. Первую строку таблицы
3. CSS-свойства ячеек первой строки

```css
table {
  table-layout: fixed;
  width: 100%;
}

colgroup .name {
  width: 25%;
}

colgroup .email {
  width: 35%;
}

/* Или через ячейки первой строки */
thead th:first-child {
  width: 200px;
}
```

:::info
Если ни один из столбцов не имеет явной ширины, `fixed` распределит пространство равномерно между всеми столбцами.
:::
