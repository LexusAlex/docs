# cursor

Определяет тип курсора при наведении на элемент.

## Значения

| Значение | Описание |
|----------|----------|
| `auto` | Курсор определяется браузером по умолчанию |
| `default` | Стандартный курсор (стрелка) |
| `none` | Курсор скрыт |
| `pointer` | Указатель руки (для ссылок и кнопок) |
| `text` | Текстовый курсор (I-beam) |
| `wait` | Индикатор загрузки (песочные часы) |
| `help` | Вопросительный знак |
| `move` | Четырёхнаправленные стрелки |
| `crosshair` | Перекрестие |
| `grab` | Курсор захвата |
| `grabbing` | Курсор захвата (при перетаскивании) |
| `not-allowed` | Запрещено (зачёркнутый круг) |
| `progress` | Индикатор выполнения |
| `col-resize` | Изменение ширины столбца |
| `row-resize` | Изменение высоты строки |
| `nesw-resize` | Диагональное изменение размера (SE/NW) |
| `nwse-resize` | Диагональное изменение размера (NE/SW) |
| `zoom-in` | Увеличительное стекло с плюсом |
| `zoom-out` | Уменьшительное стекло с минусом |
| `url()` | Пользовательский курсор из файла |

:::info
Значение `pointer` — самое частое для интерактивных элементов. Используйте его для ссылок, кнопок и кликабельных областей.
:::

## Примеры

### Курсор-указатель для ссылок и кнопок

```css
a,
button,
[role="button"] {
  cursor: pointer;
}
```

### Текстовый курсор для редактируемых областей

```css
input,
textarea,
[contenteditable="true"] {
  cursor: text;
}
```

### Курсор загрузки

```css
.is-loading {
  cursor: wait;
  pointer-events: none;
}
```

### Запрещённый курсор для неактивных элементов

```css
button:disabled {
  cursor: not-allowed;
  opacity: 0.5;
}
```

### Курсор захвата для перетаскиваемых элементов

```css
.draggable {
  cursor: grab;
}

.draggable:active {
  cursor: grabbing;
}
```

### Пользовательский курсор с fallback

```css
.custom-cursor {
  cursor: url("custom.png"), auto;
}
```

:::tip
Всегда указывайте fallback-значение после `url()`, чтобы браузер мог отобразить стандартный курсор, если файл изображения не загрузился.
:::

### Масштабирование пользовательского курсора

```css
.scaled-cursor {
  cursor: url("cursor.svg") 16 16, auto;
}
```

Значения `16 16` задают горячую точку (hotspot) — точку, за которую «цепляется» курсор.

### Скрытие курсора

```css
.fullscreen-presentation {
  cursor: none;
}
```
