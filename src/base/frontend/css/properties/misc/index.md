# Разное

Свойства, которые не входят в другие категории, но важны для понимания каскада, наследования и оптимизации.

## Управление наследованием

| Свойство | Назначение |
|----------|-----------|
| `all` | Сброс всех свойств за один раз |
| `initial` | Установка начального значения по спецификации |
| `inherit` | Принудительное наследование от родителя |
| `unset` | Сброс: наследуемое → inherit, остальное → initial |
| `revert` | Откат к предыдущему каскадному значению |

## Оптимизация

| Свойство | Назначение |
|----------|-----------|
| `will-change` | Подсказка браузеру о готовящихся анимациях |

:::warning
Не используйте `will-change` на множестве элементов — это потребляет много памяти. Применяйте только к тем элементам, которые действительно будут анимироваться.
:::
