# Orphans & Widows

Свойства `orphans` и `widows` определяют минимальное количество строк, которое должно остаться на странице (в колонке) при разрыве.

## Свойства

| Свойство | Описание |
|---|---|
| `orphans` | Минимум строк **в конце** страницы (после разрыва) |
| `widows` | Минимум строк **в начале** страницы (после разрыва) |

## Значения

Оба свойства принимают целое число (≥ 1). Значение по умолчанию — `2`.

## илиphans

Задаёт минимальное количество строк абзаца, которые должны остаться на странице (в колонке) после разрыва. Если после разрыва остаётся меньше строк, весь абзац переносится на следующую страницу:

```css
p {
  orphans: 3;
}
```

::: info
Значение `3` означает: в конце страницы должно остаться минимум 3 строки абзаца. Если их меньше — весь абзац уйдёт на следующую страницу.
:::

## widows

Задаёт минимальное количество строк абзаца, которые должны оказаться в начале страницы (колонки) после разрыва:

```css
p {
  widows: 2;
}
```

::: info
Значение `2` означает: в начале новой страницы должно быть минимум 2 строки абзаца. Если их меньше — абзац останется на предыдущей странице.
:::

## Примеры

### Базовая настройка для печати

```css
@media print {
  p {
    orphans: 3;
    widows: 3;
  }
}
```

### Жёсткие правила для журнала

```css
@media print {
  article p {
    orphans: 4;
    widows: 2;
  }
}
```

::: tip
Более высокие значения `orphans` уменьшают количество «осиротевших» строк в конце страницы, но могут увеличить количество пустого пространства.
:::

### Комплексный пример

```css
@media print {
  body {
    orphans: 3;
    widows: 3;
  }

  h1, h2, h3, h4 {
    break-after: avoid;
    widows: 3;
  }

  blockquote, pre, table {
    break-inside: avoid;
    orphans: 3;
    widows: 3;
  }
}
```

## Что такое сироты и вдовы

Термины пришли из типографики:

- **Сирота (orphan)** — строка абзаца, оставшаяся одна в конце страницы (колонки). Визуально выглядит как «оторванная» строка.
- **Вдова (widow)** — строка абзаца, оставшаяся одна в начале новой страницы (колонки). Также визуально неудачна.

```
┌─────────────────────────┐    ┌─────────────────────────┐
│ ...текст предыдущего    │    │ Одна строка — вдова     │
│ абзаца продолжается.    │    │                         │
│ И вот последняя строка  │    │ Новый абзац начинается  │
│ — сирота.               │    │ здесь...                │
└─────────────────────────┘    └─────────────────────────┘
```
