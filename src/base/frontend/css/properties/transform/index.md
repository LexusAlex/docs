# 2D/3D-трансформации

Трансформации позволяют изменять форму, размер и положение элементов без влияния на документальный поток (в отличие от `position`). Элемент остаётся на своём месте в разметке, но визуально перемещается, поворачивается или масштабируется.

## Основные возможности

| Возможность | CSS-свойства | Описание |
|-------------|-------------|----------|
| 2D-трансформации | `transform` | Поворот, масштаб, сдвиг, наклон |
| 3D-трансформации | `transform`, `perspective` | Вращение в пространстве, перспектива |
| Точка трансформации | `transform-origin` | Центр вращения/масштабирования |

## Когда использовать

- **Анимации** — плавные переходы при наведении, загрузке, взаимодействии
- **Hover-эффекты** — увеличение, поворот карточек, кнопок
- **Интерфейсы** — 3D-переворот карточек, параллакс-эффекты
- **Декор** — наклоненные элементы, вращение иконок

:::tip
Трансформации не влияют на layout — элемент не сдвигает соседей. Для изменения потока используйте `position` или `flex`/`grid`.
:::
