# Frontend (Клиент)

Разработка клиентской части веб-приложений. Код выполняется в браузере пользователя и отвечает за отображение интерфейса, обработку событий и взаимодействие с сервером.

## Основные технологии

- **HTML** — структура и семантика документов
- **CSS** — визуальное оформление, селекторы, методологии (БЭМ)
- **JavaScript** — интерактивность, работа с DOM, асинхронные запросы

## Разделы

### [HTML](/base/frontend/html/)

Структура HTML-документа, элементы и их атрибуты. Блочные и строчные элементы, семантическая разметка.

### [CSS](/base/frontend/css/)

Селекторы, каскадность, методологии организации стилей. Базовые, комбинаторные, псевдоклассы и псевдоэлементы.

### [JavaScript](/base/frontend/javascript/)

Vanilla JavaScript: события, EventTarget, Promise. Фреймворки (Vue.js) и библиотеки.
