# Концепции

## Декларативность

`vue` позволяет декларативно описывать конечный `html`, на основе состояния `javascript`.

То есть декларативность - это когда мы описываем результат, а не способ его получения.

## Реактивность

`vue` автоматически отслеживает изменения состояния `javascript` и эффективно обновляет `DOM`.

Реактивность - это способность системы реагировать на изменение своего состояния.

Когда мы меняем данные в `javacript`, `html` автоматически обновляется, не необходимости вручную искать и менять элементы.

::: info
Во `vue` используется `Proxy` из современного `javascript`, который отслеживает какие части `DOM` поменялись, и обновлет именно их.
:::

## Комопнентный подход

Можно разбить каждый элемент интерфейса на независимые компоненты. Так их удобно поддерживать и тестировать.

## Однофайловые комопоненты sfc

Комопонент - это файл с расширением `.vue`, который содержит в себе три части:

- `template` - разметка со специальными директивами.
- `script` - логика компонента.
- `style` - стили для текущего комопнента.
